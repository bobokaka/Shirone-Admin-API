# ダッシュボードとプレビュー

`http://localhost:5173/` を開いて最初に表示されるページが**ダッシュボード**です。管理画面全体の概要です。未公開の変更がどれだけあるか、記事とモーメンツが何件あるか、そしてブログの実際の見た目をリアルタイム描画するプレビューウィンドウが並びます。

![ダッシュボード](/assets/guide/dashboard.png)

## 4枚の統計カード

| カード | 数値の意味 | ショートカットボタン |
|------|----------|----------|
| **未公開の変更** | コンテンツリポジトリ内のステージ済み + 変更済み + 未追跡の git 変更ファイル総数 | 「公開へ」→ [コミットと公開](./publish.md)へ移動 |
| **記事総数** | コンテンツリポジトリ内の全記事（下書きを含む） | 「記事を管理」→ [記事管理](./posts.md)へ移動 |
| **モーメンツ総数** | すべてのモーメンツ（下書きを含む） | 「モーメンツを管理」→ [モーメンツ](./moments.md)へ移動 |
| **下書き総数** | 記事とモーメンツのうち下書きマークが付いた数の合計 | 「執筆を続ける」→ 記事管理へ移動 |

「未公開の変更」は、管理画面で行ったまだコミットしていない変更すべての集計です。記事を書き、モーメンツを投稿した後にこの数字が 0 でなければ、まだ公開されていないことを意味します。

## 最近のコンテンツ

統計カードの下の 2枚のリストカードは、**直近 6件の記事**と**直近 6件のモーメンツ**を表示します：

- 記事行にはタイトルと公開日が表示され、下書きには黄色いラベルが付きます
- モーメンツ行には時刻、ピン留め/下書き/タグが表示され、本文は先頭 3行を抜粋、サムネイルは最大 3枚（クリックで拡大プレビュー）
- 右上の「もっと見る」から対応する管理ページへ移動できます

## 実サイトプレビュー {#実サイトプレビュー}

ページ下部の「実サイトプレビュー」カードは iframe を内蔵し、`http://localhost:4321/` を直接読み込みます。つまりテーマリポジトリの Astro 開発サーバーが描画した**実際のサイト**です。スクリーンショットでも簡易シミュレーションでもなく、プレビューの結果は将来公開されるサイトと完全に一致します。

### 状態表示と操作

プレビューパネル上部のツールバー、左から：

- **状態ラベル**（3秒ごとにポーリング）：
  - サイト準備完了 `:4321` —— プレビュー可能
  - dev server の起動を検出 `:4321` —— プレビュー可能（このパネルが起動したプロセスではありません）
  - 起動中、初回はコンパイルが必要です… —— Astro がコールドスタート中。しばらくお待ちください
  - 未実行 —— 「プレビューを起動」を押す必要があります
- **プレビューを起動 / 停止** —— 管理画面からテーマリポジトリの `content:watch` + `astro dev` プロセスを立ち上げ、または終了します
- **新しいウィンドウで開く** —— ブラウザーのタブで直接 `:4321` にアクセスします

ダッシュボードのプレビューパネルは、プロセスを自動で立ち上げません（邪魔をしないためです）。「プレビューを起動」を手動で押す必要があります。`node workspace/content-watch.mjs` でワンクリック起動した場合、dev server はすでに動いているので、パネルはすぐ準備完了と表示します。

### プレビューが「実サイト」である理由

[3リポジトリワークスペース](./workspace.md)で説明したデータフロー：管理画面で保存 → コンテンツリポジトリへ書き込み → `content:watch` がテーマリポジトリへマテリアライズ → Astro が再コンパイル。だから管理画面で一文直して保存すると、数秒後にプレビュー内のブログが更新されます——**見えているものが、まさに公開される実際のサイトです**。

## トップバーとグローバル入口

すべてのページで共通するトップバー：

- **ページタイトル** —— 現在いる機能ページの名前
- **接続状態ラベル** —— コンテンツリポジトリの「接続済み / 未接続」（詳細は[3リポジトリワークスペース · 接続状態の確認方法](./workspace.md#接続状態の確認方法)）
- **✨ ボタン** —— グローバルの [AI コンソール](./ai.md#ai-コンソール)を開く
- **歯車ボタン** —— 「設定」ダイアログを開く（[AI プロバイダー設定](./ai.md#プロバイダーの設定)と About ページ）
