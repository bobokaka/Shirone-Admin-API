# 構造化データ

ブログの「マイ」ページにあるプロジェクト、スキル、デバイスのリスト。サイドバーのアニメ視聴リスト、友達リンク、背景のプレイリスト——これらはすべて**構造化データ**です。各種類はコンテンツリポジトリ `data/*.ts` の 1つの TypeScript 配列です。「データ管理」ページはそれらすべてをテーブル + フォームのビジュアル編集にし、変更は**即座にリポジトリへ反映**されます。

![データ管理](/assets/guide/data.png)

## 8種類のデータ {#_8種類のデータ}

| タブ | 項目 | 代表的なフィールド |
|------|------|----------|
| プロジェクト | プロジェクト | 名前、概要、カテゴリ、段階（リリース済み/開発中/模索中）、技術スタック、注目フラグ |
| スキル | スキル | 名前、カテゴリ（フロントエンド/バックエンド/ツール/ゲーム開発）、レベル（入門→エキスパート）、アイコン |
| タイムライン | イベント | タイトル、日付、分類（マイルストーン/プロジェクト/経験/生活）、要点、関連リンク |
| デバイス | デバイス | 名前、ブランド、カテゴリ、状態（使用中/サブ用/引退/欲しい）、スペック |
| アニメ | アニメ | タイトル、状態（視聴中/視聴済み/視聴予定/保留/中止）、評点、進捗、タイプ、カバー |
| 羅針盤 | シェルフ | 名前、アイコン、ナビゲーション項目（名前 + リンク + メモ） |
| プレイリスト | 曲目 | 曲名、アーティスト、カバー、音声 URL、再生時間 |
| 友達リンク | 友達リンク | サイト名、アバター、説明、URL、タグ |

## 共通操作

- **新規追加**——編集ダイアログを開いてフィールドを 1つずつ入力。必須項目の欠落はバリデーションでブロックされます
- **テーブル内で直接切替**——「注目」「有効」などのブール型フィールドはテーブル上でそのままトグルスイッチになっており、ひねれば保存されます
- **並べ替え**——各行右側の ↑↓ ボタンで順序を調整（配列の順序が表画面の表示順です）。即座に反映されます
- **編集 / 削除**——編集はダイアログに全フィールドを反映。削除には二重確認があります

楽になる細かい配慮：

- **識別フィールドの自動生成**——プロジェクトの key、デバイスの id、曲目の id などの識別列は手入力不要です。新規追加時にタイトルからピンイン slug を自動生成し（重複には番号付加）、友達リンクの id は最大値 +1 になります
- **アイコンフィールド**——Iconify アイコン名（例：`simple-icons:typescript`）を入力すると即座にプレビュー。アイコンはすべてローカル内蔵で、ネットワークリクエストは発生しません
- **画像フィールド**——カバーはローカルアップロード（データ種別に応じたリソースディレクトリへ自動保存）またはパスの貼り付けに対応。アニメ/プレイリストには専用のワンクリック取り込みがあります（後述）
- **羅針盤とタイムラインの項目リスト**——「ナビゲーション項目」「関連リンク」のようなネスト配列はビジュアルカードで編集します。各項目の名前/アイコン/URL を 1行で入力でき、必須バリデーションにも対応

すべての変更は**直列保存キュー**で `data/*.ts` に書き戻されます——ファイル内の interface 定義、コメント、export 文は文字通り保持され、置き換えられるのは配列リテラル部分だけです。手でメンテナンスしたコードが書き換えられることはありません。

## アニメ：検索取り込み

アニメタブ専用の「**検索して取り込み**」ボタン。データは [Bangumi（番組計画）](https://bgm.tv/)の公開 API から取得します：

![アニメ検索取り込み](/assets/guide/data-anime.png)

1. **検索**——中国語/日本語/英語のタイトルを入力すると、候補リストを返します（年、話数、評点、カバーつき）
2. **項目を選択**——詳細を自動取得して補完します：制作会社、放送期間、高頻度のジャンルタグ
3. **確定**——新しいアニメの下書きを 1件生成します。タイトル/年/タイプ/概要/カバー/制作はすべて入力済みで、**状態と評点だけあなたが決める**。カバー画像は Bangumi 公式の画像ホストからダウンロードされ、`public/assets/anime/` に保存されます

これから視聴記録のメタデータを手入力する必要はありません。1本観終わるたびに検索するだけです。

## プレイリスト：音楽の取り込み {#プレイリスト-音楽の取り込み}

プレイリストタブの「**音楽の取り込み**」には 3つの楽曲取り込み方法があります：

- **AI 検索**——欲しい曲を言葉で（曲名/ジャンル）、AI が Web 検索し**著作権情報**つきで返します（無料商用可否、根拠リンク）。確定すると音声とカバーが自動でリポジトリに保存されます
- **直リンク取り込み**——音声の直リンクを貼り付けると、サーバー側が代理ダウンロードします（ブラウザーの CORS で取得できないものも落とせます）
- **ローカルアップロード**——音声ファイルを直接アップロード

取り込んだ後はテーブルの **▶ 試聴** をクリック。下部のプレイヤーバーで選んだものをすぐ再生でき、気に入ってから保存します。

## タイムライン：AI 起草

タイムラインタブの「**AI 起草**」ボタン（AI 有効時に表示）は、2つのモードでイベントの下書きを一括生成します：

- **git モード**——3つのリポジトリのコミット履歴をスキャンし（各リポジトリ最大 30件、ファイル増減統計つき）、AI がタイムラインイベントにまとめます。「今月何をやったか」の振り返りに最適です
- **記述モード**——一文で記述すると、AI が規範的なイベント（タイトル/日付/分類/要点/タグ）に起草します

生成された下書きリストは**1件ずつチェックボックスで選択**でき、収録済みのイベントは自動重複除去されます（タイトル + 日付で照合）。挿入を確定すると、日付から正しい位置を探してリストに挿入・保存され、日付フォーマットはサイトで使われるドット区切り（`2025.06.01`）に自動変換されます。

## フィールド単位の AI {#フィールド単位-ai}

概要や説明のような長文テキストフィールド（プロジェクト概要、スキル説明、アニメ説明、友達リンク説明、タイムライン説明、デバイス説明）には、編集ダイアログ右上に **✨ ボタン**があります。項目タイトルを入力した後、クリックすると AI が 1–3 文の中国語でそのフィールドを生成または書き換えます。結果はストリーミングでそのまま入力欄に育ち、停止も手修正も可能です。
