# 記事管理

「記事管理」ページは記事を扱うメインの入口です。すべての記事の閲覧、カテゴリ・タグでのフィルタリング、本文のクイックプレビュー、カテゴリ体系の一括整理ができます。

![記事管理](/assets/guide/posts.png)

ページは左右 2カラムです。**左側の記事リスト**（フィルター + 選択）、**右側のコンテンツプレビュー**（閲覧またはその場編集）。左側の記事をクリックすると、右側に即座に Markdown 本文が描画されます。

## 新規記事の作成

ツールバーの「**新規記事**」をクリックし、ダイアログにタイトルを入力して（作成後いつでも変更可能）確定すると：

1. バックエンドがコンテンツリポジトリの `content/posts/` 配下に**下書き状態**の記事を作成します
2. 自動的に[記事編集](./post-editor.md)ページへ移動し、執筆を開始します

記事タイトルはピンイン転写で URL フレンドリーなディレクトリ名（slug）に変換されます。例：《快速上手指南》（中国語タイトルの場合）→ `kuai-su-shang-shou-zhi-nan/index.md`。重複する場合は自動的に番号を付加します。

## 閲覧とフィルタリング

ツールバーには 3つのフィルターがあり、組み合わせて使えます：

| フィルター | 動作 |
|--------|------|
| 検索ボックス | **タイトル、カテゴリ、タグ**を同時にマッチ（大文字小文字を区別しない） |
| カテゴリドロップダウン | そのカテゴリの記事のみ表示。選択肢の後ろの括弧内はそのカテゴリの記事数 |
| タグドロップダウン | そのタグを含む記事のみ表示 |

リストの先頭には「記事（フィルター後 / 全件）」がリアルタイム表示されます。各記事行にはタイトル、公開日、カテゴリに加え、状態ラベルが表示されます。黄色の「下書き」、「ピン留め」、赤の「暗号化」です。

## プレビューとその場編集

記事を選択すると右側に表示されます：

- **タイトルとメタ情報**：日付、カテゴリ、タグ、下書き/ピン留め/暗号化ラベル
- **本文描画**：Markdown をリアルタイム描画。記事ディレクトリ内の画像（`./images/…` 相対参照）もそのまま表示されます
- **編集**ボタン：右カラムがその場で完全なエディターに切り替わります（[記事編集](./post-editor.md)ページと同一のインターフェースで、分割プレビューが付かないだけです）。エディター右上の「分割編集」アイコンから、左右分割プレビュー付きの完全編集ページへ移動でき、戻ってくるとこの記事の編集状態が自動復元されます
- **削除**ボタン：ディレクトリ式の記事では「この記事とそのディレクトリ配下の全画像を削除します」と確認を促します。git にコミット済みの内容は履歴から復元できます

> [!TIP]
> その場編集の状態で左側の記事を切り替えるとき、未保存の変更があれば**まずサイレント自動保存**してから切り替わるため、原稿が失われることはありません（詳細は[記事編集 · 自動保存](./post-editor.md#自動保存)）。

## カテゴリ / タグ管理 {#カテゴリ-タグ管理}

ツールバー右側の「**カテゴリ管理**」から一括整理ダイアログが開きます。サイト全体のカテゴリ体系で唯一メンテナンスが必要な場所です：

- 上部にカテゴリ / タグの 2タブがあり、リストは**使用記事数の降順**で並びます
- **リネーム / 統合**：あるカテゴリ（またはタグ）を新しい名前に変更します。新しい名前がすでに存在する場合は、両者の**統合**になります。バックエンドが記事ごとに frontmatter を書き換え、日付フォーマットを保持します
- **削除**：すべての記事からそのカテゴリ/タグを取り除きます（記事そのものには影響しません）

たとえば散らばった「JS」「JavaScript」を「JavaScript」に統一したい場合：「JS」をリネームして `JavaScript` を入力し、確定すれば関連するすべての記事が自動的に書き換えられます。

## ディスク上の記事の形態

保存形式を理解しておくと、バックアップやトラブルシュート時に余裕が生まれます：

```
content/posts/
├── hello/                  # ディレクトリ式（新規作成のデフォルト）：画像を記事と一緒に管理
│   ├── index.md
│   └── images/
│       └── cover.webp
└── old-post.md             # フラット式（過去の記事や外部取り込み）：単一ファイル
```

- 新規作成した記事はすべて**ディレクトリ式**で、エディターでアップロードした画像は自動的にそのディレクトリの `images/` サブディレクトリに入ります
- リストは**ピン留め優先、公開日の降順**で並びます
