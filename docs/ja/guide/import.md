# プラットフォームからの取り込み

他のプラットフォームでブログを書いていますか？「プラットフォームからの取り込み」ページが移行の通路を提供します。現在は**簡書（Jianshu）**に対応し、ページ上部はプラットフォーム別のタブになっていて、今後のプラットフォームはこの形で拡張します。

取り込みには 2つの経路があります。ページに入ったらまずどちらかを選びます：

| 方法 | 適するケース | 入力 |
|------|------|------|
| **エクスポートパッケージ取り込み** | サイト全体の引っ越し、数十〜数百本 | 簡書公式の「全記事をパッケージダウンロード」で得られる rar / zip |
| **単一記事の貼り付け** | 厳選した 1本、貼ってすぐ変換 | Web 版の記事ページを全選択コピーした内容 |

![プラットフォームからの取り込み](/assets/guide/import.png)

## エクスポートパッケージ取り込み

5ステップのウィザード：**方法の選択 → パッケージのアップロード → 記事の選択 → コンテンツ変換 → 取り込み完了**。

### ステップ 1：エクスポートパッケージのアップロード

簡書の「設定 → アカウント管理 → 全記事をパッケージダウンロード」でエクスポートを申請します（簡書がダウンロードリンクをメールで送ります）。圧縮パッケージを入手したらアップロードエリアにドラッグします。制限：zip / rar 形式、1パッケージ ≤30MB です。

アップロード後、サーバーがメモリ上で解凍・解析し、**文集（ノートブック）**ごとに全記事を一覧表示します。

### ステップ 2：記事の選択

- 解析成功後、未取り込みの記事が**デフォルトで全選択**されています
- 文集単位での一括チェック、全選択/全解除に対応
- 取り込み済みの記事には「取り込み済み」マークが付き選択不可。重複を防ぎます
- 各記事は先に「プレビュー」できます——ディスクに書かずに変換後の Markdown を確認できます

ページ右側で取り込みオプションを設定します：

| オプション | 説明 |
|------|------|
| 公開日を統一 | 簡書のエクスポートパッケージには日付が含まれないため、全記事に同じ公開日を適用（後から 1本ずつ変更可能） |
| 文集をカテゴリにする | チェックすると各文集名がそのまま記事カテゴリになります。未チェックなら統一カテゴリを手動で指定 |
| タグ | このバッチの記事に一律でタグを追加 |
| 画像のローカル化 | 簡書 CDN の画像を各記事の `images/` ディレクトリにダウンロード。失敗したものはリモートリンクを保持 |
| 下書きとして取り込み | **チェックしたままをおすすめ**——まず[記事管理](./posts.md)で目を通してから公開 |

### ステップ 3：コンテンツ変換

開始をクリックすると、サーバーが**バックグラウンドタスク**を作成して 1本ずつ変換し、ページは 2秒ごとに進捗をポーリングします：総数、完了数、現在処理中の記事タイトル。途中でページを離れてもタスクは継続します。

### ステップ 4：完了

タスク終了時に結果一覧を表示します：各記事の成否、保存先パス、ローカル化した画像数。失敗したものには理由が示されます（1本の失敗は他の記事に影響しません）。「次のパッケージを取り込み」で続けるか、記事管理へ移動して成果を確認できます。

## 単一記事の貼り付け

5ステップのウィザード：**方法の選択 → 内容の貼り付け → コンテンツ変換 → 記事情報 → 取り込み完了**。

1. **貼り付け**——簡書の Web 版で記事を開き、全選択コピーして、エディターにそのまま `Ctrl+V` で貼り付けます：リッチテキストは自動的に Markdown へ変換され（見出し、太字、リンク、画像はすべて保持）、左にソース・右にプレビューで、引き続き手修正もできます
2. **コンテンツ変換**——確定するとサーバーがリポジトリへ保存します：画像は記事ディレクトリへ自動ダウンロード（失敗したものはリモートリンクを保持）し、ディレクトリ式の記事を生成します
3. **記事情報**——AI が本文を解析して**自動補完**します：タイトル（空欄なら AI が命名）、要約、カテゴリ、タグの提案。すべて手修正可能。AI が利用不可の場合は本文からの要約抽出にフォールバックし、`aiUsed=false` を明示します
4. **確定**——メタ情報を記事に書き戻して完了。[記事編集](./post-editor.md)へワンクリックで移動して仕上げもできます

> [!TIP]
> タイトル入力欄も貼り付けフォールバックに対応しています：クリップボードにリッチテキストしかない場合（Web からコピーするとよくある）、自動的にプレーンテキストを抽出して 1行に圧縮します。

## セッションとタスクについて

- エクスポートパッケージをアップロードすると 1つの**セッション**が成立します（解析結果はサーバーのメモリにキャッシュ）。有効期間は 24時間、同時に保持できるのは最大 3件で、期限切れ/超過分は最も古いものから自動破棄——「別のパッケージに切り替え」で現在のセッションを即座に破棄できます
- バックグラウンド取り込みタスクの結果は 1時間保持されます
- サービスを再起動するとメモリ上のセッションとタスクは消えます。エクスポートパッケージを再アップロードすればよく、**取り込み済みの記事には影響しません**（すでにコンテンツリポジトリに保存されているため）

## 次のステップ

- 取り込んだ記事は[記事管理](./posts.md)で 1本ずつ確認し、下書きマークを外す
- カテゴリの一括変更は[記事管理 · カテゴリ管理](./posts.md#カテゴリ-タグ管理)
