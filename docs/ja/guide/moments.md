# モーメンツ

「モーメンツ」は記事より軽いコンテンツ形式です。ひとことの思いつき、数枚の画像、気分のアイコン。投稿フォームがページ上部に、フィードが下部にあり、書いたらすぐ投稿できます。

![モーメンツ](/assets/guide/moments.png)

## モーメンツを投稿する

投稿フォームカードは上から：

1. **本文**——複数行テキスト欄。今の思いを
2. **画像エリア**——最大 **9枚**。+ をクリックして選ぶか、貼り付けでアップロード
3. **メタ情報行**——気分 / 場所 / タグ / 投稿時刻 / ピン留め
4. **操作行**——AI 添削（AI 有効時）/ 下書き保存 / モーメンツを投稿

### 気分アイコン

9つのプリセット気分から選べます：😊 嬉しい、🤩 ワクワク、😐 平穏、😔 落ち込み、😢 悲しい、❤️ 好き、🎉 祝い、☕ 一杯、🌙 おやすみ。アイコンは Iconify 名で保存され（すべてローカル内蔵でネットワークリクエストなし）、表画面で対応するアイコンとして描画されます。

### 画像のアーカイブ先

1回の投稿のすべての画像は**同じバッチディレクトリ**に入ります：

```
public/images/moments/<yyyymmdd-HHmmss>/   # バッチ番号はモーメンツのファイル名と同一
├── 1.webp
└── 2.webp
```

複数選択アップロードが並行して進んでも同じバッチに振り分けられます（バッチ番号は事前に生成）。このディレクトリ規則には理由があります——テーマのサムネイル生成パイプラインは `public/images/moments/` **だけをスキャン**するため、モーメンツ画像を別の場所に置くと表画面でサムネイルが生成できません。だからバックエンドが保存先を強制しています。

> [!TIP]
> 投稿前に画像を取り除いても、今回は公開しないだけでファイルはリポジトリに残ります。モーメンツ全体を削除しても画像ファイルは残るので、掃除したいときは手動で処理してください。

### AI 支援（任意）

AI 有効時、投稿フォームに 2つの入口が追加されます：

- **AI 添削**——本文をストリーミングで書き換え、結果はそのまま入力欄の中で育ちます（口語的で自然、口調と事実を保持）。いつでも停止でき、停止すれば原文に戻ります
- **AI 提案**——本文から 2–4 個のタグを抽出（既存タグとマージして重複除去）し、気分も推測します（すでに選択済みなら上書きしません）

## フィードの管理

下部のリストはフィルターの組み合わせとページング（1ページ 8件）に対応します：

| フィルター | 説明 |
|------|------|
| 検索ボックス | 本文、場所、タグをマッチ |
| 状態ドロップダウン | すべて / 公開済み / 下書き |
| タグ複数選択 | カード上のタグをクリックしても素早く絞り込めます（もう一度クリックで解除） |
| ピン留めのみ表示 | チェックボックス |

各モーメンツカードには次の操作があります：

- **編集**——内容を上部の投稿フォームに戻します（新しくアップロードする画像は**新しいバッチ**に入り、古いディレクトリには混ざりません）。修正後に「モーメンツを投稿」で保存
- **ピン留め切替**——ワンクリックでピン留め/解除、リストは即座に更新されます
- **削除**——二重確認の後 `.md` ファイルを削除します（画像は保持）

## モーメンツと記事の違い

| | 記事 | モーメンツ |
|---|------|------|
| コンテンツ形式 | 長文 + メタ情報体系 | 短いテキスト + 画像 + 気分 |
| 保存先 | `content/posts/<slug>/index.md` | `content/moments/<yyyymmdd-HHmmss>.md` |
| 典型的な用途 | チュートリアル、ノート、深い考察 | 近況、つぶやき、とりあえずの記録 |
