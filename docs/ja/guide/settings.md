# サイト設定

「サイト設定」ページは、テーマのすべての設定項目をフォーム化します。左側にセクション別フォーム、右側に[実サイトプレビュー](./dashboard.md#実サイトプレビュー)を内蔵し、保存すればプレビューが更新される、WYSIWYG（見たままを得る）の作りです。

ページは 5つのタブで構成されます：**基本情報**、**ナビゲーション**、**フッター**、**テーマ外観**、**バナー壁紙**。

![サイト設定 · 基本情報](/assets/guide/settings.png)

## 基本情報

7つのセクションがあり、それぞれ独立して保存します：

| セクション | 何を設定するか |
|------|----------|
| サイト情報 | サイト名、サブタイトル（サブタイトルには AI ✨ による一言生成つき） |
| プロフィール | アバター（オンライン URL またはローカルアップロード、自動リネームでリポジトリに保存）、ニックネーム、署名（同じく AI ✨ つき） |
| ソーシャルリンク | GitHub / Bilibili などの外部リンクリスト：名前、Iconify アイコン、URL |
| サイトアイコン favicon | ライト / ダークの 2スロット。未カスタム時はテーマデフォルトアイコンの現在有効表示。アップロードは自動で `favicon-light/dark.<ext>` と命名してその場で置き換え、オンライン URL を直接入力しても OK |
| 一般設定 | サイトアドレス（デプロイ後の最終ドメイン）、サブパス（ルートにデプロイするなら `/`）、タイムゾーン（主要なタイムゾーンのドロップダウン、手入力も可） |
| 訪問者表示パネル | 表画面で訪問者に開放する表示スイッチの制御：カラーピッカー、カラースペック切替、背景モード、リストレイアウト、モーション軽減、背景テクスチャ |
| 国際化 | 多言語を開放するか：開放する言語の集合にチェック。サイトの主言語はその集合に含まれる必要があります。オフなら全サイトを簡体字中国語に固定 |

## ナビゲーション

ビジュアルなナビゲーションメニューエディター：

- **テーマプリセット**——15個の内蔵プリセット（ホーム、アーカイブ、友達リンクなど）から選んでワンクリックで組み込み
- **カスタムリンク**——名前 + アイコン + URL、「新しいウィンドウで開く」マークも付けられます
- **ドロップダウングループ**——サブメニューをドラッグアウトして同系統の入口をまとめます

ナビゲーション設定は全体で保存され、配列のセマンティクスは**一括置換**です。

## フッター

- **有効スイッチ**——カスタムフッターの内容をテーマの著作権行の上に注入するかを制御
- **HTML エディター**——CodeMirror コードエディターに **Prettier フォーマット**ボタンが付属。フッター HTML の原文はコンテンツリポジトリの `config/footer.html` に保存されます
- **フッター画像ライブラリ**——画像アップロードまたはオンライン直リンクの貼り付け（サーバー側が代理ダウンロード、webp は png/jpg に自動変換）で `public/images/footer/` に保存。「パスをコピー」で HTML に貼り付けます
- **リアルタイムプレビュー**——iframe でテーマのフッター描画を近似再現。著作権行 + あなたのカスタム内容

## テーマ外観

![サイト設定 · テーマ外観](/assets/guide/settings-appearance.png)

2つのセクション：

### テーマカラー

- **色相スライダー**（0–360）——その色相から生成される 5段階のカラーパレットをリアルタイム表示
- **ロック**——チェックするとサイトの色相がコンテンツ/訪問者の好みに追従しなくなります
- **カラースタイル**——Material 3 の 9種類のダイナミック配色スタイル：tonalSpot（クラシックで柔らかい）、vibrant（鮮やか）、content（コンテンツの色から採色）、expressive、rainbow、fruitSalad、monochrome、neutral、fidelity
- **カラースペック**——Material 3 の 2021 / 2025 の 2世代の仕様

### 壁紙とテクスチャ

- **デフォルト背景モード**——banner / none の二択。壁紙未選択時の表画面のデフォルト形態を決めます
- **背景テクスチャ**——6種類のプリセット：none、starlight（星光）、cyber-dots（サイバードット）、topography（等高線）、geometric（幾何学）、sakura（桜）。不透明度 0.05–0.25。モーション許可スイッチつき

## バナー壁紙 {#バナー壁紙}

ホームバナーの完全なコントロール：

- **デスクトップ壁紙 / モバイル壁紙**の 2リスト——ローカルアップロード、オンライン直リンクの取り込み（サーバー代理取得）、**AI 壁紙推奨**ボタン（safebooru 画像ソースからサイズで絞り込んで一括取得：デスクトップは ≥1920 の横長画像、モバイルは ≥1920 の縦長画像。選んでダウンロードしリポジトリに保存）
- **表示制御**——位置（top/center/bottom）、マスク（スイッチ + 不透明度）
- **ホーム文言**——タイトル、複数行のサブタイトル、タイプライター効果（速度/削除速度/停止時間/ループ）。サブタイトルは **AI 生成** をクリックすると、サイト名と署名から 4–6 行のローテーション文案を一括生成できます
- **スライドショー**——壁紙が複数枚のときに有効。切替間隔、フェード時間、6種類の切替アニメーション（ken-burns の緩やかなパン・ズーム、zoom-in/out、pan-left/right、none）
- **波の装飾**——バナー底部の波のモーションスイッチ

> [!TIP]
> バナーを保存するとき、デスクトップ/モバイルのどちらからも参照されなくなったローカル壁紙ファイルは**自動クリーンアップ**されます。手動でファイルを消す必要はありません。

## 設定の保存先

すべての設定はコンテンツリポジトリの `config/*.yaml` に書き込まれ、**最小上書き**の原則に従います。変更したキーだけを書き、未宣言のフィールドはテーマのデフォルト値を継承します——テーマのアップグレードで設定項目が増えてもサイトは自動的に追従し、「全量スナップショット」のせいで古いバージョンに固まることがありません。辞書キーは再帰マージ、配列は一括置換です。
