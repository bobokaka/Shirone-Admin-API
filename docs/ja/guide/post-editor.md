# 記事編集

記事エディターは管理画面で最も機能が密集したページです。[記事管理](./posts.md)から新規作成、または「編集」をクリックして入ると、完全編集ページには**左右分割のリアルタイムプレビュー**が付いています。記事管理ページ内のその場編集は、同じエディターの 1カラム形態です。

![記事編集](/assets/guide/post-editor.png)

## トップバーの操作

左から：

| ボタン | 役割 |
|------|------|
| 戻る | 自動保存してから前のページへ戻る |
| タイトル入力欄 | 常時表示される大型入力欄。いつでも改名可能 |
| 記事情報 | メタ情報ドロワーを開く（後述） |
| 削除 | 記事とそのディレクトリ配下の全画像を削除。二重確認あり |
| 保存 | 即座にコンテンツリポジトリへ書き込む |
| 保存して公開へ | 保存後、そのまま [コミットと公開](./publish.md)へ移動 |

トップバーには「自動保存済み HH:mm:ss」と、直近の自動保存時刻も表示されます。

## エディター

エディターは **Markdown ソースモード**です（md-editor-v3 + CodeMirror ベース）。Markdown ソースを直接書くと、右側の分割ペインにリアルタイムでプレビューが描画されます。ツールバーには常用の整形が揃っています：太字、斜体、取り消し線、見出し、引用、リスト、タスク、インラインコード、コードブロック、リンク、画像、表、元に戻す/やり直し、プレビュー/目次の切り替えです。

**画像はゼロ手間**：エディターにスクリーンショットを貼り付け、または画像ボタンからアップロードすると、ファイルは現在の記事ディレクトリの `images/` サブディレクトリに自動保存され、本文には相対参照（`./images/xxx.webp`）が自動挿入されます。記事はこれで自己完結します——ディレクトリごと持ち出せば、それだけで完全な 1本になります。

AI 有効時はツールバーの末尾に **AI ドロップダウンツール**が追加されます。詳細は後述の [AI ライティング支援](#ai-ライティング支援)。

## 記事情報ドロワー

「記事情報」ドロワーがすべてのメタデータ（記事の frontmatter に対応）を收纳します：

### 基本フィールド

- **公開日**（`YYYY-MM-DD`）と**時刻**——同じ日に複数の記事を公開するときの並び順の制御に使います。タイムゾーンは `+08:00` に自動正規化されます
- **カテゴリ**——ドロップダウンで既存カテゴリを選択（使用カウント付き）。新しい名前を直接入力して Enter で新規作成もできます
- **タグ**——複数選択。同じく入力による新規作成に対応
- **要約**——空欄の場合、テーマが本文の先頭部分を自動抽出します。カバーはローカルアップロードか外部リンクに対応
- **スイッチ**——下書き / ピン留め / コメント / 暗号化

### 暗号化記事

「暗号化」にチェックを入れると 3つのフィールドが展開します：

- **アクセスパスワード**——すでに設定済みの記事では、入力すれば変更、空欄なら現状維持。「暗号化」のチェックを外せばパスワードはクリアされます
- **パスワードヒント**——訪問者がパスワードを入力する前に見るヒント文
- **ホームカードでプレビューを隠す**——暗号化された内容が要約としてホームに漏れるのを防ぎます

### アクセスパス

3つのモードが記事の最終 URL を決め、下部にリアルタイムの URL プレビューがあります：

| モード | URL 形式 | 適する場面 |
|------|----------|----------|
| デフォルト | `/posts/<記事名>/` | 通常の記事 |
| カスタムエイリアス | `/posts/<エイリアス>/` | より短く、意味が分かりやすい URL にしたい |
| ルートパス固定リンク | `/<カスタムパス>/` | 入念に作った看板ページ。例：`/about-me/` |

## AI ライティング支援 {#ai-ライティング支援}

> [!NOTE]
> 以下の機能には、先に AI アシスタントを有効化する必要があります（[設定方法](./ai.md#プロバイダーの設定)）。無効時はツールバーに AI 入口が表示されず、執筆機能には影響しません。

AI ドロップダウンツールには 5つのアクション + カスタム指示が組み込まれています。すべてのアクションは**コードと Shirone テーマ独自の拡張構文をそのまま保持**します（三重コロンコンテナ、file-tree など）：

| アクション | 対象範囲 | 結果の適用方法 |
|------|----------|--------------|
| AI 内容補完 | 全文 | 論述の欠落を補い、論理のつながりを強化——プレビューしてから適用 |
| AI フォーマット最適化 | 全文 | 見出し階層の正規化、句読点の統一、コードフェンスの言語指定の補完——プレビューしてから適用 |
| AI 添削 | **選択優先** | 選択テキストがあれば直接置換。未選択なら全文 diff プレビュー |
| AI 続きを書く | 文末 | 結末から自然に続き、結果を本文末尾に追記 |
| AI 要約生成 | 全文 | 80–160 字の要約を生成して「記事情報」に反映（既存の要約がある場合は先に確認） |
| カスタム指示 | 選択または全文 | 任意の指示（例：「より口語的な文体に変えて」）を入力して実行 |

**diff プレビュー**は、全文書き換え系アクション（補完/フォーマット最適化/未選択の添削/カスタム指示）のセーフティネットです。AI の結果は左右比較の差分ビューでストリーミング更新され、変化のない長い行は自動折りたたまれ、「前へ/次へ」でブロックごとに移動できます。確認して「置換を適用」してはじめて本文が書き換わります。生成を停止した中途半端な内容は適用できません。本文の長さが 20% 以上変化する場合はプレビュー枠が赤字で警告し、注意深い確認を促します。

すべての AI アクションはグローバルの [AI コンソール](./ai.md#ai-コンソール)で実行されます。思考プロセスが見え、いつでも停止できます。

## 自動保存

エディターには邪魔にならない自動保存の仕組みがあります：

- **10秒ごと**にチェックし、タイトルか本文に変更があった場合のみサイレントに書き込みます
- **記事の切り替え、戻るボタン、編集ページを離れる**瞬間にも先に自動保存されます
- あなたを止める唯一のケース：タイトルが空（書き込めない）のときで、その場合は先にタイトルを入れるよう促します

自動保存がカバーするのはタイトルと本文のみです。「記事情報」ドロワーのメタデータは「保存」ボタンで書き込まれます。
