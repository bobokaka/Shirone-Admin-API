# AI アシスタント

Shirone-Admin の AI 機能は**任意の拡張**です。設定しなくてもすべての機能は普通に動きます。設定すると、執筆・取り込み・公開の各場面に一連のスマート支援が加わります。この章ではまず設定、次に使い方を説明します。

## プロバイダーの設定 {#プロバイダーの設定}

トップバーの**歯車**をクリックして「設定」ダイアログを開き、左側のメニューで「AI アシスタント」を選びます。

![AI プロバイダー設定](/assets/guide/app-settings.png)

### 中核概念

- **複数プロバイダー**——複数セットの接続設定を保存でき（最大 20セット）、有効にするセットをいつでも切替できます。公式 API とリレープロキシを併用している人、複数モデルを使い分けたい人に適しています
- **2プロトコル**——各セットで二択：
  - `anthropic`——Anthropic 互換プロトコル（`v1/messages`）。公式 API と各社の「Anthropic 互換」中継に対応
  - `openai`——OpenAI 互換プロトコル（`chat/completions`）。OpenAI と大多数の中国製モデル API に対応
- **マスタースイッチ**——「有効」をオフにするとすべての AI 入口が非表示になり、API は一律拒否します

### 各セットのフィールド

| フィールド | 説明 |
|------|------|
| 名前 | 表示名。例：`Anthropic 公式` / `GLM リレー` |
| プロトコル | anthropic / openai |
| API アドレス | ルート URL で OK（`https://api.anthropic.com` または `https://api.openai.com/v1`）。裸のルート、`/v1` つき、プロキシのサブパスなどの書式を許容します |
| API Key | 本体の `server/data/ai-settings.json` にのみ保存され、**コンテンツリポジトリには絶対に書き込まれず**、公開で漏れることもありません |
| メインモデル | 日常タスク用。例：`claude-sonnet-5` / `gpt-4o-mini` / `glm-5.3` |
| 軽量モデル | 要約、タグ提案などの単純タスク用。**空欄 = メインモデルと同じ**（設定を 1つ節約） |
| Web 検索 | 対応するサービスに Web 検索ツールを追加。サーバー側が非対応の場合は自動的に通常リクエストへ降格します |
| temperature | サンプリング温度 0–2、デフォルト 0.7 |
| タイムアウト | 1リクエストのタイムアウト秒数。5–86400、デフォルト 30 |

### 操作の流れ

1. + をクリックして**プロバイダーを追加**（デフォルト名「デフォルト設定 N」、入力を始めると同時に改名）
2. フィールドを入力するか、**貼り付けインポート**を利用：Claude Code の `settings.json` の env ブロック、シェルの `export` 文、dotenv の内容を丸ごと貼り付けると、`ANTHROPIC_*` / `OPENAI_*` など 10個のキーを自動認識してフォームに流し込みます
3. **接続テスト**——保存せずともテストでき、レイテンシとモデルの応答を返します。通ってから**保存**

> [!WARNING]
> `server/data/ai-settings.json` には API Key が平文で入っています。このファイルは gitignore 済みですが、コミットや共有され得る場所へコピーしないでください。

## AI コンソール

トップバーの **✨ ボタン** で開くグローバルフローティングウィンドウが、すべての AI タスクの実行現場です：

![AI コンソール](/assets/guide/ai-console.png)

2つの形態があります：

- **タスク形態**——各機能ページからトリガーされた AI アクション（添削、続きを書く、起草…）がここで実行されます：「タスク」バッジつきの指示エントリ、モデルの**思考プロセス**（折りたたみ可能）、本文のストリーミング表示、所要時間と使用モデルの明記
- **対話形態**——タスク終了後そのまま入力欄で追問できます（コンテキストを携えて原稿をさらに修正）、あるいは純粋な雑談・質問も OK。Enter で送信、Shift+Enter で改行

共通の能力：**いつでも停止**（停止後の既存内容は場面に応じて保持または復元）、タイトルバーのクリックで**折りたたみ**して場所を取らない、**新しい会話**でクリアしてやり直し。複数ターンの対話履歴が 6万文字を超えると最も古いものから自動破棄されます。思考ストリームは直近 8000文字を保持します。

## 各ページの AI 入口

有効にすると、これらの場所に AI 機能が現れます（ページ別に整理）：

| ページ | 入口 | 機能 |
|------|------|------|
| [記事編集](./post-editor.md#ai-ライティング支援) | ツールバーの AI ドロップダウン | 内容補完 / フォーマット最適化 / 添削（選択優先）/ 続きを書く / 要約生成 / カスタム指示。全文書き換えは diff プレビューつき |
| [モーメンツ](./moments.md#ai-支援-任意) | 投稿フォームのボタン | 本文の添削（ストリーミング反映）、タグと気分の提案 |
| [データ管理](./data.md#フィールド単位-ai) | 編集ダイアログの ✨ | プロジェクト/スキル/アニメなどの説明フィールドの生成と書き換え |
| [データ管理 · タイムライン](./data.md#タイムライン-ai-起草) | AI 起草ボタン | git 履歴からのまとめ / 記述からのイベント起草。チェックして挿入 |
| [データ管理 · プレイリスト](./data.md#プレイリスト-音楽の取り込み) | 音楽の取り込み | Web 検索で曲目を検索し著作権情報つきで提示 |
| [サイト設定](./settings.md#基本情報) | 入力欄の ✨ | サブタイトル、署名の一言生成 |
| [サイト設定 · バナー](./settings.md#バナー壁紙) | AI 文言生成 | タイプライター用ローテーション文案の一括生成 |
| [プラットフォームからの取り込み](./import.md#単一記事の貼り付け) | 自動トリガー | 貼り付け記事のタイトル/要約/カテゴリ/タグの補完 |
| [コミットと公開](./publish.md#コミットメッセージ) | AI 生成ボタン | 2リポジトリのコミットメッセージ生成（非準拠なら自動フォールバック） |

さらに、エディターツールバーの AI メニューは生成中にローディングアニメーションを表示し、重複トリガーを無効化します。すべてのストリーミングタスクは 1つのコンソールを共有し、同時に実行されるのは 1つだけです。

## 設計思想

- **AI はメインフローを決してブロックしない**——コミットメッセージ生成の失敗はヒューリスティックへ自動フォールバック。取り込みのメタ情報失敗は本文要約へフォールバック。添削の停止は即座に原文へ復元
- **結果はプレビューしてから適用**——全文書き換え系はすべて diff 確認を経由し、あなたの文章を直接上書きしません
- **軽いタスクには軽いモデル**——タグ提案、要約などの小さなタスクは `modelFast` で思考をオフにして実行。お金と時間の節約になります
