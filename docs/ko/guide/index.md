# 가이드

**Shirone-Admin**에 오신 것을 환영합니다 — [Shirone](https://github.com/LyraVoid/Shirone) 블로그를 위한 시각화 콘텐츠 관리 도구입니다. 로컬에서 단독으로 실행되고 프론트엔드와 백엔드가 분리되어 있으며, 여러분의 콘텐츠 저장소를 직접 읽고 쓰면서 AI 글쓰기 지원과 원클릭 이중 저장소 게시를 제공합니다.

이 섹션은 **Shirone-Admin을 처음 접하는 독자**를 대상으로 합니다. 얕은 것부터 깊은 것까지, 모든 단계를 그대로 따라 할 수 있고 배경 지식이 전혀 필요 없습니다. 낯선 개념은 처음 등장할 때 그 자리에서 설명하거나 이동 링크를 제공합니다.

## 여기서 시작하기

- **[빠른 시작](./quick-start.md)** — 저장소 클론부터 관리 화면 열기까지, 완전한 작업 공간을 한 번에 구축합니다
- **[3저장소 작업 공간](./workspace.md)** — 아키텍처 이해: 데이터 흐름, 환경 변수, 포트와 연결 상태

## 콘텐츠 제작

- **[대시보드와 미리보기](./dashboard.md)** — 통계 카드, 최근 콘텐츠, 실제 사이트 미리보기 패널
- **[글 관리](./posts.md)** — 탐색·필터, 그 자리에서 편집, 분류/태그 일괄 정리
- **[글 편집](./post-editor.md)** — 에디터, 글 정보, 첨부 이미지, AI 글쓰기 지원, 자동 저장
- **[모먼트](./moments.md)** — 기분/장소/태그/9장 이미지, 게시와 관리

## 사이트 커스터마이징

- **[사이트 설정](./settings.md)** — 기본 정보, 내비게이션, 푸터, 테마 외형, 배너 배경화면
- **[구조화 데이터](./data.md)** — 프로젝트/스킬/타임라인/장치/애니메이션/나침반/재생목록/링크, 검색 가져오기 포함

## 더 알아보기

- **[콘텐츠 가져오기](./import.md)** — 젠수(简书) 내보내기 패키지 일괄 이전, 단일 글 붙여넣기 즉시 변환
- **[AI 어시스턴트](./ai.md)** — 프로바이더 설정, 전역 콘솔과 각 페이지의 AI 진입점
- **[커밋과 게시](./publish.md)** — 이중 저장소 게시, 게시 전 검증, 커밋 메시지 생성

## 읽기 방식 제안

- 체계적으로 배우고 싶다면: 위 순서대로 읽으면 됩니다. 각 글 말미에 다음 글로 이어지는 안내가 있습니다
- 특정 설정이나 인터페이스를 찾고 싶다면: [API 참조](/ko/api/)로 이동하세요
