# AI 어시스턴트

Shirone-Admin의 AI 기능은 **선택적 강화**입니다. 설정하지 않아도 모든 기능이 정상 동작하고, 설정하면 글쓰기·가져오기·게시 각 단계에 스마트한 보조가 한 세트 더 생깁니다. 이 장에서는 먼저 설정을, 다음 사용법을 다룹니다.

## 프로바이더 설정 {#프로바이더-설정}

상단 바의 **톱니바퀴**를 눌러 「설정」 대화상자를 열고 왼쪽 메뉴에서 「AI 어시스턴트」를 선택합니다.

![AI 프로바이더 설정](/assets/guide/app-settings.png)

### 핵심 개념

- **다중 프로바이더** — 여러 벌의 연결 설정을 저장할 수 있습니다(최대 20벌). 언제든 적용될 벌을 전환합니다. 공식 API와 프록시 중계를 함께 쓰거나, 여러 모델을 필요에 따라 갈아 끼우는 사람에게 적합
- **이중 프로토콜** — 각 설정마다 둘 중 하나:
  - `anthropic` — Anthropic 호환 프로토콜(`v1/messages`). 공식 API와 각사의 「Anthropic 호환」 중계에 대응
  - `openai` — OpenAI 호환 프로토콜(`chat/completions`). OpenAI와 대부분의 중국 모델 API에 대응
- **마스터 스위치** — 「활성」을 끄면 모든 AI 진입점이 숨겨지고 API는 일률적으로 거부합니다

### 각 설정의 필드

| 필드 | 설명 |
|------|------|
| 이름 | 표시 이름. 예: `Anthropic 공식` / `GLM 중계` |
| 프로토콜 | anthropic / openai |
| API 주소 | 루트 주소만 쓰면 됩니다(`https://api.anthropic.com` 또는 `https://api.openai.com/v1`). 맨 루트, `/v1` 포함, 프록시 하위 경로 등의 표기를 수용 |
| API Key | 본기의 `server/data/ai-settings.json`에만 저장되며 **콘텐츠 저장소에 절대 기록되지 않고** 게시와 함께 새어 나가지 않습니다 |
| 주 모델 | 일상 작업용. 예: `claude-sonnet-5` / `gpt-4o-mini` / `glm-5.3` |
| 경량 모델 | 요약, 태그 제안 같은 단순 작업용. **비워 두면 주 모델과 동일**(설정 하나 절약) |
| 웹 검색 | 지원하는 서비스에 웹 검색 도구를 덧붙입니다. 서버가 지원하지 않으면 일반 요청으로 자동 강등 |
| 온도 | 샘플링 온도 0–2, 기본 0.7 |
| 시간 초과 | 요청 한 번의 시간 초과 초. 5–86400, 기본 30 |

### 조작 흐름

1. + 를 눌러 **프로바이더 추가**(기본 이름 「기본 설정 N」, 바로 입력하면 이름 변경)
2. 필드를 채우거나 **붙여넣기 가져오기** 활용: Claude Code의 `settings.json` env 블록, 셸 `export` 문, dotenv 내용을 통째로 붙여넣으면 `ANTHROPIC_*` / `OPENAI_*` 등 10개 키를 자동 인식해 폼을 채웁니다
3. **연결 테스트** — 저장 없이도 테스트할 수 있으며 지연 시간과 모델 응답을 돌려줍니다. 통과한 뒤 **저장**

> [!WARNING]
> `server/data/ai-settings.json`에는 평문 API Key가 담깁니다. 이 파일은 gitignore되어 있지만, 커밋되거나 공유될 만한 위치로 복사하는 일은 피하세요.

## AI 콘솔 {#ai-콘솔}

상단 바의 **✨ 버튼**으로 여는 전역 플로팅 창이 모든 AI 작업의 실행 현장입니다.

![AI 콘솔](/assets/guide/ai-console.png)

두 가지 형태:

- **작업 형태** — 각 기능 페이지에서 촉발된 AI 동작(윤문, 이어쓰기, 초안 작성…)이 여기서 실행됩니다. 「작업」 배지가 붙은 지시문 항목, 모델의 **사고 과정**(접기 가능), 본문의 스트리밍 출력, 소요 시간과 사용 모델 표시
- **대화 형태** — 작업이 끝난 뒤 입력 상자에서 바로 후속 질문(맥락을 실고 원고를 계속 다듬기)하거나, 순수하게 잡담하듯 질문합니다. Enter 전송, Shift+Enter 줄 바꿈

공통 기능: **언제든 정지**(정지 후 이미 나온 내용은 상황에 따라 보존 또는 복원), 제목 표시줄 클릭 시 **접기**로 화면 확보, **새 대화**로 비우고 재시작. 다중 턴 대화 기록이 6만 자를 넘기면 가장 오래된 것부터 자동 버리고, 사고 스트림은 최근 8000자를 유지합니다.

## 각 페이지의 AI 진입점

활성화하면 아래 위치에 AI 기능이 나타납니다(페이지별 정리):

| 페이지 | 진입점 | 기능 |
|------|------|------|
| [글 편집](./post-editor.md#ai-글쓰기-지원) | 도구 모음 AI 드롭다운 | 내용 보완 / 서식 정리 / 윤문(선택 우선)/ 이어쓰기 / 요약 생성 / 커스텀 지시문. 전문 개작에는 diff 미리보기 |
| [모먼트](./moments.md#ai-지원-선택) | 발행기 버튼 | 본문 윤문(스트리밍 반영), 태그와 기분 제안 |
| [데이터 관리](./data.md#필드-단위-ai) | 편집 대화상자 ✨ | 프로젝트/스킬/애니메이션 등 설명 필드 생성과 개작 |
| [데이터 관리 · 타임라인](./data.md#타임라인-ai-초안-작성) | AI 초안 작성 버튼 | git 기록 종합 / 설명으로 이벤트 초안, 선택해 삽입 |
| [데이터 관리 · 재생목록](./data.md#재생목록-음악-가져오기) | 음악 가져오기 | 웹에서 곡을 검색하고 저작권 정보를 첨부 |
| [사이트 설정](./settings.md#기본-정보) | 입력란 ✨ | 부제, 서명 한 줄 생성 |
| [사이트 설정 · 배너](./settings.md#배너-배경화면) | AI 문구 생성 | 타이프라이터 롤링 문구 통째로 생성 |
| [콘텐츠 가져오기](./import.md#단일-글-붙여넣기) | 자동 촉발 | 붙여넣은 글의 제목/요약/분류/태그 보완 |
| [커밋과 게시](./publish.md#커밋-메시지) | AI 생성 버튼 | 이중 저장소 커밋 메시지 생성(비준수 시 자동 대체) |

그 밖에 에디터 도구 모음의 AI 메뉴는 생성 중 로딩 애니메이션을 표시하며 중복 촉발을 막습니다. 모든 스트리밍 작업은 하나의 콘솔을 공유해 같은 시점에 하나만 실행됩니다.

## 설계 철학

- **AI가 주 흐름을 절대 막지 않음** — 커밋 메시지 생성 실패 시 휴리스틱으로 자동 대체, 가져오기 메타 정보 실패 시 본문 요약으로 대체, 윤문 정지 즉시 원문 복원
- **결과는 미리보기 후 적용** — 전문 개작형은 모두 diff 확인을 거칩니다. 여러분의 글을 바로 덮어쓰지 않습니다
- **가벼운 작업은 경량 모델** — 태그 제안, 요약 같은 소소한 작업은 `modelFast`로 돌리고 사고를 꺼서 돈과 시간을 절약
