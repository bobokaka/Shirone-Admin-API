# 대시보드와 미리보기

`http://localhost:5173/`을 열었을 때 보이는 첫 페이지가 바로 **대시보드**입니다. 관리 화면 전체의 개요입니다. 게시 대기 중인 변경이 몇 개인지, 글과 모먼트가 몇 개인지, 그리고 블로그의 실제 모습을 실시간 렌더링하는 미리보기 창이 있습니다.

![대시보드](/assets/guide/dashboard.png)

## 네 장의 통계 카드

| 카드 | 수치 의미 | 바로가기 버튼 |
|------|----------|----------|
| **게시 대기 변경 사항** | 콘텐츠 저장소에서 스테이징됨 + 수정됨 + 추적 안 됨 상태인 git 변경 파일의 총 개수 | 「게시하러 가기」→ [커밋과 게시](./publish.md)로 이동 |
| **글 총 개수** | 콘텐츠 저장소의 모든 글(초안 포함) | 「글 관리」→ [글 관리](./posts.md)로 이동 |
| **모먼트 총 개수** | 모든 모먼트(초안 포함) | 「모먼트 관리」→ [모먼트](./moments.md)로 이동 |
| **초안 총 개수** | 글과 모먼트 중 초록으로 표시된 것의 합 | 「이어서 쓰기」→ 글 관리로 이동 |

「게시 대기 변경 사항」은 관리 화면에서 아직 커밋하지 않은 모든 변경의 총합입니다 — 글을 쓰고 모먼트를 올린 뒤 이 숫자가 0이 아니라면 아직 게시하지 않았다는 뜻입니다.

## 최근 콘텐츠

통계 카드 아래의 두 목록 카드는 **최근 글 6편**과 **최근 모먼트 6개**를 보여 줍니다.

- 글 행은 제목과 게시일을 표시하고, 초안은 노란 배지가 붙습니다
- 모먼트 행은 시간, 고정/초안/태그를 표시하고 본문은 첫 세 줄만 발췌하며, 썸네일은 최대 3장(클릭하면 확대 미리보기)
- 오른쪽 위 「더 보기」는 해당 관리 페이지로 이동합니다

## 실제 사이트 미리보기 {#실제-사이트-미리보기}

페이지 하단의 「실제 사이트 미리보기」 카드는 iframe을 내장해 `http://localhost:4321/`을 직접 불러옵니다 — 즉 테마 저장소의 Astro 개발 서버가 렌더링하는 **실제 사이트**입니다. 스크린샷도 단순한 모의 화면도 아니며, 미리보기 결과는 향후 게시될 사이트와 완전히 일치합니다.

### 상태 표시와 조작

미리보기 패널 상단 도구 모음의 왼쪽부터:

- **상태 배지**(3초마다 갱신):
  - 사이트 준비됨 `:4321` — 미리보기 사용 가능
  - dev server가 이미 실행 중임을 감지 `:4321` — 미리보기 사용 가능(프로세스가 이 패널이 시작한 것이 아님)
  - 시작 중, 처음은 컴파일이 필요합니다… — Astro가 콜드 스타트 중이니 잠시 기다리세요
  - 실행 중 아님 — 「미리보기 시작」을 눌러야 합니다
- **미리보기 시작 / 정지** — 관리 화면에서 테마 저장소의 `content:watch` + `astro dev` 프로세스를 띄우거나 종료
- **새 창에서 열기** — 브라우저 탭을 열어 `:4321`에 직접 접속

대시보드의 미리보기 패널은 방해를 피하기 위해 프로세스를 자동으로 띄우지 않으며, 「미리보기 시작」을 직접 눌러야 합니다. `node workspace/content-watch.mjs`로 원클릭 시작했다면 dev server가 이미 실행 중이므로 패널이 바로 준비됨을 표시합니다.

### 미리보기가 「실제」인 이유

[3저장소 작업 공간](./workspace.md)에서 데이터 흐름을 소개했습니다. 관리 화면 저장 → 콘텐츠 저장소에 기록 → `content:watch`가 테마 저장소로 물화 → Astro 재컴파일. 따라서 관리 화면에서 문구 하나를 고쳐 저장하면 몇 초 뒤 미리보기의 블로그가 갱신됩니다 — **보이는 것이 곧 게시될 실제 사이트입니다**.

## 상단 바와 전역 진입점

모든 페이지가 공유하는 상단 바:

- **페이지 제목** — 현재 있는 기능 페이지의 이름
- **연결 상태 배지** — 콘텐츠 저장소 「연결됨 / 연결 안 됨」([3저장소 작업 공간 · 연결 상태 확인 방법](./workspace.md#연결-상태-확인-방법) 참고)
- **✨ 버튼** — 전역 [AI 콘솔](./ai.md#ai-콘솔) 열기
- **톱니바퀴 버튼** — 「설정」 대화상자 열기([AI 프로바이더 설정](./ai.md#프로바이더-설정) 및 정보 페이지)
