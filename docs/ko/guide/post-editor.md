# 글 편집

글 에디터는 관리 화면에서 기능이 가장 밀집한 페이지입니다. [글 관리](./posts.md)에서 새 글을 만들거나 「편집」을 누르면 진입하며, 완전한 편집 페이지에는 **좌우 분할 실시간 미리보기**가 딸려 있습니다. 글 관리 페이지 안의 그 자리 편집은 같은 에디터의 단일 칸 형태입니다.

![글 편집](/assets/guide/post-editor.png)

## 상단 바 조작

왼쪽부터:

| 버튼 | 역할 |
|------|------|
| 뒤로 | 자동 저장 후 이전 페이지로 돌아갑니다 |
| 제목 입력란 | 항상 표시되는 큰 입력란으로, 언제든 이름을 바꿀 수 있습니다 |
| 글 정보 | 메타 정보 드로어를 엽니다(아래 참고) |
| 삭제 | 글과 해당 디렉터리의 모든 첨부 이미지를 삭제합니다. 이중 확인이 필요합니다 |
| 저장 | 즉시 콘텐츠 저장소에 기록합니다 |
| 저장하고 게시하러 가기 | 저장 후 바로 [커밋과 게시](./publish.md)로 이동합니다 |

상단 바에는 「HH:mm:ss에 자동 저장됨」이라며 최근 자동 저장 시각도 표시됩니다.

## 에디터

에디터는 **Markdown 소스 모드**입니다(md-editor-v3 + CodeMirror 기반). Markdown 소스를 직접 쓰면 오른쪽 분할 화면이 실시간으로 미리보기를 렌더링합니다. 도구 모음은 자주 쓰는 서식을 제공합니다. 굵게, 기울임, 취소선, 제목, 인용, 목록, 작업 목록, 인라인 코드, 코드 블록, 링크, 이미지, 표, 실행 취소/다시 실행, 미리보기/목차 전환까지.

**첨부 이미지 걱정 없음**: 에디터에 스크린샷을 붙여넣거나 이미지 버튼으로 업로드하면 파일이 현재 글 디렉터리의 `images/` 하위 디렉터리에 자동 저장되고, 본문에는 상대 참조(`./images/xxx.webp`)가 자동 삽입됩니다. 글이 그래서 자기 완결적이 됩니다 — 디렉터리 전체를 통째로 옮기면 한 편의 완전한 글입니다.

AI가 활성화되면 도구 모음 끝에 **AI 드롭다운 도구**가 하나 더 나타납니다. 아래 [AI 글쓰기 지원](#ai-글쓰기-지원) 참고.

## 글 정보 드로어

「글 정보」 드로어는 모든 메타데이터를 수용합니다(글 frontmatter에 대응).

### 기본 필드

- **게시 날짜**(`YYYY-MM-DD`)와 **정확한 시각** — 같은 날 여러 글을 게시할 때 순서를 제어합니다. 시간대는 자동으로 `+08:00` 기준으로 정규화됩니다
- **분류** — 드롭다운으로 기존 분류 선택(사용 횟수 표시). 새 이름을 직접 입력하고 Enter를 누르면 바로 생성됩니다
- **태그** — 여러 개 선택 가능하며, 역시 입력 생성을 지원합니다
- **요약** — 비워 두면 테마가 본문 앞부분을 자동 발췌합니다. 표지 이미지는 로컬 업로드 또는 외부 링크를 지원합니다
- **스위치** — 초안 / 고정 / 댓글 / 암호화

### 암호화 글

「암호화」를 선택하면 세 필드가 펼쳐집니다.

- **접근 암호** — 이미 설정된 글은 입력하면 수정, 비워 두면 유지됩니다. 「암호화」 선택을 해제하면 암호가 삭제됩니다
- **암호 힌트** — 방문자가 암호를 입력하기 전에 보는 안내 문구
- **홈 카드 미리보기 숨김** — 암호화된 내용이 요약 형태로 홈에 새어 나가는 것을 막습니다

### 접근 경로

세 가지 모드가 글의 최종 URL을 결정하며, 하단에 실시간 주소 미리보기가 있습니다.

| 모드 | 주소 형태 | 적합한 상황 |
|------|----------|----------|
| 기본 | `/posts/<글명>/` | 일반적인 글 |
| 커스텀 별명 | `/posts/<별명>/` | 더 짧고 의미 있는 URL을 원할 때 |
| 루트 경로 퍼머링크 | `/<커스텀 경로>/` | 정성 들여 만든 대표 페이지. 예: `/about-me/` |

## AI 글쓰기 지원 {#ai-글쓰기-지원}

> [!NOTE]
> 아래 기능은 먼저 AI 어시스턴트를 활성화해야 합니다([설정 방법](./ai.md#프로바이더-설정)). 비활성화 시 도구 모음에 AI 진입점이 나타나지 않으며, 집필 기능에는 영향이 없습니다.

AI 드롭다운 도구에는 5가지 동작 + 커스텀 지시문이 내장되어 있습니다. 모든 동작은 **코드와 Shirone 테마 전용 확장 문법**(삼중 콜론 컨테이너, file-tree 등)을 그대로 보존합니다.

| 동작 | 적용 범위 | 결과 적용 방식 |
|------|----------|--------------|
| AI 내용 보완 | 전문 | 논거의 빈틈을 채우고 논리적 연결을 강화 — 미리보기 후 적용 |
| AI 서식 정리 | 전문 | 제목 수준 정규화, 문장 부호 통일, 코드 펜스 언어 보완 — 미리보기 후 적용 |
| AI 윤문 | **선택 우선** | 선택한 텍스트가 있으면 바로 교체, 없으면 전문 diff 미리보기로 진행 |
| AI 이어쓰기 | 글 끝 | 끝부분에서 자연스럽게 이어 받아 결과를 본문 끝에 추가 |
| AI 요약 생성 | 전문 | 80–160자 요약을 생성해 「글 정보」에 반영합니다(기존 요약이 있으면 먼저 확인) |
| 커스텀 지시문 | 선택 또는 전문 | 임의 지시문(예: 「더 구어체로 바꿔 줘」)을 입력하고 실행 |

**diff 미리보기**는 전문 개작형 동작(보완/서식 정리/선택 없는 윤문/커스텀 지시문)의 안전망입니다. AI 결과가 좌우 대조 차이 뷰로 스트리밍 갱신되고, 변경되지 않은 긴 구간은 자동 접힙니다. 「이전/다음」으로 구간별 이동도 가능합니다. 확인 후 「적용」을 눌러야 실제로 본문이 다시 쓰입니다. 생성이 중단된 내용은 불완전하므로 적용할 수 없습니다. 본문 길이가 20% 이상 변하면 미리보기 창에 빨간 경고가 떠 꼼꼼한 확인을 재촉합니다.

모든 AI 동작은 전역 [AI 콘솔](./ai.md#ai-콘솔)에서 실행됩니다. 사고 과정이 보이고 언제든 멈출 수 있습니다.

## 자동 저장 {#자동-저장}

에디터에는 방해하지 않는 자동 저장 메커니즘이 있습니다.

- **10초마다** 확인하며, 제목이나 본문에 변경이 있을 때만 조용히 기록합니다
- **글 전환, 뒤로 가기 클릭, 편집 페이지를 벗어나는** 순간에도 먼저 자동 저장됩니다
- 유일하게 사용자를 막는 경우: 제목이 비어 있으면(기록 불가) 먼저 제목을 채우라는 안내가 뜹니다

자동 저장은 제목과 본문만 담당합니다. 「글 정보」 드로어의 메타데이터는 「저장」 버튼으로 기록됩니다.
