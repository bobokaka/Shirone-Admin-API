# 콘텐츠 가져오기

다른 플랫폼에서 글을 쓰고 계셨나요? 「콘텐츠 가져오기」 페이지가 이전 통로를 제공합니다. 현재 **젠수(简书)**를 지원하며, 페이지 상단은 플랫폼별 탭으로 나뉘고 이후 플랫폼도 이렇게 확장됩니다.

가져오기 경로는 두 가지입니다. 페이지에 들어서면 먼저 하나를 고릅니다.

| 방식 | 적합한 경우 | 입력 |
|------|------|------|
| **내보내기 패키지 가져오기** | 사이트 전체 이전, 수십~수백 편 | 젠수 공식 「전체 글 패키지 다운로드」로 받은 rar / zip |
| **단일 글 붙여넣기** | 엄선한 한 편, 붙이는 즉시 변환 | 웹 버전 글 페이지에서 전체 복사한 내용 |

![콘텐츠 가져오기](/assets/guide/import.png)

## 내보내기 패키지 가져오기

5단계 마법사: **방식 선택 → 내보내기 패키지 업로드 → 글 선택 → 내용 변환 → 가져오기 완료**.

### 1단계: 내보내기 패키지 업로드

젠수의 「설정 → 계정 관리 → 전체 글 패키지 다운로드」에서 내보내기를 신청하고(젠수가 다운로드 링크를 이메일로 보냅니다) 압축 파일을 받아 업로드 영역에 끌어다 놓습니다. 제한: zip / rar 형식, 패키지당 ≤30MB.

업로드되면 서버가 메모리에서 압축을 풀어 파싱하고, **문집** 단위로 묶어 전체 글을 나열합니다.

### 2단계: 글 선택

- 파싱 성공 후 아직 가져오지 않은 글이 **기본 전체 선택**됩니다
- 문집 단위 그룹 선택, 전체 선택/해제 지원
- 이미 가져온 글은 「가져옴」 표시와 함께 선택 불가로 잠겨 중복을 막습니다
- 각 글은 먼저 「미리보기」할 수 있습니다 — 디스크에 기록하지 않고 변환된 Markdown 결과를 봅니다

페이지 오른쪽에서 가져오기 옵션을 설정합니다.

| 옵션 | 설명 |
|------|------|
| 게시 날짜 통일 | 젠수 내보내기 패키지에는 날짜가 없어 모든 글에 같은 게시일을 적용합니다(이후 글마다 변경 가능) |
| 문집을 분류로 | 선택하면 각 문집 이름이 그대로 글 분류가 됩니다. 선택하지 않으면 하나의 통일 분류를 직접 지정합니다 |
| 태그 | 이번 배치 글에 통일 태그를 추가합니다 |
| 이미지 로컬화 | 젠수 CDN 이미지를 각 글의 `images/` 디렉터리로 내려받습니다. 실패한 것은 원격 링크 유지 |
| 초안으로 가져오기 | **선택 유지 권장** — 먼저 [글 관리](./posts.md)에서 훑어본 뒤 게시하세요 |

### 3단계: 내용 변환

시작을 누르면 서버가 **백그라운드 작업**을 만들어 글마다 변환하며, 페이지는 2초마다 진행 상황을 확인합니다. 총수, 완료 수, 현재 처리 중인 글 제목. 도중에 페이지를 떠나도 작업은 계속됩니다.

### 4단계: 완료

작업이 끝나면 결과 목록이 표시됩니다. 글마다 성공 여부, 저장소 반영 경로, 로컬화된 이미지 수. 실패한 글은 원인이 제시됩니다(한 편 실패는 다른 글에 영향 없음). 「다음 패키지 가져오기」로 계속하거나 글 관리로 이동해 결과를 확인할 수 있습니다.

## 단일 글 붙여넣기 {#단일-글-붙여넣기}

5단계 마법사: **방식 선택 → 내용 붙여넣기 → 내용 변환 → 글 정보 → 가져오기 완료**.

1. **붙여넣기** — 젠수 웹 버전에서 글을 열고 전체 복사해 에디터에 바로 `Ctrl+V`로 붙여넣습니다. 리치 텍스트가 자동으로 Markdown으로 변환되고(제목, 굵게, 링크, 이미지 모두 보존) 왼쪽 소스·오른쪽 미리보기에서 계속 수동 수정할 수 있습니다
2. **내용 변환** — 확인하면 서버가 저장소에 기록합니다. 이미지는 글 디렉터리로 자동 다운로드되고(실패한 것은 원격 링크 유지) 디렉터리 방식 글이 생성됩니다
3. **글 정보** — AI가 본문을 분석해 **자동 보완**합니다. 제목(비워 두면 AI가 짓습니다), 요약, 분류, 태그 제안. 전부 수동 수정 가능합니다. AI를 쓸 수 없을 때는 본문 요약 발췌로 대체되며 `aiUsed=false`가 명시됩니다
4. **확정** — 메타 정보를 글에 반영하고 완료. [글 편집](./post-editor.md)으로 한 번에 넘어가 마무리 손질을 할 수 있습니다

> [!TIP]
> 제목 입력란도 붙여넣기 대체 처리를 지원합니다. 클립보드에 리치 텍스트만 있을 때(웹에서 복사할 때 흔함) 일반 텍스트를 자동 추출해 한 줄로 압축합니다.

## 세션과 작업에 대해

- 내보내기 패키지 업로드 후 **세션**이 하나 만들어집니다(파싱 결과는 서버 메모리에 캐시). 유효 기간 24시간, 최대 3개 동시 유지이며 시간 초과/초과 시 가장 오래된 것부터 자동 퇴출됩니다 — 「다른 패키지로」를 누르면 현재 세션을 즉시 버릴 수 있습니다
- 백그라운드 가져오기 작업 결과는 1시간 보관됩니다
- 서버 재시작 시 메모리 세션과 작업은 비워지며, 내보내기 패키지만 다시 올리면 됩니다. **이미 가져온 글은 영향 없습니다**(이미 콘텐츠 저장소에 반영되어 있으니까요)
