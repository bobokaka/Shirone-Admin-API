# 모먼트

「모먼트」는 글보다 가벼운 콘텐츠 형태입니다. 짧은 생각 몇 마디, 사진 몇 장, 기분 아이콘 하나. 발행기는 페이지 위쪽에, 모먼트 스트림은 아래에 있어 쓰는 대로 바로 올립니다.

![모먼트](/assets/guide/moments.png)

## 모먼트 하나 게시하기

발행기 카드를 위에서부터:

1. **본문** — 여러 줄 텍스트 상자. 지금 떠오른 생각
2. **이미지 영역** — 최대 **9장**. + 를 눌러 선택하거나 그냥 붙여넣어 업로드
3. **메타 정보 행** — 기분 / 장소 / 태그 / 게시 시간 / 고정
4. **조작 행** — AI 윤문(AI 활성화 시)/ 초안 저장 / 모먼트 게시

### 기분 아이콘

아홉 개의 기본 기분 중 선택할 수 있습니다. 😊 즐거움, 🤩 신남, 😐 평온, 😔 침체, 😢 슬픔, ❤️ 좋아함, 🎉 축하, ☕ 한 잔, 🌙 굿나잇. 아이콘은 Iconify 이름으로 저장되며(전부 로컬 내장, 네트워크 요청 없음), 프론트에서 해당 아이콘으로 렌더링됩니다.

### 이미지는 어떻게 보관되나

한 번에 게시되는 모든 이미지는 **같은 배치 디렉터리**에 들어갑니다.

```
public/images/moments/<yyyymmdd-HHmmss>/   # 배치 번호는 모먼트 파일명과 동일
├── 1.webp
└── 2.webp
```

여러 장을 동시에 업로드해도 같은 배치로 분류됩니다(배치 번호는 미리 생성). 이 디렉터리 규칙은 임의로 정해진 것이 아닙니다 — 테마의 썸네일 생성 파이프라인이 `public/images/moments/`만 스캔하기 때문입니다. 모먼트 이미지를 다른 곳에 두면 프론트에서 썸네일을 만들 수 없어, 백엔드가 저장 위치를 강제합니다.

> [!TIP]
> 게시 전에 어떤 이미지를 제거하는 것은 이번 게시에서 빼는 것뿐이며 파일은 저장소에 남습니다. 모먼트 전체를 삭제할 때도 첨부 이미지 파일은 유지되므로, 정리가 필요하면 수동으로 처리하세요.

### AI 지원(선택) {#ai-지원-선택}

AI가 활성화되면 발행기에 진입점이 두 개 늘어납니다.

- **AI 윤문** — 본문을 스트리밍으로 다시 썰며, 결과가 입력 상자 안에서 그대로 자라납니다(구어체답고 자연스럽게, 어투와 사실 유지). 언제든 멈출 수 있고 멈추면 원문이 복원됩니다
- **AI 제안** — 본문에서 2–4개 태그를 추출해(기존 태그와 병합·중복 제거) 기분을 추측합니다(이미 선택되어 있으면 덮어쓰지 않음)

## 모먼트 스트림 관리

아래 목록은 조합 필터와 페이지 매김(페이지당 8개)을 지원합니다.

| 필터 | 설명 |
|------|------|
| 검색 상자 | 본문, 장소, 태그 매칭 |
| 상태 드롭다운 | 전체 / 게시됨 / 초안 |
| 태그 다중 선택 | 카드의 태그를 눌러도 빠르게 필터링됩니다(다시 누르면 해제) |
| 고정만 보기 | 확인란 |

각 모먼트 카드가 제공하는 것:

- **편집** — 내용이 위 발행기로 다시 채워집니다(새로 업로드하는 이미지는 **새 배치**로 들어가고 옛 디렉터리에 섞이지 않음). 고친 뒤 「모먼트 게시」를 누르면 저장됩니다
- **고정 전환** — 원클릭으로 고정/해제하며 목록이 즉시 갱신됩니다
- **삭제** — 이중 확인 후 `.md` 파일을 제거합니다(첨부 이미지는 유지)

## 모먼트와 글의 차이

| | 글 | 모먼트 |
|---|------|------|
| 콘텐츠 형태 | 장문 + 메타 정보 체계 | 짧은 텍스트 + 이미지 + 기분 |
| 저장 | `content/posts/<slug>/index.md` | `content/moments/<yyyymmdd-HHmmss>.md` |
| 전형적 용도 | 튜토리얼, 노트, 깊이 있는 사고 | 근황, 사소한 생각, 기록 |
