# 구조화 데이터

블로그 「소개」 페이지의 프로젝트, 스킬, 장치 목록, 사이드바의 애니메이션 시청 목록, 링크, 배경 재생목록 — 이런 것들이 모두 **구조화 데이터**입니다. 각 종류는 콘텐츠 저장소 `data/*.ts`의 TypeScript 배열 하나입니다. 「데이터 관리」 페이지는 이 전부를 표 + 폼으로 시각화해 편집할 수 있게 하며, 변경은 **즉시 저장소에 반영**됩니다.

![데이터 관리](/assets/guide/data.png)

## 여덟 가지 데이터 유형 {#여덟-가지-데이터-유형}

| 탭 | 항목 | 대표 필드 |
|------|------|----------|
| 프로젝트 | 프로젝트 | 이름, 소개, 분류, 단계(공개됨/개발 중/탐색 중), 기술 스택, 추천 |
| 스킬 | 스킬 | 이름, 분류(프론트엔드/백엔드/도구/게임 개발), 수준(입문→전문가), 아이콘 |
| 타임라인 | 이벤트 | 제목, 날짜, 분류(마일스톤/프로젝트/경험/생활), 요점, 관련 링크 |
| 장치 | 장치 | 이름, 브랜드, 분류, 상태(사용 중/예비/퇴역/구매 희망), 사양 |
| 애니메이션 | 애니메이션 | 제목, 상태(시청 중/시청 완료/예정/보류/하차), 평점, 진행도, 장르, 표지 |
| 나침반 | 책장 | 이름, 아이콘, 내비게이션 항목(이름 + 링크 + 메모) |
| 재생목록 | 곡 | 곡명, 아티스트, 표지, 오디오 주소, 길이 |
| 링크 | 링크 | 사이트 이름, 아바타, 설명, 주소, 태그 |

## 공통 조작

- **추가** — 편집 대화상자를 열어 필드별로 입력. 필수 항목이 빠지면 저지하고 안내합니다
- **표 안에서 바로 전환** — 「추천」「활성」 같은 불리언 필드는 표에서 스위치 그 자체입니다. 넘기면 곧바로 저장됩니다
- **정렬** — 각 행 오른쪽의 ↑↓ 버튼으로 순서 조정(배열 순서가 곧 프론트 표시 순서). 즉시 반영됩니다
- **편집 / 삭제** — 편집은 대화상자를 열어 전체 필드를 다시 채웁니다. 삭제는 이중 확인이 필요합니다

수고를 덜어 주는 디테일 몇 가지:

- **식별 필드 자동 생성** — 프로젝트 key, 장치 id, 곡 id 같은 식별 열은 직접 채우지 않아도 됩니다. 추가 시 제목이 자동으로 병음 slug로 변환되고(중복이면 번호 추가), 링크 id는 최댓값 +1
- **아이콘 필드** — Iconify 아이콘 이름(예: `simple-icons:typescript`)을 입력하면 즉시 미리보기. 아이콘은 전부 로컬 내장이며 네트워크 요청을 보내지 않습니다
- **이미지 필드** — 표지는 로컬 업로드(데이터 종류에 따라 대응하는 리소스 디렉터리에 자동 저장) 또는 경로 붙여넣기를 지원합니다. 애니메이션/재생목록에는 전용 원클릭 가져오기가 있으며 아래에서 소개합니다
- **나침반과 타임라인의 항목 목록** — 「내비게이션 항목」「관련 링크」 같은 중첩 배열은 시각화 카드로 편집합니다. 각 하위 항목의 이름/아이콘/주소를 한 줄에 채우며 필수 검증을 지원합니다

모든 변경은 **직렬 저장 큐**를 거쳐 `data/*.ts`에 다시 기록됩니다 — 파일의 interface 정의, 주석, export 문은 글자 그대로 보존되고 배열 리터럴 부분만 교체되어, 손으로 관리해 온 코드가 건드려지지 않습니다.

## 애니메이션: 검색 가져오기

애니메이션 탭 전용 「**검색 가져오기**」 버튼. 데이터는 [Bangumi(番组计划)](https://bgm.tv/) 공개 API에서 옵니다.

![애니메이션 검색 가져오기](/assets/guide/data-anime.png)

1. **검색** — 중국어/일본어/영어 제목을 입력하면 후보 목록이 반환됩니다(연도, 화수, 평점, 표지 포함)
2. **항목 선택** — 세부 정보를 자동으로 가져와 채웁니다. 제작사, 방영 시기, 빈도 높은 장르 태그
3. **확인** — 새 애니메이션 초안 한 줄이 생성됩니다. 제목/연도/장르/소개/표지/제작이 이미 채워져 있고 **상태와 평점만 여러분이 정하면** 됩니다. 표지 이미지는 Bangumi 공식 이미지 서버에서 내려받아 `public/assets/anime/`에 반영됩니다

시청 기록에 이제 메타데이터를 손으로 입력할 필요가 없습니다. 한 편 다 보면 검색해서 한 줄 추가하면 끝.

## 재생목록: 음악 가져오기 {#재생목록-음악-가져오기}

재생목록 탭의 「**음악 가져오기**」는 세 가지 입수 방법을 제공합니다.

- **AI 검색** — 찾고 싶은 노래를 설명하면(곡명/장르) AI가 웹을 검색하고 **저작권 정보**(무료 상업적 이용 가능 여부, 판단 근거 링크)를 덧붙입니다. 확인하면 오디오와 표지가 자동으로 저장소에 반영됩니다
- **직접 링크 가져오기** — 오디오 직접 링크를 붙여넣으면 서버가 대신 내려받습니다(브라우저의 크로스 도메인 제한으로 못 받는 것도 받을 수 있음)
- **로컬 업로드** — 오디오 파일을 바로 업로드

가져온 뒤에는 표에서 **▶ 미리듣기**를 누르면 하단 재생 바에서 골라 들을 수 있습니다. 마음에 들면 저장하세요.

## 타임라인: AI 초안 작성 {#타임라인-ai-초안-작성}

타임라인 탭의 「**AI 초안 작성**」 버튼(AI 활성화 시 나타남)은 두 가지 모드로 이벤트 초안을 일괄 생성합니다.

- **git 모드** — 세 저장소의 커밋 기록을 스캔해(저장소당 최대 30건, 파일 증감 통계 포함) AI가 타임라인 이벤트로 종합합니다. 「이번 달에 내가 뭘 했지」 복기에 적합
- **설명 모드** — 한 문장으로 설명을 쓰면 AI가 규격에 맞는 이벤트로 초안을 작성합니다(제목/날짜/분류/요점/태그)

생성된 초안 목록은 **한 줄씩 선택**할 수 있고, 이미 수록된 이벤트는 자동 중복 제거됩니다(제목 + 날짜 비교). 삽입을 확정하면 날짜로 올바른 위치를 찾아 목록에 끼워 넣고 저장소에 반영하며, 날짜 형식은 사이트가 쓰는 점 구분 스타일로 자동 변환됩니다(`2025.06.01`).

## 필드 단위 AI {#필드-단위-ai}

소개, 설명 같은 긴 텍스트 필드(프로젝트 소개, 스킬 설명, 애니메이션 설명, 링크 설명, 타임라인 설명, 장치 설명)는 편집 대화상자 오른쪽 위에 **✨ 버튼**이 있습니다. 항목 제목을 채운 뒤 누르면 AI가 1–3문장으로 해당 필드를 생성하거나 다시 쓰며, 결과는 스트리밍으로 입력 상자 안에서 바로 자라납니다. 멈출 수 있고 수동 수정도 가능합니다.
