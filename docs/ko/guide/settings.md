# 사이트 설정

「사이트 설정」 페이지는 테마의 모든 설정 항목을 폼으로 만듭니다. 왼쪽에는 섹션별 폼, 오른쪽에는 내장 [실제 사이트 미리보기](./dashboard.md#실제-사이트-미리보기). 수정하고 저장하면 미리보기가 갱신되어, 보이는 것이 얻는 것입니다.

페이지는 다섯 개의 탭으로 나뉩니다. **기본 정보**, **내비게이션**, **푸터**, **테마 외형**, **배너 배경화면**.

![사이트 설정 · 기본 정보](/assets/guide/settings.png)

## 기본 정보 {#기본-정보}

일곱 개의 섹션이 각자 독립적으로 저장됩니다.

| 섹션 | 설정 내용 |
|------|----------|
| 사이트 정보 | 사이트 이름, 부제(부제에는 AI ✨ 한 줄 생성이 붙음) |
| 개인 프로필 | 아바타(온라인 URL 또는 로컬 업로드, 자동으로 이름을 바꿔 저장소에 반영), 닉네임, 서명(역시 AI ✨ 포함) |
| 소셜 링크 | GitHub / 빌리빌리 등 외부 링크 목록: 이름, Iconify 아이콘, 주소 |
| 사이트 아이콘 favicon | 라이트 / 다크 두 슬롯. 커스텀하지 않았을 때는 테마 기본 아이콘의 현재 적용 안내가 표시됩니다. 업로드 시 `favicon-light/dark.<ext>`로 자동 명명되어 그 자리를 대체하며, 온라인 주소를 직접 입력해도 됩니다 |
| 일반 설정 | 사이트 주소(배포 후의 최종 도메인), 하위 경로(루트 배포는 `/`), 시간대(자주 쓰는 시간대 드롭다운, 직접 입력 가능) |
| 방문자 표시 패널 | 프론트에서 방문자에게 개방하는 표시 스위치 제어: 색조 선택기, 색상 사양 전환, 배경 모드, 목록 레이아웃, 동작 축소, 배경 텍스처 |
| 국제화 | 다국어 개방 여부: 개방할 언어 집합을 선택하며 사이트 주 언어는 반드시 집합 안에 포함되어야 합니다. 끄면 사이트 전체가 중국어 간체로 고정됩니다 |

## 내비게이션

시각적인 내비게이션 메뉴 편집기입니다.

- **테마 프리셋** — 15개 내장 프리셋(홈, 아카이브, 링크 등)에서 골라 한 번에 연결
- **커스텀 링크** — 이름 + 아이콘 + 주소. 「새 창에서 열기」 표시 가능
- **드롭다운 그룹** — 2단계 메뉴를 끌어내어 같은 종류의 진입점을 수용

내비게이션 설정은 통째로 저장되며, 배열의 의미는 **전체 교체**입니다.

## 푸터

- **활성 스위치** — 커스텀 푸터 내용을 테마 저작권 줄 위에 삽입할지 제어
- **HTML 편집기** — CodeMirror 코드 편집기, **Prettier 포맷** 버튼 동봉. 푸터 HTML 원문은 콘텐츠 저장소 `config/footer.html`에 저장됩니다
- **푸터 이미지 라이브러리** — 이미지 업로드 또는 온라인 직접 링크 붙여넣기(서버가 대신 내려받고, webp는 자동으로 png/jpg로 변환) 후 `public/images/footer/`에 반영. 「경로 복사」로 꺼내 HTML에 붙여넣습니다
- **실시간 미리보기** — iframe으로 테마 푸터 렌더링을 유사하게 재현. 저작권 줄 + 여러분의 커스텀 내용

## 테마 외형

![사이트 설정 · 테마 외형](/assets/guide/settings-appearance.png)

두 개의 섹션:

### 테마 색상

- **색조 슬라이더**(0–360) — 해당 색조로 생성되는 5단계 팔레트를 실시간 표시
- **고정** — 선택하면 사이트 색조가 콘텐츠/방문자 선호를 따라 변하지 않습니다
- **색상 스타일** — Material 3의 9가지 동적 색상 추출 스타일: tonalSpot(클래식 부드러움), vibrant(선명), content(콘텐츠 색에서 추출), expressive, rainbow, fruitSalad, monochrome, neutral, fidelity
- **색상 사양** — Material 3의 2021 / 2025 두 세대 사양

### 배경화면과 텍스처

- **기본 배경 모드** — banner / none 둘 중 하나. 배경화면을 선택하지 않았을 때 프론트의 기본 형태를 결정
- **배경 텍스처** — 여섯 가지 프리셋: none, starlight(별빛), cyber-dots(사이버 도트), topography(등고선), geometric(기하), sakura(벚꽃). 불투명도 0.05–0.25, 동작 효과 허용 스위치

## 배너 배경화면 {#배너-배경화면}

홈 배너의 완전한 제어:

- **데스크톱 배경화면 / 모바일 배경화면** 두 목록 — 로컬 업로드, 온라인 직접 링크 가져오기(서버 대신 다운로드), **AI 배경화면 추천** 버튼(safebooru 이미지 소스에서 크기별로 걸러 한 배치를 가져옵니다. 데스크톱 ≥1920 가로 이미지, 모바일 ≥1920 세로 이미지. 선택해 다운로드하고 저장소에 반영)
- **표시 제어** — 위치(top/center/bottom), 마스크(스위치 + 불투명도)
- **홈 문구** — 제목, 여러 줄 부제, 타이프라이터 효과(속도/삭제 속도/머무는 시간/반복). 부제는 **AI 생성**을 눌러 사이트 이름과 서명을 바탕으로 4–6문장 롤링 문구를 한 번에 만들 수 있습니다
- **롤링** — 배경화면이 여러 장일 때 활성화. 전환 간격, 페이드 시간, 여섯 가지 전환 애니메이션(ken-burns 느린 줌, zoom-in/out, pan-left/right, none)
- **물결 장식** — 배너 하단 물결 동작 스위치

> [!TIP]
> 배너를 저장할 때 데스크톱/모바일 어느 쪽에서도 더 이상 참조되지 않는 로컬 배경화면 파일은 **자동 정리**됩니다. 수동으로 지울 필요가 없습니다.

## 설정은 어디에 기록되나

모든 설정은 콘텐츠 저장소 `config/*.yaml`에 기록되며 **최소 덮어쓰기** 원칙을 따릅니다. 바꾼 키만 쓰고, 선언하지 않은 필드는 테마 기본값을 상속합니다 — 테마 업그레이드로 설정 항목이 늘어나도 사이트가 자동으로 따라가며, 「전체 스냅샷」 하나 때문에 구버전에 갇히는 일이 없습니다. 딕셔너리 키는 재귀 병합되고, 배열은 통째로 교체됩니다.
