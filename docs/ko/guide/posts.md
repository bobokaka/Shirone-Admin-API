# 글 관리

「글 관리」 페이지는 글을 다루는 주 진입점입니다. 전체 글 탐색, 분류·태그 필터링, 본문 빠른 미리보기, 분류 체계 일괄 정리까지 가능합니다.

![글 관리](/assets/guide/posts.png)

페이지는 좌우 두 칸으로 나뉩니다. **왼쪽 글 목록**(필터 + 선택), **오른쪽 내용 미리보기**(읽기 또는 그 자리에서 편집). 왼쪽에서 아무 글이나 클릭하면 오른쪽에 즉시 Markdown 본문이 렌더링됩니다.

## 새 글 만들기

도구 모음의 「**새 글 만들기**」를 누르고 대화상자에 제목을 입력하면(만든 뒤 언제든 변경 가능), 확인 시:

1. 백엔드가 콘텐츠 저장소 `content/posts/` 아래에 **초안 상태**의 글을 생성합니다
2. 자동으로 [글 편집](./post-editor.md) 페이지로 이동해 집필을 시작합니다

글 제목은 병음 전사를 거쳐 URL 친화적인 디렉터리 이름(slug)이 됩니다. 예를 들어 《快速上手指南》→ `kuai-su-shang-shou-zhi-nan/index.md`. 중복되면 자동으로 번호가 붙습니다.

## 탐색과 필터

도구 모음에는 조합해 쓸 수 있는 세 개의 필터가 있습니다.

| 필터 | 동작 |
|--------|------|
| 검색 상자 | **제목, 분류, 태그**를 동시에 매칭(대소문자 구분 없음) |
| 분류 드롭다운 | 해당 분류의 글만 표시. 옵션 뒤 괄호는 해당 분류의 글 수 |
| 태그 드롭다운 | 해당 태그를 포함한 글만 표시 |

목록 머리에는 「글(필터 후 / 전체)」가 실시간 표시됩니다. 각 글 행은 제목, 게시일, 분류와 상태 배지를 보여 줍니다. 노란 「초안」, 「고정」, 빨간 「암호화」.

## 미리보기와 그 자리에서 편집

글을 선택하면 오른쪽에 다음이 표시됩니다.

- **제목과 메타 정보**: 날짜, 분류, 태그, 초안/고정/암호화 배지
- **본문 렌더링**: Markdown 실시간 렌더링. 글 디렉터리 안의 첨부 이미지(`./images/…` 상대 참조)도 바로 표시됩니다
- **편집** 버튼: 오른쪽 칸이 그 자리에서 완전한 에디터로 전환됩니다([글 편집](./post-editor.md) 페이지와 같은 인터페이스, 분할 미리보기만 없음). 에디터 오른쪽 위의 「분할 편집」 아이콘으로 좌우 분할 미리보기가 있는 완전한 편집 페이지로 이동할 수 있으며, 돌아올 때 이 글의 편집 상태가 자동 복원됩니다
- **삭제** 버튼: 디렉터리 방식 글은 「이 글과 해당 디렉터리의 모든 첨부 이미지를 삭제합니다」라고 안내합니다. git에 커밋된 이력이 있다면 기록에서 복구할 수 있습니다

> [!TIP]
> 그 자리 편집 상태에서 왼쪽의 글을 전환할 때 저장하지 않은 변경이 있으면 **먼저 조용히 자동 저장**한 뒤 전환하므로 원고를 잃지 않습니다([글 편집 · 자동 저장](./post-editor.md#자동-저장) 참고).

## 분류 / 태그 관리 {#분류-태그-관리}

도구 모음 오른쪽의 「**분류 관리**」는 일괄 정리 대화상자를 엽니다. 사이트 전체 분류 체계를 관리하는 유일한 곳입니다.

- 상단의 분류 / 태그 두 탭. 목록은 **사용 글 수 내림차순**으로 정렬됩니다
- **이름 변경 / 병합**: 어떤 분류(또는 태그)의 이름을 새 이름으로 바꿉니다. 새 이름이 이미 존재하면 둘을 **병합**하는 것과 같습니다. 백엔드가 글마다 frontmatter를 다시 쓰되 날짜 형식은 그대로 유지합니다
- **제거**: 모든 글에서 이 분류/태그를 삭제합니다(글 자체는 영향받지 않음)

예를 들어 흩어진 「JS」「JavaScript」를 「JavaScript」로 통일하고 싶다면 「JS」에 이름 변경을 실행하고 `JavaScript`를 입력하세요. 확인 후 관련 글 전부가 자동으로 다시 쓰입니다.

## 글의 디스크 상 형태

저장 형태를 이해하면 백업과 문제 해결이 여유로워집니다.

```
content/posts/
├── hello/                  # 디렉터리 방식(새 글의 기본): 첨부 이미지를 글과 함께 관리
│   ├── index.md
│   └── images/
│       └── cover.webp
└── old-post.md             # 평면형(과거 글 또는 외부 가져오기): 단일 파일
```

- 새로 만드는 글은 모두 **디렉터리 방식**이며, 에디터에서 업로드한 첨부 이미지는 자동으로 이 디렉터리의 `images/` 하위 디렉터리에 들어갑니다
- 목록은 **고정 우선, 게시일 내림차순**으로 정렬됩니다
