# AI 助手

Shirone-Admin 的 AI 能力是**可選增強**：不設定，所有功能照常工作；設定後，寫作、匯入、發布各環節多出一系列智慧輔助。本章先講設定，再講使用。

## 設定服務商

點頂欄**齒輪**打開「設定」對話框，左側選單選「AI助手」。

![AI 服務商設定](/assets/guide/app-settings.png)

### 核心概念

- **多服務商**——可保存多套連線設定（最多 20 套），隨時切換生效的那套。適合同時持有官方 API 與中轉代理、或多模型按需切換的人
- **雙協定**——每套設定二選一：
  - `anthropic`——Anthropic 相容協定（`v1/messages`），適配官方 API 及各家「Anthropic 相容」中轉
  - `openai`——OpenAI 相容協定（`chat/completions`），適配 OpenAI 及絕大多數國產模型 API
- **總開關**——「啟用」關閉時所有 AI 入口隱藏，API 一律拒絕

### 每套設定的欄位

| 欄位 | 說明 |
|------|------|
| 名稱 | 顯示名，如 `Anthropic 官方` / `GLM 中轉` |
| 協定 | anthropic / openai |
| API 位址 | 根位址即可（`https://api.anthropic.com` 或 `https://api.openai.com/v1`），容忍裸根、帶 `/v1`、代理子路徑等寫法 |
| API Key | 僅保存在本機 `server/data/ai-settings.json`，**絕不寫入內容倉**、不會隨發布洩漏 |
| 主模型 | 日常任務用，如 `claude-sonnet-5` / `gpt-4o-mini` / `glm-5.3` |
| 輕量模型 | 摘要、標籤建議等簡單任務用；**留空 = 同主模型**（省一份設定） |
| 連網檢索 | 給支援的服務附加 web 檢索工具；伺服端不支援時自動降級為普通請求 |
| 溫度 | 取樣溫度 0–2，預設 0.7 |
| 超時 | 單次請求超時秒數，5–86400，預設 30 |

### 操作流程

1. 點 + **新增服務商**（預設名「預設設定 N」，直接輸入即改名）
2. 填寫欄位，或用**貼上匯入**：把 Claude Code 的 `settings.json` env 區塊、shell `export` 語句或 dotenv 內容整段貼進去，自動識別 `ANTHROPIC_*` / `OPENAI_*` 等 10 個鍵填表
3. **測試連線**——無需儲存即可測，返回延遲與模型應答；通過後再**儲存**

> [!WARNING]
> `server/data/ai-settings.json` 裡是明文 API Key。該檔案已被 gitignore，但請避免把它拷貝到任何會被提交或分享的位置。

## AI 控制台

頂欄 **✨ 按鈕**打開的全域浮動視窗，是所有 AI 任務的執行現場：

![AI 控制台](/assets/guide/ai-console.png)

兩種形態：

- **任務形態**——從各功能頁觸發的 AI 動作（潤色、續寫、起草…）在這裡執行：帶「任務」角標的指令條目、模型**思考過程**（可折疊）、內文串流上屏、耗時與所用模型標註
- **對話形態**——任務結束後直接在輸入框追問（攜帶上文繼續改稿），或純聊天提問；Enter 傳送、Shift+Enter 換行

通用能力：**隨時停止**（停止後已有內容按場景保留或恢復）、標題條點擊**收起**不佔螢幕、**新對話**清空重來。多輪對話歷史超 6 萬字元時自動從最舊丟棄；思考流保留最近 8000 字元。

## 各頁面的 AI 入口

啟用後這些位置會出現 AI 功能（按頁面整理）：

| 頁面 | 入口 | 能力 |
|------|------|------|
| [文章編輯](./post-editor.md#ai-輔助寫作) | 工具列 AI 下拉 | 完善內容 / 格式優化 / 潤色（選取優先）/ 續寫 / 生成摘要 / 自訂指令，全文改寫帶 diff 預覽 |
| [說說動態](./moments.md#ai-輔助-可選) | 發布器按鈕 | 內文潤色（串流回填）、標籤與心情建議 |
| [資料管理](./data.md#欄位級-ai) | 編輯對話框 ✨ | 專案/技能/番劇等描述欄位生成與改寫 |
| [資料管理 · 時間線](./data.md#時間線-ai-起草) | AI起草按鈕 | git 歷史歸納 / 描述起草事件，勾選插入 |
| [資料管理 · 歌單](./data.md#歌單-匯入音樂) | 匯入音樂 | 網路檢索曲目並附版權資訊 |
| [站點設定](./settings.md#基礎資訊) | 輸入框 ✨ | 副標題、簽名一句話生成 |
| [站點設定 · 橫幅](./settings.md#橫幅桌布) | AI生成文案 | 打字機輪播文案整組生成 |
| [平台匯入](./import.md#單篇貼上) | 自動觸發 | 貼上文章的標題/摘要/分類/標籤補全 |
| [提交和發布](./publish.md#提交訊息) | AI生成按鈕 | 雙倉提交訊息生成（不合規自動回退） |

此外編輯器工具列的 AI 選單在生成期間會顯示載入動畫並停用重複觸發；所有串流任務共用一個控制台，同一時間只跑一個。

## 設計理念

- **AI 永不阻斷主流程**——提交訊息生成失敗自動回退啟發式；匯入元資訊失敗回退內文摘要；潤色停止即恢復原文
- **結果先預覽再套用**——全文改寫類一律走 diff 確認，不直接覆蓋你的文字
- **輕量任務用輕量模型**——標籤建議、摘要等小任務走 `modelFast` 並關閉思考，省錢省時
