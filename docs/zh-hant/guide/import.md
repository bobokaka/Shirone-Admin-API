# 平台匯入

正在其他平台寫博？「平台匯入」頁提供遷移通道，目前支援**簡書**，頁面頂部按平台分頁籤，後續平台以此擴展。

匯入有兩條路徑，進入頁面先二選一：

| 方式 | 適合 | 輸入 |
|------|------|------|
| **匯出包匯入** | 整站搬遷、幾十上百篇 | 簡書官方「打包下載全部文章」得到的 rar / zip |
| **單篇貼上** | 精選單篇、即貼即轉 | 網頁版文章頁全選複製的內容 |

![平台匯入](/assets/guide/import.png)

## 匯出包匯入

五步嚮導：**選擇方式 → 上傳匯出包 → 選擇文章 → 內容轉換 → 匯入完成**。

### 第 1 步：上傳匯出包

在簡書「設定 → 帳號管理 → 打包下載全部文章」申請匯出（簡書會寄電子郵件附下載連結），得到壓縮包後拖入上傳區。限制：zip / rar 格式，單包 ≤30MB。

上傳後伺服端在記憶體中解包解析，按**文集**分組列出全部文章。

### 第 2 步：選擇文章

- 解析成功後**預設全選**未匯入過的文章
- 支援按文集整組勾選、全選/清空
- 已匯入過的文章標記「已匯入」並禁選，防止重複
- 每篇文章可先「預覽」——不落盤查看轉換後的 Markdown 效果

頁面右側設定匯入選項：

| 選項 | 說明 |
|------|------|
| 統一發布日期 | 簡書匯出包不含日期，所有文章套用同一發布日（之後可逐篇改） |
| 文集作分類 | 勾選後每個文集名直接成為文章分類；不勾則手動指定一個統一分類 |
| 標籤 | 為本批文章統一附加標籤 |
| 圖片本地化 | 把簡書 CDN 圖片下載進各文章的 `images/` 目錄；下載失敗的保留遠端連結 |
| 匯入為草稿 | **建議保持勾選**——先在[文章管理](./posts.md)過目再發布 |

### 第 3 步：內容轉換

點擊開始後伺服端建立**背景任務**逐篇轉換，頁面每 2 秒輪詢進度：總數、已完成、目前正在處理的文章標題。中途可以離開頁面，任務繼續跑。

### 第 4 步：完成

任務結束展示結果清單：每篇的成敗、落倉路徑、本地化圖片數。失敗的會給出原因（單篇失敗不影響其他文章）。可「匯入下一包」繼續，或跳轉文章管理檢查成果。

## 單篇貼上

五步嚮導：**選擇方式 → 貼上內容 → 內容轉換 → 文章資訊 → 匯入完成**。

1. **貼上**——在簡書網頁版打開文章，全選複製，直接 `Ctrl+V` 貼進編輯器：富文本自動轉 Markdown（標題、粗體、連結、圖片全保留），左側原始碼右側預覽，可繼續手動修正
2. **內容轉換**——確認後伺服端落倉：圖片自動下載到文章目錄（失敗的保留遠端連結），生成目錄式文章
3. **文章資訊**——AI 分析內文**自動補全**：標題（留空時 AI 擬定）、摘要、分類、標籤建議，全部可手改；AI 不可用時回退為內文摘要擷取，會明確提示 `aiUsed=false`
4. **定稿**——元資訊寫回文章，完成。可一鍵跳轉[文章編輯](./post-editor.md)繼續精修

> [!TIP]
> 標題輸入框也支援貼上兜底：剪貼簿裡只有富文本（從網頁複製常見）時自動擷取純文字壓成單行。

## 工作階段與任務說明

- 匯出包上傳後形成一個**工作階段**（解析結果快取於伺服端記憶體），有效期 24 小時，最多同時保留 3 個，超時/超量自動淘汰最舊的——「換一個包」可立即丟棄目前工作階段
- 背景匯入任務結果保留 1 小時
- 服務重啟後記憶體工作階段與任務清空，重新上傳匯出包即可，**已匯入的文章不受影響**（它們已經落在內容倉裡了）

## 下一步

- 匯入的文章在[文章管理](./posts.md)裡逐篇核對，去掉草稿標記
- 批次改分類用[文章管理 · 分類管理](./posts.md#分類-標籤管理)
