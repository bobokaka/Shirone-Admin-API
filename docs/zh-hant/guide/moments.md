# 說說動態

「說說」是比文章輕量的內容形態：一段隨想、幾張圖、一個心情圖示。發布器在頁面上方，動態流在下方，即寫即發。

![說說動態](/assets/guide/moments.png)

## 發布一條說說

發布器卡片從上到下：

1. **內文**——多行文字框，此刻的想法
2. **圖片區**——最多 **9 張**，點擊 + 選擇或直接貼上上傳
3. **元資訊列**——心情 / 地點 / 標籤 / 發布時間 / 置頂
4. **操作列**——AI潤色（AI 啟用時）/ 存草稿 / 發布說說

### 心情圖示

九個預設心情可選：😊 開心、🤩 興奮、😐 平靜、😔 低落、😢 難過、❤️ 喜歡、🎉 慶祝、☕ 小酌、🌙 晚安。圖示以 Iconify 名稱儲存（全部本地內建，無網路請求），前台渲染為對應圖示。

### 圖片如何歸檔

一次發布的所有圖片進入**同一個批次目錄**：

```
public/images/moments/<yyyymmdd-HHmmss>/   # 批次號與說說檔名一致
├── 1.webp
└── 2.webp
```

多選上傳並行進行時也歸入同一批（批次號預先生成）。這條目錄規則不是隨意的——主題的縮圖生成管線**只掃描** `public/images/moments/`，說說圖放別處前台無法生成縮圖，所以後端強制約束了落盤位置。

> [!TIP]
> 發布前移除某張圖只是從本次發布中去掉，檔案仍留在倉庫裡；刪除整條說說時配圖檔案同樣保留，需要清理時手動處理。

### AI 輔助（可選）

AI 啟用時發布器多兩個入口：

- **AI潤色**——串流改寫內文，結果直接在輸入框裡長出來（口語化自然、保留語氣與事實），隨時可停止、停止即恢復原文
- **AI建議**——從內文提取 2–4 個標籤（與已有標籤合併去重）並猜測心情（已有選擇不覆蓋）

## 管理動態流

下方清單支援組合篩選與分頁（每頁 8 條）：

| 篩選 | 說明 |
|------|------|
| 搜尋框 | 匹配內文、地點、標籤 |
| 狀態下拉 | 全部 / 已發布 / 草稿 |
| 標籤多選 | 點卡片上的標籤也能快速篩選（再點取消） |
| 只看置頂 | 核取方塊 |

每條動態卡片提供：

- **編輯**——內容回填到上方發布器（新上傳的圖進**新批次**，不混入舊目錄），改完點「發布說說」儲存
- **置頂切換**——一鍵置頂/取消，清單立即刷新
- **刪除**——二次確認後移除 `.md` 檔案（配圖保留）

## 說說與文章的區別

| | 文章 | 說說 |
|---|------|------|
| 內容形態 | 長文 + 元資訊體系 | 短文字 + 圖 + 心情 |
| 儲存 | `content/posts/<slug>/index.md` | `content/moments/<yyyymmdd-HHmmss>.md` |
| 典型用途 | 教程、筆記、深度思考 | 近況、碎碎念、隨手記錄 |
