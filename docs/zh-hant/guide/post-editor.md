# 文章編輯

文章編輯器是後台功能最密集的頁面。從[文章管理](./posts.md)新建文章、或點「編輯」後進入，完整編輯頁自帶**左右分欄即時預覽**；文章管理頁內的就地編輯則是同一套編輯器的單欄形態。

![文章編輯](/assets/guide/post-editor.png)

## 頂欄操作

從左到右：

| 按鈕 | 作用 |
|------|------|
| 返回 | 自動儲存後回到上一頁面 |
| 標題輸入框 | 常駐大號輸入框，隨時改名 |
| 文章資訊 | 打開元資訊抽屜（見下文） |
| 刪除 | 刪除文章及其目錄下全部配圖，需二次確認 |
| 儲存 | 立即落盤內容倉 |
| 儲存並去發布 | 儲存後直接跳轉[提交和發布](./publish.md) |

頂欄還會顯示「已自動儲存 HH:mm:ss」提示最近一次自動儲存的時間。

## 編輯器

編輯器採用 **Markdown 原始碼模式**（基於 md-editor-v3 + CodeMirror），你直接書寫 Markdown 原始碼，右側分欄即時渲染預覽。工具列提供常用排版：粗體、斜體、刪除線、標題、引用、清單、任務、行內程式碼、程式碼區塊、連結、圖片、表格、復原/重做，以及預覽/目錄切換。

**配圖零負擔**：編輯器裡貼上螢幕截圖或透過圖片按鈕上傳，檔案自動存入目前文章目錄的 `images/` 子目錄，內文自動插入相對引用（`./images/xxx.webp`）。文章因此是自包含的——整個目錄拷貝走就是完整的一篇。

AI 啟用後，工具列末尾會多出一個 **AI 下拉工具**，詳見下文 [AI 輔助寫作](#ai-輔助寫作)。

## 文章資訊抽屜

「文章資訊」抽屜收納全部中繼資料（對應文章 frontmatter）：

### 基礎欄位

- **發布日期**（`YYYY-MM-DD`）與**精確時間**——同一天發布多篇文章時用它控制排序，時區自動按 `+08:00` 正規化
- **分類**——下拉可選已有分類（附使用計數），直接輸入新名字按 Enter 即新建
- **標籤**——多選，同樣支援輸入新建
- **摘要**——留空時主題自動擷取內文前段；封面支援本地上傳或外鏈
- **開關**——草稿 / 置頂 / 評論 / 加密

### 加密文章

勾選「加密」後展開三個欄位：

- **存取密碼**——已設定過的文章，輸入則修改、留空保持不變；取消勾選「加密」即清除密碼
- **密碼提示**——訪客輸入密碼前看到的提示語
- **首頁卡片隱藏預覽**——防止加密內容以摘要形式洩露到首頁

### 存取路徑

三種模式決定文章的最終 URL，底部有即時位址預覽：

| 模式 | 位址形態 | 適用場景 |
|------|----------|----------|
| 預設 | `/posts/<文章名>/` | 常規文章 |
| 自訂別名 | `/posts/<別名>/` | 想要更短、更語義化的 URL |
| 根路徑固定連結 | `/<自訂路徑>/` | 精心製作的招牌頁面，如 `/about-me/` |

## AI 輔助寫作

> [!NOTE]
> 以下功能需要先啟用 AI 助手（[設定方法](./ai.md#設定服務商)）。未啟用時工具列不出現 AI 入口，寫作功能不受影響。

AI 下拉工具內建 5 個動作 + 自訂指令，所有動作都會**原樣保留程式碼與 Shirone 主題私有擴充片段**（三冒號容器、file-tree 等）：

| 動作 | 作用範圍 | 結果如何套用 |
|------|----------|--------------|
| AI完善內容 | 全文 | 補全論述缺口、增強邏輯銜接——先預覽再套用 |
| AI格式優化 | 全文 | 規範標題層級、統一標點、補全程式碼圍欄語言——先預覽再套用 |
| AI潤色 | **選取優先** | 有選取文字直接替換；無選取走全文 diff 預覽 |
| AI續寫 | 文末 | 從結尾自然延續，結果附加到內文末尾 |
| AI生成摘要 | 全文 | 生成 80–160 字摘要回填「文章資訊」（已有摘要會先確認） |
| 自訂指令 | 選取或全文 | 輸入任意指令（如「改成更口語化的風格」）後執行 |

**diff 預覽**是全文改寫類動作（完善/格式優化/無選取潤色/自訂指令）的安全網：AI 結果以左右對照的差異視圖串流刷新，長段未變行自動折疊，可用「上一處/下一處」逐塊跳轉。核對後「套用替換」才真正改寫內文；停止生成的內容不完整，不允許套用。內文長度變化超過 20% 時預覽框會紅字警示，提醒仔細核對。

所有 AI 動作在全域 [AI 控制台](./ai.md#ai-控制台)裡執行：思考過程可見、隨時可停止。

## 自動儲存

編輯器有一套不打擾的自動儲存機制：

- 每 **10 秒**檢查一次，標題或內文有改動才靜默落盤
- **切換文章、點擊返回、離開編輯頁**的瞬間也會先自動儲存
- 唯一會攔下你的情況：標題為空（無法落盤），此時會提示先填標題

自動儲存只覆蓋標題與內文；「文章資訊」抽屜裡的中繼資料透過「儲存」按鈕落盤。
