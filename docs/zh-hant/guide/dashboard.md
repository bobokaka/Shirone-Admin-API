# 儀表板與預覽

打開 `http://localhost:5173/` 後看到的第一個頁面就是**儀表板**。它是整個後台的總覽：目前有多少待發布的改動、多少文章與動態，以及一個即時渲染你部落格真實外觀的預覽視窗。

![儀表板](/assets/guide/dashboard.png)

## 四張統計卡

| 卡片 | 數值含義 | 快捷按鈕 |
|------|----------|----------|
| **待發布變更** | 內容倉裡已暫存 + 已修改 + 未跟蹤的 git 變更檔案總數 | 「去發布」→ 跳轉[提交和發布](./publish.md) |
| **文章總數** | 內容倉中全部文章（含草稿） | 「管理文章」→ 跳轉[文章管理](./posts.md) |
| **動態總數** | 全部說說（含草稿） | 「管理說說」→ 跳轉[說說動態](./moments.md) |
| **草稿總數** | 文章與說說中標記為草稿的數量之和 | 「繼續創作」→ 跳轉文章管理 |

「待發布變更」就是你在後台做過的所有尚未提交改動的彙總——寫完文章、發完說說後，看到這個數字不為零，說明還沒發布上線。

## 最近內容

統計卡下方兩張清單卡分別展示**最近 6 篇文章**與**最近 6 條動態**：

- 文章列顯示標題、發布日期，草稿帶黃色標籤
- 動態列顯示時間、置頂/草稿/標籤，內文擷取前三行，縮圖最多 3 張（點擊可放大預覽）
- 右上角「更多」跳轉對應管理頁

## 真站預覽

頁面底部的「真站預覽」卡片內嵌一個 iframe，直接載入 `http://localhost:4321/` ——也就是主題倉 Astro 開發伺服器渲染出的**真實站點**。它不是截圖或簡化模擬，預覽效果與將來發布的站點完全一致。

### 狀態指示與操作

預覽面板頂部工具列從左到右：

- **狀態標籤**（3 秒輪詢一次）：
  - 站點就緒 `:4321` —— 預覽可用
  - 偵測到 dev server 已在運行 `:4321` —— 預覽可用（行程非本面板啟動）
  - 啟動中，首次需編譯… —— Astro 正在冷啟動，稍等片刻
  - 未運行 —— 需要點「啟動預覽」
- **啟動預覽 / 停止** —— 在後台拉起或終止主題倉的 `content:watch` + `astro dev` 行程
- **新視窗打開** —— 彈出瀏覽器分頁直接存取 `:4321`

儀表板的預覽面板不會自動拉起行程（避免打擾），需要手動點「啟動預覽」。如果你是用 `node workspace/content-watch.mjs` 一鍵啟動的，dev server 已經在跑，面板會直接顯示就緒。

### 預覽為什麼是「真」的

[三倉工作區](./workspace.md)裡介紹過資料流：後台儲存 → 寫入內容倉 → `content:watch` 物化到主題倉 → Astro 重新編譯。所以你在後台改一處文案、儲存，幾秒後預覽裡的部落格就會更新——**所見即即將發布的真實站點**。

## 頂欄與全域入口

每個頁面共用的頂欄：

- **頁面標題** —— 目前所在功能頁名稱
- **連接狀態標籤** —— 內容倉「已連接 / 未連接」（詳見[三倉工作區 · 連接狀態怎麼看](./workspace.md#連接狀態怎麼看)）
- **✨ 按鈕** —— 打開全域 [AI 控制台](./ai.md#ai-控制台)
- **齒輪按鈕** —— 打開「設定」對話框（[AI 服務商設定](./ai.md#設定服務商)與關於頁）
