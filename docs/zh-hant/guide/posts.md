# 文章管理

「文章管理」頁是你與文章打交道的主入口：瀏覽全部文章、按分類標籤篩選、快速預覽內文，以及批次整理分類體系。

![文章管理](/assets/guide/posts.png)

頁面分為左右兩欄：**左側文章清單**（篩選 + 選取），**右側內容預覽**（閱讀或就地編輯）。點擊左側任意文章，右側立即渲染它的 Markdown 內文。

## 新建文章

點工具列「**新建文章**」，在對話框裡輸入標題（建立後隨時可改），確認後：

1. 後端在內容倉 `content/posts/` 下建立一篇**草稿狀態**的文章
2. 自動跳轉到[文章編輯](./post-editor.md)頁開始寫作

文章標題會經拼音轉寫生成 URL 友好的目錄名（slug），例如《快速上手指南》→ `kuai-su-shang-shou-zhi-nan/index.md`。重名時自動加序號。

## 瀏覽與篩選

工具列提供三個篩選器，可組合使用：

| 篩選器 | 行為 |
|--------|------|
| 搜尋框 | 同時匹配**標題、分類、標籤**（不區分大小寫） |
| 分類下拉 | 只顯示該分類的文章，選項後括號內是該分類的文章數 |
| 標籤下拉 | 只顯示含該標籤的文章 |

清單頭部即時顯示「文章（篩選後 / 全部）」。每列文章顯示標題、發布日期、分類，以及狀態標籤：黃色「草稿」、「置頂」、紅色「加密」。

## 預覽與就地編輯

選取文章後右側展示：

- **標題與元資訊**：日期、分類、標籤、草稿/置頂/加密標籤
- **內文渲染**：Markdown 即時渲染，文章目錄內的配圖（`./images/…` 相對引用）直接顯示
- **編輯**按鈕：右欄原地切換為完整編輯器（與[文章編輯](./post-editor.md)頁同一套介面，只是不帶分欄預覽）。編輯器右上角的「分欄編輯」圖示可跳轉到帶左右分欄預覽的完整編輯頁，返回時自動恢復到這篇文章的編輯狀態
- **刪除**按鈕：目錄式文章會提示「將刪除該文章及其目錄下全部配圖」；已提交過 git 的內容可從歷史恢復

> [!TIP]
> 在就地編輯狀態下切換左側文章時，若有未儲存改動會**先靜默自動儲存**再切換，不會丟稿（詳見[文章編輯 · 自動儲存](./post-editor.md#自動儲存)）。

## 分類 / 標籤管理

工具列右側「**分類管理**」打開批次整理對話框，這是全站分類體系唯一需要維護的地方：

- 頂部分類 / 標籤兩個頁籤，清單按**使用文章數降序**排列
- **重新命名 / 合併**：把某個分類（或標籤）改名為新名字；如果新名字已存在，等於把兩者**合併**。後端會逐篇改寫文章 frontmatter 並保持日期格式不變
- **移除**：從所有文章中刪掉這個分類/標籤（文章本身不受影響）

例如想把零散的「JS」「JavaScript」統一成「JavaScript」：對「JS」執行重新命名，填 `JavaScript`，確認後所有相關文章自動改寫。

## 文章在磁碟上的形態

理解儲存形式，備份與排查時更從容：

```
content/posts/
├── hello/                  # 目錄式（新建文章預設）：配圖隨文管理
│   ├── index.md
│   └── images/
│       └── cover.webp
└── old-post.md             # 平鋪式（歷史文章或外部匯入）：單檔案
```

- 新建文章一律是**目錄式**，編輯器裡上傳的配圖自動進該目錄的 `images/` 子目錄
- 清單按**置頂優先、發布日期倒序**排列
