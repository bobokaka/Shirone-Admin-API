# 站點設定

「站點設定」頁把主題的全部設定項做成表單：左側分區表單，右側內嵌[真站預覽](./dashboard.md#真站預覽)，改完儲存、預覽刷新，所見即所得。

頁面分五個頁籤：**基礎資訊**、**導航**、**頁尾**、**主題外觀**、**橫幅桌布**。

![站點設定 · 基礎資訊](/assets/guide/settings.png)

## 基礎資訊

七個分區，各自獨立儲存：

| 分區 | 設定什麼 |
|------|----------|
| 站點資訊 | 站名、副標題（副標題帶 AI ✨ 一句話生成） |
| 個人資料 | 頭像（線上 URL 或本地上傳，自動重新命名落倉）、暱稱、簽名（同樣帶 AI ✨） |
| 社群連結 | GitHub / B 站等外鏈清單：名稱、Iconify 圖示、位址 |
| 站點圖示 favicon | 淺色 / 深色兩個槽位；未自訂時顯示主題預設圖示的目前生效提示；上傳自動定名 `favicon-light/dark.<ext>` 原位替換，也可直接填線上位址 |
| 常規設定 | 站點位址（部署後的最終網域）、子路徑（根部署填 `/`）、時區（下拉常用時區，可手輸） |
| 訪客顯示面板 | 控制前台開放給訪客的顯示開關：配色選擇器、配色規範切換、背景模式、清單佈局、減弱動效、背景紋理 |
| 國際化 | 是否開放多語言：勾選開放的語言集合，站點主語言必須落在集合內；關閉則全站鎖定簡體中文 |

## 導航

視覺化的導航選單編輯器：

- **主題預設**——從 15 個內建預設（首頁、歸檔、友鏈等）中選取，一鍵接入
- **自訂連結**——名稱 + 圖示 + 位址，可標記「新視窗打開」
- **下拉分組**——拖出二級選單收納同類入口

導航設定整體儲存，陣列語義為**整體替換**。

## 頁尾

- **啟用開關**——控制自訂頁尾內容是否注入主題版權行上方
- **HTML 編輯器**——CodeMirror 程式碼編輯器，附帶 **Prettier 格式化**按鈕；頁尾 HTML 原文保存在內容倉 `config/footer.html`
- **頁尾圖片庫**——上傳圖片或貼上線上直鏈（伺服端代為下載，webp 自動轉 png/jpg）落倉到 `public/images/footer/`，點「複製路徑」貼進 HTML
- **即時預覽**——iframe 近似還原主題頁尾渲染效果，版權行 + 你的自訂內容

## 主題外觀

![站點設定 · 主題外觀](/assets/guide/settings-appearance.png)

兩個分區：

### 主題配色

- **色相滑桿**（0–360）——即時顯示由該色相生成的 5 級色板預覽
- **鎖定**——勾選後站點色相不隨內容/訪客偏好變化
- **配色風格**——Material 3 的 9 種動態取色風格：tonalSpot（經典柔和）、vibrant（鮮活）、content（取自內容色）、expressive、rainbow、fruitSalad、monochrome、neutral、fidelity
- **配色規範**——Material 3 的 2021 / 2025 兩代規範

### 桌布與紋理

- **預設背景模式**——banner / none 二選一，決定未選桌布時前台預設形態
- **背景紋理**——六種預設：none、starlight（星光）、cyber-dots（賽博點陣）、topography（等高線）、geometric（幾何）、sakura（櫻花）；透明度 0.05–0.25；允許動效開關

## 橫幅桌布

首頁橫幅的完整控制：

- **桌面桌布 / 行動桌布**兩組清單——本地上傳、線上直鏈匯入（伺服端代取）、**AI 推薦桌布**按鈕（從 safebooru 圖源按尺寸篩選抓取一批：桌面 ≥1920 橫圖、行動 ≥1920 豎圖，勾選下載落倉）
- **展示控制**——位置（top/center/bottom）、遮罩（開關 + 透明度）
- **首頁文案**——標題、多句副標題、打字機效果（速度/刪除速度/停頓時長/循環）；副標題可點 **AI生成** 基於站名與簽名一次生成 4–6 句輪播文案
- **輪播**——多張桌布時啟用，切換間隔、漸變時長、六種切換動畫（ken-burns 緩慢推拉、zoom-in/out、pan-left/right、none）
- **波浪裝飾**——橫幅底部波浪動效開關

> [!TIP]
> 儲存橫幅時，不再被桌面/行動任何一端引用的本地桌布檔案會被**自動清理**，無需手動刪檔案。

## 設定落在哪裡

所有設定寫入內容倉 `config/*.yaml`，遵循**最小化覆蓋**原則：只寫你改過的鍵，未宣告的欄位繼承主題預設值——主題升級新增設定項時你的站點自動跟進，不會因為一份「全量快照」而卡死在舊版本。字典鍵遞迴合併，陣列整體替換。
