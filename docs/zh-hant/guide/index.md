# 指南

歡迎使用 **Shirone-Admin**——[Shirone](https://github.com/LyraVoid/Shirone) 部落格的視覺化內容管理工具。它本地單機運行、前後端分離，直接讀寫你的內容倉，並提供 AI 輔助寫作與一鍵雙倉發布。

本板塊面向**第一次接觸 Shirone-Admin 的讀者**：由淺入深、每一步都可照做複現，不需要任何背景知識。遇到不熟悉的概念，文中會在它首次出現時就地解釋，或給出跳轉連結。

## 從這裡開始

## 內容創作

- **[文章編輯](./post-editor.md)**——編輯器、文章資訊、配圖、AI 輔助寫作、自動儲存
