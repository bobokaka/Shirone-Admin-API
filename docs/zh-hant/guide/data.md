# 結構化資料

部落格裡「我的」頁面上的專案、技能、設備清單，側欄的番劇追番表、友鏈、背景歌單——這些都是**結構化資料**：每一類是內容倉 `data/*.ts` 裡的一個 TypeScript 陣列。「資料管理」頁把它們全部做成表格 + 表單的視覺化編輯，改動**即時落倉**。

![資料管理](/assets/guide/data.png)

## 八類資料

| 頁籤 | 條目 | 典型欄位 |
|------|------|----------|
| 專案 | 專案 | 名稱、簡介、分類、階段（已發布/開發中/探索中）、技術棧、精選 |
| 技能 | 技能 | 名稱、分類（前端/後端/工具/遊戲開發）、水平（入門→專家）、圖示 |
| 時間線 | 事件 | 標題、日期、分類（里程碑/專案/經歷/生活）、要點、關聯連結 |
| 設備 | 設備 | 名稱、品牌、分類、狀態（在用/備用/退役/想買）、規格 |
| 番劇 | 番劇 | 標題、狀態（在看/看完/計劃/擱置/棄番）、評分、進度、類型、封面 |
| 羅盤 | 書架 | 名稱、圖示、導航條目（名稱 + 連結 + 備註） |
| 歌單 | 曲目 | 曲名、藝術家、封面、音訊位址、時長 |
| 友鏈 | 友鏈 | 站點名、頭像、描述、位址、標籤 |

## 通用操作

- **新增**——打開編輯對話框逐欄位填寫；必填項缺失會攔截提示
- **表格內直接切換**——「精選」「啟用」等布林欄位在表格裡就是開關，撥動即儲存
- **排序**——每列右側 ↑↓ 按鈕調整順序（陣列順序即前台展示順序），即時落倉
- **編輯 / 刪除**——編輯打開對話框回填全部欄位；刪除需二次確認

幾個省力的細節：

- **標識欄位自動生成**——專案 key、設備 id、曲目 id 等標識列不用手填：新增時由標題自動轉拼音 slug（重名加序號），友鏈 id 取最大值 +1
- **圖示欄位**——輸入 Iconify 圖示名（如 `simple-icons:typescript`）即時預覽；圖示全部本地內建，不發起網路請求
- **圖片欄位**——封面支援本地上傳（按資料類型自動落入對應資源目錄）或貼上路徑；番劇/歌單有專門的一鍵匯入，見下文
- **羅盤與時間線的條目清單**——「導航條目」「關聯連結」這類巢狀陣列用視覺化卡片編輯，每條子項的名稱/圖示/位址一排填完，支援必填驗證

所有改動透過**循序儲存佇列**寫回 `data/*.ts`——檔案裡的 interface 定義、註解、匯出陳述式逐字保留，只替換陣列字面值部分，手工維護的程式碼不會被動到。

## 番劇：搜尋匯入

番劇頁籤專屬的「**搜尋匯入**」按鈕，資料來自 [Bangumi（番組計劃）](https://bgm.tv/)公開 API：

![番劇搜尋匯入](/assets/guide/data-anime.png)

1. **搜尋**——輸入中文/日文/英文標題，返回候選清單（含年份、集數、評分、封面）
2. **選條目**——自動拉取詳情補全：製作公司、放送檔期、高頻類型標籤
3. **確認**——生成一條新番劇草稿：標題/年份/類型/簡介/封面/製作都已填好，**狀態與評分留給你定**；封面圖從 Bangumi 官方圖床下載落倉到 `public/assets/anime/`

追番記錄從此不用手動填元資料，看完一部搜一部。

## 歌單：匯入音樂

歌單頁籤的「**匯入音樂**」提供三種進曲方式：

- **AI 檢索**——描述想找的歌（歌名/風格），AI 網路檢索並附帶**版權資訊**（能否免費商用、依據連結），確認後音訊與封面自動落倉
- **直鏈匯入**——貼上音訊直鏈，伺服端代為下載（瀏覽器跨來源拿不到的也能下）
- **本地上傳**——直接上傳音訊檔案

匯入後在表格裡點 **▶ 試聽**，底部播放條隨選隨播，聽對了再儲存。

## 時間線：AI 起草

時間線頁籤的「**AI 起草**」按鈕（AI 啟用時出現）用兩種模式批次生成事件草稿：

- **git 模式**——掃描三個倉庫的提交歷史（每倉最多 30 條，含檔案增刪統計），AI 歸納成時間線事件：適合「這個月我做了什麼」的複盤
- **描述模式**——你寫一句話描述，AI 起草成規範事件（標題/日期/分類/要點/標籤）

生成的草稿清單可**逐條勾選**，已收錄的事件自動去重（按標題 + 日期比對）。確認插入時按日期找到正確位置插入清單並落倉，日期格式自動轉為站點使用的點分風格（`2025.06.01`）。

## 欄位級 AI

簡介、描述這類長文字欄位（專案簡介、技能描述、番劇描述、友鏈描述、時間線描述、設備描述）在編輯對話框右上角有 **✨ 按鈕**：填了條目標題之後，點一下 AI 按 1–3 句中文生成或改寫該欄位，結果串流直接在輸入框裡長出來，可停止、可手改。
