# ИИ-ассистент

Возможности ИИ в Shirone-Admin — **необязательное усиление**: без настройки всё работает как прежде; с настройкой на этапах письма, импорта и публикации появляется набор умных помощников. В этой главе сначала настройка, затем использование.

## Настройка провайдеров

Нажмите **шестерёнку** в верхней панели и откройте диалог «Настройки», в меню слева выберите «ИИ-ассистент».

![Настройка ИИ-провайдеров](/assets/guide/app-settings.png)

### Ключевые понятия

- **Несколько провайдеров** — можно хранить несколько комплектов настроек подключения (до 20) и в любой момент переключать активный. Удобно тем, кто держит и официальный API, и транзитный прокси, или переключает модели под задачу
- **Два протокола** — в каждом комплекте выбирается один из двух:
  - `anthropic` — протокол, совместимый с Anthropic (`v1/messages`): официальный API и всевозможные «Anthropic-совместимые» посредники
  - `openai` — протокол, совместимый с OpenAI (`chat/completions`): OpenAI и подавляющее большинство API моделей от китайских вендоров
- **Главный переключатель** — при выключенном «Включить» все ИИ-входы скрываются, API единообразно отказывает

### Поля каждого комплекта

| Поле | Описание |
|------|------|
| Название | Отображаемое имя, например `Anthropic официальный` / `GLM-транзит` |
| Протокол | anthropic / openai |
| Адрес API | Достаточно корневого адреса (`https://api.anthropic.com` или `https://api.openai.com/v1`); допускаются голый корень, вариант с `/v1`, прокси-подпуть и т. п. |
| API Key | Хранится только локально в `server/data/ai-settings.json`, **никогда не пишется в контент-репозиторий** и не утечёт при публикации |
| Основная модель | Для повседневных задач, например `claude-sonnet-5` / `gpt-4o-mini` / `glm-5.3` |
| Лёгкая модель | Для простых задач вроде аннотаций и подсказок тегов; **пусто = та же, что основная** (одна настройка экономится) |
| Поиск в интернете | Добавляет инструмент web-поиска поддерживающим его сервисам; при отсутствии поддержки автоматически снижается до обычного запроса |
| Температура | Температура сэмплирования 0–2, по умолчанию 0.7 |
| Таймаут | Таймаут одного запроса в секундах, 5–86400, по умолчанию 30 |

### Порядок действий

1. Нажмите + **добавить провайдера** (имя по умолчанию «Конфигурация N» — ввод текста сразу переименовывает)
2. Заполните поля или используйте **импорт вставкой**: вставьте целиком блок env из `settings.json` Claude Code, shell-строки `export` или содержимое dotenv — автоматически распознаются `ANTHROPIC_*` / `OPENAI_*` и ещё 8 ключей, и таблица заполнится
3. **Проверить соединение** — тест работает ещё до сохранения, возвращает задержку и ответ модели; после успеха **сохраните**

> [!WARNING]
> В `server/data/ai-settings.json` лежит открытый текст API Key. Файл уже в gitignore, но не копируйте его туда, где он может быть закоммичен или расшарен.

## ИИ-консоль

Глобальное плавающее окно, открываемое кнопкой **✨** в верхней панели, — рабочее место всех ИИ-задач:

![ИИ-консоль](/assets/guide/ai-console.png)

Две формы:

- **Форма задачи** — ИИ-действия, запущенные со страниц функций (полировка, дописывание, черновики…), выполняются здесь: строка инструкции с бейджем «задача», видимый **процесс размышления** модели (сворачивается), потоковый вывод текста, отметки времени и использованной модели
- **Форма диалога** — после завершения задачи можно сразу задать вопрос в поле ввода (правка текста с учётом контекста) или просто поболтать; Enter отправляет, Shift+Enter переносит строку

Общие возможности: **остановка в любой момент** (после остановки уже выведенное сохраняется или восстанавливается по контексту), клик по заголовку **сворачивает** окно, **новый диалог** очищает всё. История многократного диалога при превышении 60 тысяч символов автоматически отбрасывается с самых старых; поток размышлений хранит последние 8000 символов.

## ИИ-входы на страницах

После включения ИИ-функции появляются в этих местах (сгруппировано по страницам):

| Страница | Вход | Возможности |
|------|------|------|
| [Редактирование статей](./post-editor.md#ии-помощь-в-написании) | ИИ-выпадающий список на панели | Улучшение содержания / наведение формата / полировка (сначала выделенное) / дописывание / генерация аннотации / произвольная инструкция; перезапись всего текста — с diff-предпросмотром |
| [Моменты](./moments.md#ии-помощь-опционально) | Кнопки формы публикации | Полировка текста (потоковое заполнение), подсказки тегов и настроения |
| [Управление данными](./data.md#ии-на-уровне-полеи) | ✨ в диалоге редактирования | Генерация и перезапись полей-описаний проектов/навыков/аниме и др. |
| [Управление данными · Таймлайн](./data.md#таимлаин-черновики-от-ии) | Кнопка «Черновик от ИИ» | Сводка git-истории / черновики событий из описания; выбор и вставка |
| [Управление данными · Плейлист](./data.md#плеилист-импорт-музыки) | Импорт музыки | Поиск треков в сети со сведениями о лицензии |
| [Настройки сайта](./settings.md#основная-информация) | ✨ у полей ввода | Генерация подзаголовка и подписи одной фразой |
| [Настройки сайта · Баннер](./settings.md#обои-баннера) | ИИ-генерация текстов | Генерация всего набора ротационных фраз для печатной машинки |
| [Импорт с платформ](./import.md#вставка-отдельнои-статьи) | Автозапуск | Дополнение заголовка/аннотации/категории/тегов вставленной статьи |
| [Коммиты и публикация](./publish.md#сообщения-коммита) | Кнопка ИИ-генерации | Генерация сообщений коммита для двух репозиториев (откат при несоответствии формату) |

Кроме того, ИИ-меню на панели редактора на время генерации показывает анимацию загрузки и блокирует повторный запуск; все потоковые задачи делят одну консоль — одновременно выполняется только одна.

## Философия дизайна

- **ИИ никогда не блокирует основной поток** — сбой генерации сообщения коммита откатывается к эвристике; сбой дополнения метаданных при импорте — к началу текста; остановка полировки возвращает исходный текст
- **Результат сначала на предпросмотр, потом в дело** — перезапись всего текста всегда идёт через diff-подтверждение, ваш текст не перезаписывается напрямую
- **Лёгкие задачи — лёгкой модели** — мелкие работы вроде подсказок тегов и аннотаций идут через `modelFast` с выключенным размышлением: экономия денег и времени
