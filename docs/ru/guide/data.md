# Структурированные данные

Проекты, навыки и список устройств на странице «Обо мне», таблица просматриваемых аниме, друзья сайта и фоновый плейлист в боковой панели — всё это **структурированные данные**: каждый тип — это массив TypeScript в `data/*.ts` контент-репозитория. Страница «Управление данными» превращает их все в визуальное редактирование таблицей + формой, изменения **немедленно записываются в репозиторий**.

![Управление данными](/assets/guide/data.png)

## Восемь типов данных

| Вкладка | Записи | Типичные поля |
|------|------|----------|
| Проекты | Проект | Название, описание, категория, стадия (выпущено/в разработке/в исследовании), технологический стек, избранное |
| Навыки | Навык | Название, категория (фронтенд/бэкенд/инструменты/разработка игр), уровень (новичок → эксперт), иконка |
| Таймлайн | Событие | Заголовок, дата, категория (веха/проект/опыт/жизнь), тезисы, связанные ссылки |
| Устройства | Устройство | Название, бренд, категория, статус (в использовании/запас/списано/хочу купить), характеристики |
| Аниме | Аниме | Заголовок, статус (смотрю/просмотрено/в планах/отложено/брошено), оценка, прогресс, тип, обложка |
| Компас | Полка | Название, иконка, элементы навигации (название + ссылка + примечание) |
| Плейлист | Трек | Название, исполнитель, обложка, адрес аудио, длительность |
| Друзья сайта | Сайт-друг | Название сайта, аватар, описание, адрес, теги |

## Общие операции

- **Добавление** — открывается диалог редактирования с заполнением по полям; отсутствие обязательных полей перехватывается подсказкой
- **Прямое переключение в таблице** — булевы поля вроде «Избранное», «Включено» — это прямо переключатели в таблице, щелчок и сохранение
- **Сортировка** — кнопки ↑↓ справа в каждой строке меняют порядок (порядок массива — он и порядок показа на фронтенде), запись немедленная
- **Редактирование / удаление** — редактирование открывает диалог со всеми заполненными полями; удаление требует повторного подтверждения

Несколько сберегающих усилия мелочей:

- **Поля-идентификаторы генерируются автоматически** — столбцы-идентификаторы вроде ключа проекта, id устройства, id трека заполнять руками не нужно: при добавлении из заголовка автоматически создаётся slug в пиньине (при совпадении добавляется номер), id друга берётся как максимум +1
- **Поля иконок** — имя иконки Iconify (например `simple-icons:typescript`) сразу показывает предпросмотр; все иконки встроены локально, сетевых запросов нет
- **Поля изображений** — обложку можно загрузить локально (автоматически попадает в соответствующий каталог ресурсов по типу данных) или вставить путь; для аниме/плейлиста есть отдельный импорт одним кликом, см. ниже
- **Списки записей компаса и таймлайна** — вложенные массивы вроде «элементов навигации», «связанных ссылок» редактируются визуальными карточками: название/иконка/адрес каждой подзаписи заполняются в одну строку, поддержана проверка обязательных полей

Все изменения записываются назад в `data/*.ts` через **последовательную очередь сохранения** — определения interface, комментарии и операторы экспорта в файле сохраняются буква в букву, заменяется только литерал массива; код, поддерживаемый вручную, не затрагивается.

## Аниме: импорт через поиск

Кнопка «**Импорт через поиск**», доступная только на вкладке аниме, берёт данные из открытого API [Bangumi](https://bgm.tv/):

![Импорт аниме через поиск](/assets/guide/data-anime.png)

1. **Поиск** — введите название на китайском/японском/английском, получите список кандидатов (с годом, числом эпизодов, оценкой, обложкой)
2. **Выбор записи** — детали подтягиваются автоматически: студия, эфирный период, частотные теги типов
3. **Подтверждение** — создаётся черновик записи аниме: заголовок/год/тип/описание/обложка/студия уже заполнены, **статус и оценку выбираете вы**; обложка скачивается с официального хостинга Bangumi в `public/assets/anime/`

Больше не нужно вручную вбивать метаданные для списка просмотренного — досмотрели тайтл, нашли его поиском.

## Плейлист: импорт музыки

«**Импорт музыки**» на вкладке плейлиста предлагает три пути добавления треков:

- **ИИ-поиск** — опишите искомую песню (название/жанр), ИИ ищет в сети и прикладывает **сведения о лицензии** (можно ли свободно использовать в коммерческих целях, ссылка-основание); после подтверждения аудио и обложка автоматически записываются в репозиторий
- **Импорт по прямой ссылке** — вставьте прямую ссылку на аудио, сервер скачает сам (в том числе недоступное браузеру из-за CORS)
- **Локальная загрузка** — прямая загрузка аудиофайла

После импорта нажмите **▶ прослушать** в таблице — нижняя панель плеера играет выбранное на ходу; убедившись, сохраняйте.

## Таймлайн: черновики от ИИ

Кнопка «**Черновик от ИИ**» на вкладке таймлайна (появляется при включённом ИИ) массово генерирует черновики событий в двух режимах:

- **Режим git** — сканирует историю коммитов трёх репозиториев (до 30 на каждый, со статистикой изменений файлов), ИИ сводит её в события таймлайна: подходит для ретроспективы «что я сделал в этом месяце»
- **Режим описания** — вы пишете описание одной фразой, ИИ оформляет событие по формату (заголовок/дата/категория/тезисы/теги)

Список сгенерированных черновиков можно **отмечать по одному**; уже внесённые события автоматически исключаются как дубликаты (сравнение по заголовку + дате). При подтверждении вставки событие попадает в правильное место по дате и записывается в репозиторий, формат даты автоматически приводится к точечному стилю сайта (`2025.06.01`).

## ИИ на уровне полей

Длиннотекстовые поля вроде описаний (описание проекта, описание навыка, описание аниме, описание друга сайта, описание события таймлайна, описание устройства) имеют кнопку **✨** в правом верхнем углу диалога редактирования: если заголовок записи уже заполнен, один клик — и ИИ генерирует или переписывает поле в 1–3 предложениях; результат потоково «вырастает» прямо в поле ввода, с возможностью остановить и поправить руками.
