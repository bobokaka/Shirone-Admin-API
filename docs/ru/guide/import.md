# Импорт с платформ

Ведёте блог на другой платформе? Страница «Импорт с платформ» даёт канал миграции: сейчас поддерживается **Цзяньшу (Jianshu)**; вверху страницы вкладки по платформам, новые платформы добавляются по той же схеме.

Импорт идёт двумя путями — сразу после входа на страницу выберите один:

| Способ | Подходит для | Входные данные |
|------|------|------|
| **Импорт архива экспорта** | Переезд всего блога, десятки и сотни статей | rar / zip из официальной функции Цзяньшу «Скачать все статьи архивом» |
| **Вставка отдельной статьи** | Отдельные избранные статьи, вставил — и готово | Содержимое, скопированное целиком со страницы статьи в веб-версии |

![Импорт с платформ](/assets/guide/import.png)

## Импорт архива экспорта

Мастер из пяти шагов: **выбор способа → загрузка архива → выбор статей → преобразование → завершение**.

### Шаг 1: загружаем архив экспорта

Запросите экспорт в Цзяньшу («Настройки → Управление аккаунтом → Скачать все статьи архивом»; Цзяньшу пришлёт ссылку на скачивание по почте) и перетащите полученный архив в зону загрузки. Ограничения: форматы zip / rar, один архив ≤30 МБ.

После загрузки сервер распаковывает и разбирает пакет в памяти, выводя все статьи, сгруппированные по **сборникам**.

### Шаг 2: выбираем статьи

- После успешного разбора **по умолчанию отмечены** все ещё не импортированные статьи
- Можно отмечать целыми сборниками, выбирать всё и снимать всё
- Уже импортированные статьи помечены «Импортировано» и заблокированы от выбора — защита от дублей
- Для каждой статьи доступен «Предпросмотр» — увидеть преобразованный Markdown без записи на диск

Справа на странице задаются параметры импорта:

| Параметр | Описание |
|------|------|
| Единая дата публикации | Архив Цзяньшу не содержит дат; одна дата публикации применяется ко всем статьям (потом можно поменять каждую) |
| Сборник как категория | Если отмечено, имя каждого сборника становится категорией статей; иначе задаётся одна общая категория вручную |
| Теги | Единый набор тегов для всей партии статей |
| Локализация изображений | Скачать изображения с CDN Цзяньшу в каталоги `images/` статей; при сбое загрузки сохраняется удалённая ссылка |
| Импортировать черновиками | **Рекомендуется оставить отмеченным** — сначала просмотреть в [Управлении статьями](./posts.md), потом публиковать |

### Шаг 3: преобразование

После нажатия старта сервер создаёт **фоновую задачу**, преобразующую статьи по одной; страница опрашивает прогресс каждые 2 секунды: всего, готово, заголовок обрабатываемой статьи. Со страницы можно уйти — задача продолжит работать.

### Шаг 4: завершение

По окончании задача показывает итоговый список: успех/провал каждой статьи, путь записи в репозиторий, число локализованных изображений. Для провальных указана причина (сбой одной статьи не мешает остальным). Можно продолжить «Импортировать следующий архив» или перейти в управление статьями и проверить результат.

## Вставка отдельной статьи

Мастер из пяти шагов: **выбор способа → вставка содержимого → преобразование → информация о статье → завершение**.

1. **Вставка** — откройте статью в веб-версии Цзяньшу, выделите всё и скопируйте, затем просто вставьте `Ctrl+V` в редактор: форматированный текст автоматически превращается в Markdown (заголовки, жирный, ссылки, изображения сохраняются); слева исходный код, справа предпросмотр, можно продолжить править вручную
2. **Преобразование** — после подтверждения сервер записывает в репозиторий: изображения автоматически скачиваются в каталог статьи (при сбое сохраняется удалённая ссылка), создаётся статья-каталог
3. **Информация о статье** — ИИ анализирует текст и **дополняет автоматически**: заголовок (если пусто, ИИ предложит), аннотацию, категорию, теги — всё можно поправить руками; без ИИ происходит откат к извлечению начала текста, о чём явно сообщается `aiUsed=false`
4. **Финализация** — метаданные записываются в статью, готово. Одним кликом можно перейти в [Редактирование статей](./post-editor.md) для тонкой доводки

> [!TIP]
> Поле заголовка тоже имеет страховку на случай вставки: если в буфере только форматированный текст (частая ситуация при копировании из веба), из него автоматически извлекается чистый текст и сжимается в одну строку.

## Сессии и задачи

- Загруженный архив образует **сессию** (результаты разбора кэшируются в памяти сервера) со сроком жизни 24 часа, одновременно держится максимум 3, при истечении срока или переполнении автоматически вытесняется самая старая — «Взять другой архив» немедленно отбрасывает текущую сессию
- Результаты фоновых задач импорта хранятся 1 час
- После перезапуска службы сессии и задачи в памяти очищаются — просто загрузите архив заново; **на импортированные статьи это не влияет** (они уже лежат в контент-репозитории)
