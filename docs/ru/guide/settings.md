# Настройки сайта

Страница «Настройки сайта» превращает все опции темы в формы: слева формы по разделам, справа встроенный [предпросмотр реального сайта](./dashboard.md#предпросмотр-реального-саита) — сохранили, предпросмотр обновился, что видите, то и получите.

Страница разделена на пять вкладок: **Основная информация**, **Навигация**, **Подвал**, **Внешний вид темы**, **Обои баннера**.

![Настройки сайта · Основная информация](/assets/guide/settings.png)

## Основная информация

Семь разделов, каждый сохраняется независимо:

| Раздел | Что настраивается |
|------|----------|
| Информация о сайте | Название, подзаголовок (для подзаголовка есть ИИ ✨ — генерация одной фразой) |
| Профиль | Аватар (онлайн-URL или локальная загрузка с автоматическим переименованием в репозиторий), ник, подпись (тоже с ИИ ✨) |
| Социальные ссылки | Список внешних ссылок вроде GitHub / Bilibili: название, иконка Iconify, адрес |
| Favicon сайта | Два слота: светлый / тёмный; без пользовательской настройки показывается подсказка о текущем действующем значке по умолчанию темы; загрузка автоматически именуется `favicon-light/dark.<ext>` и меняет файл на месте, можно и просто указать онлайн-адрес |
| Общие настройки | Адрес сайта (итоговый домен после развёртывания), подпуть (при установке в корень — `/`), часовой пояс (список частых + ручной ввод) |
| Панель отображения для посетителей | Переключатели видимости на фронтенде: выбор цветовой схемы, смена стандарта цветовой схемы, режим фона, вид списка, уменьшение анимаций, фоновая текстура |
| Интернационализация | Открывать ли многоязычность: отметьте набор языков — основной язык сайта обязан входить в него; выключено — весь сайт зафиксирован на упрощённом китайском |

## Навигация

Визуальный редактор навигационного меню:

- **Пресеты темы** — выбирайте из 15 встроенных пресетов (главная, архив, друзья сайта и др.) и подключайте одним кликом
- **Пользовательские ссылки** — название + иконка + адрес, можно пометить «открывать в новом окне»
- **Раскрывающиеся группы** — перетащите пункты во второй уровень, собирая однотипные входы

Конфигурация навигации сохраняется целиком, семантика массива — **полная замена**.

## Подвал

- **Переключатель включения** — добавлять ли пользовательское содержимое подвала над строкой копирайта темы
- **HTML-редактор** — редактор кода CodeMirror с кнопкой **форматирования Prettier**; исходный HTML подвала хранится в контент-репозитории в `config/footer.html`
- **Библиотека изображений подвала** — загрузка файла или вставка прямой онлайн-ссылки (сервер скачивает сам, webp автоматически конвертируется в png/jpg) с записью в `public/images/footer/`; кнопка «Копировать путь» вставляет путь в HTML
- **Предпросмотр в реальном времени** — iframe, приблизительно воспроизводящий рендер подвала темы: строка копирайта + ваш пользовательский блок

## Внешний вид темы

![Настройки сайта · Внешний вид темы](/assets/guide/settings-appearance.png)

Два раздела:

### Цветовая схема темы

- **Ползунок тона** (0–360) — рядом в реальном времени видна палитра из 5 уровней, генерируемая этим тоном
- **Фиксация** — если отмечено, тон сайта не меняется от контента/предпочтений посетителя
- **Стиль цветовой схемы** — 9 динамических стилей Material 3: tonalSpot (классический мягкий), vibrant (яркий), content (цвета из контента), expressive, rainbow, fruitSalad, monochrome, neutral, fidelity
- **Стандарт цветовой схемы** — два поколения стандартов Material 3: 2021 / 2025

### Обои и текстура

- **Режим фона по умолчанию** — banner / none, определяет вид фронтенда, когда обои не выбраны
- **Фоновая текстура** — шесть пресетов: none, starlight (звёздный свет), cyber-dots (киберточки), topography (изолинии), geometric (геометрия), sakura (сакура); прозрачность 0.05–0.25; переключатель разрешения анимации

## Обои баннера

Полный контроль над баннером главной страницы:

- **Два списка — обои для десктопа / для мобильных** — локальная загрузка, импорт по прямой онлайн-ссылке (сервер скачивает сам), кнопка **ИИ-подбор обоев** (выбирает партию с источника safebooru по размерам: десктоп — горизонтальные ≥1920, мобильные — вертикальные ≥1920; отметьте и скачайте в репозиторий)
- **Управление показом** — позиция (top/center/bottom), затемнение (переключатель + прозрачность)
- **Тексты главной** — заголовок, несколько подзаголовков, эффект печатной машинки (скорость/скорость удаления/пауза/цикл); для подзаголовков есть кнопка **ИИ-генерация** — на основе названия сайта и подписи одним запросом создаёт 4–6 ротационных фраз
- **Карусель** — включается при нескольких обоях: интервал смены, длительность перехода, шесть анимаций переключения (ken-burns медленный наезд, zoom-in/out, pan-left/right, none)
- **Волновой декор** — переключатель волновой анимации у нижней кромки баннера

> [!TIP]
> При сохранении баннера локальные файлы обоев, на которые больше не ссылается ни десктоп, ни мобильный список, **вычищаются автоматически** — удалять вручную не нужно.

## Куда записывается конфигурация

Все настройки пишутся в `config/*.yaml` контент-репозитория по принципу **минимального переопределения**: сохраняются только изменённые вами ключи, необъявленные поля наследуют значения темы по умолчанию — при обновлении темы с новыми опциями ваш сайт подхватит их автоматически и не застрянет на старой версии из-за «полного снимка». Ключи-словари сливаются рекурсивно, массивы заменяются целиком.
