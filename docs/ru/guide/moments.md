# Моменты

«Моменты» — более лёгкий формат, чем статьи: короткая мысль, пара картинок, значок настроения. Форма публикации находится вверху страницы, лента моментов — ниже; написал и сразу отправил.

![Моменты](/assets/guide/moments.png)

## Опубликовать момент

Карточка формы публикации, сверху вниз:

1. **Текст** — многострочное поле для текущей мысли
2. **Зона изображений** — максимум **9 штук**; загрузка кликом по + или прямой вставкой из буфера
3. **Строка метаданных** — настроение / место / теги / время публикации / закрепить
4. **Строка действий** — ИИ-полировка (при включённом ИИ) / сохранить черновик / опубликовать

### Значки настроения

Девять предустановленных вариантов: 😊 радость, 🤩 восторг, 😐 спокойствие, 😔 уныние, 😢 грусть, ❤️ нравится, 🎉 празднование, ☕ бокальчик, 🌙 спокойной ночи. Значок хранится по имени Iconify (все встроены локально, сетевых запросов нет), на фронтенде рендерится соответствующая иконка.

### Как архивируются изображения

Все изображения одной публикации попадают в **один и тот же каталог партии**:

```
public/images/moments/<yyyymmdd-HHmmss>/   # номер партии совпадает с именем файла момента
├── 1.webp
└── 2.webp
```

Даже при одновременной загрузке нескольких файлов они попадают в одну партию (номер партии генерируется заранее). Это правило не произвольно: конвейер генерации миниатюр темы **сканирует только** `public/images/moments/` — положи изображения куда-то ещё, фронтенд не сможет построить миниатюры, поэтому бэкенд жёстко закрепляет место записи.

> [!TIP]
> Убрать изображение перед публикацией — значит лишь исключить его из этой публикации, файл остаётся в репозитории; при удалении момента целиком файлы иллюстраций тоже сохраняются — при необходимости чистите вручную.

### ИИ-помощь (опционально)

При включённом ИИ в форме публикации появляются два дополнительных входа:

- **ИИ-полировка** — потоково переписывает текст, результат прямо «вырастает» в поле ввода (разговорная естественность с сохранением тона и фактов); можно остановить в любой момент, остановка возвращает исходный текст
- **ИИ-подсказки** — извлекает из текста 2–4 тега (сливает с существующими без повторов) и угадывает настроение (уже выбранное не перезаписывает)

## Управление лентой

Список ниже поддерживает комбинированные фильтры и постраничный вывод (по 8 на страницу):

| Фильтр | Описание |
|------|------|
| Строка поиска | Поиск по тексту, месту и тегам |
| Выпадающий список статусов | Все / Опубликованные / Черновики |
| Множественный выбор тегов | Клик по тегу на карточке тоже быстро фильтрует (повторный клик снимает) |
| Только закреплённые | Флажок |

Каждая карточка момента даёт:

- **Редактирование** — содержимое возвращается в форму публикации выше (новые загрузки идут в **новую партию**, не смешиваясь со старым каталогом); после правок нажмите «Опубликовать» для сохранения
- **Переключение закрепления** — закрепить/открепить одним кликом, список обновляется немедленно
- **Удаление** — после повторного подтверждения удаляет файл `.md` (иллюстрации сохраняются)

## Отличие моментов от статей

| | Статья | Момент |
|---|------|------|
| Форма контента | Длинный текст + система метаданных | Короткий текст + картинки + настроение |
| Хранение | `content/posts/<slug>/index.md` | `content/moments/<yyyymmdd-HHmmss>.md` |
| Типичное применение | Туториалы, заметки, глубокие размышления | Текущие дела, мелочи, записи на бегу |
