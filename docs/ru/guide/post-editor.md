# Редактирование статей

Редактор статей — самая насыщенная страница панели. Сюда попадают после создания статьи в [Управлении статьями](./posts.md) или по кнопке «Редактировать»; полная страница редактирования уже содержит **двухпанельный предпросмотр в реальном времени**, а редактирование на месте в списке статей — это тот же редактор в однопанельной форме.

![Редактирование статей](/assets/guide/post-editor.png)

## Верхняя панель

Слева направо:

| Кнопка | Действие |
|------|------|
| Назад | Автосохранение и возврат на предыдущую страницу |
| Поле заголовка | Крупное поле на постоянной основе; переименование в любой момент |
| Информация о статье | Открывает панель метаданных (см. ниже) |
| Удалить | Удаляет статью и все иллюстрации в её каталоге; требуется повторное подтверждение |
| Сохранить | Немедленная запись в контент-репозиторий |
| Сохранить и опубликовать | Сохранить и сразу перейти к [Коммиты и публикация](./publish.md) |

В верхней панели также отображается «Автосохранение HH:mm:ss» — время последнего автосохранения.

## Редактор

Редактор работает в **режиме исходного кода Markdown** (на базе md-editor-v3 + CodeMirror): вы пишете Markdown-исходник, а правая панель рендерит предпросмотр в реальном времени. Панель инструментов покрывает частые потребности вёрстки: жирный, курсив, зачёркивание, заголовки, цитаты, списки, задачи, строковый код, блоки кода, ссылки, изображения, таблицы, отмену/повтор, а также переключение предпросмотр/оглавление.

**Иллюстрации без хлопот**: вставьте скриншот в редактор или загрузите через кнопку изображения — файл автоматически сохранится в подкаталог `images/` каталога текущей статьи, а в текст автоматически встанет относительная ссылка (`./images/xxx.webp`). Статья благодаря этому самодостаточна — скопированный каталог целиком и есть готовая статья.

Когда ИИ включён, в конце панели инструментов появляется дополнительный **выпадающий ИИ-инструмент** — см. ниже [ИИ-помощь в написании](#ии-помощь-в-написании).

## Панель информации о статье

Панель «Информация о статье» собирает все метаданные (соответствуют frontmatter статьи):

### Основные поля

- **Дата публикации** (`YYYY-MM-DD`) и **точное время** — управляют сортировкой при публикации нескольких статей в один день; часовой пояс автоматически нормализуется к `+08:00`
- **Категория** — выбор существующей из списка (с числом использования) или ввод нового имени с Enter для создания
- **Теги** — множественный выбор; создание вводом тоже поддерживается
- **Аннотация** — если пусто, тема автоматически берёт начало текста; обложка загружается локально или задаётся внешней ссылкой
- **Переключатели** — черновик / закреплено / комментарии / пароль

### Защита паролем

После отметки «Пароль» раскрываются три поля:

- **Пароль доступа** — для статей, где он уже задан: ввод меняет пароль, пустое поле оставляет прежним; снятие отметки «Пароль» удаляет пароль
- **Подсказка к паролю** — текст, который посетитель видит перед вводом пароля
- **Скрывать предпросмотр в карточке на главной** — не даёт защищённому контенту утечь на главную в виде аннотации

### Путь доступа

Три режима определяют итоговый URL статьи; внизу — предпросмотр адреса в реальном времени:

| Режим | Форма адреса | Когда применять |
|------|----------|----------|
| По умолчанию | `/posts/<имя-статьи>/` | Обычные статьи |
| Пользовательский псевдоним | `/posts/<псевдоним>/` | Хочется более короткий и осмысленный URL |
| Постоянная ссылка от корня | `/<пользовательский-путь>/` | Выверенная витринная страница, например `/about-me/` |

## ИИ-помощь в написании

> [!NOTE]
> Функции ниже требуют включённого ИИ-ассистента ([как настроить](./ai.md#настроика-проваидеров)). Пока ИИ выключен, вход в панели инструментов не появляется, возможности письма не затрагиваются.

Выпадающий ИИ-инструмент содержит 5 действий + произвольную инструкцию; все действия **не трогают код и приватный синтаксис темы Shirone** (контейнеры из трёх двоеточий, file-tree и др.):

| Действие | Область действия | Как применяется результат |
|------|----------|--------------|
| ИИ: улучшить содержание | Весь текст | Закрывает пробелы в рассуждениях, усиливает логические связки — сначала предпросмотр, потом применение |
| ИИ: навести формат | Весь текст | Выравнивает уровни заголовков, унифицирует пунктуацию, дополняет языки у блоков кода — сначала предпросмотр, потом применение |
| ИИ: полировка | **Сначала выделенное** | Есть выделение — прямая замена; без выделения — diff-предпросмотр всего текста |
| ИИ: дописать | Конец текста | Естественное продолжение с конца; результат дописывается в конец |
| ИИ: сгенерировать аннотацию | Весь текст | Генерирует аннотацию 80–160 знаков и заполняет «Информацию о статье» (при существующей аннотации сначала спросит) |
| Произвольная инструкция | Выделенное или весь текст | Выполняется любая команда (например «переписать более разговорным стилем») |

**Diff-предпросмотр** — страховка действий с перезаписью всего текста (улучшение/формат/полировка без выделения/произвольная инструкция): результат ИИ потоково обновляется в виде двухпанельного сравнения различий, длинные неизменённые блоки сворачиваются автоматически, кнопки «Предыдущее/Следующее» позволяют переходить по фрагментам. Только после проверки «Применить замену» действительно переписывает текст; остановленный на середине генерации результат неполон и к применению не допускается. Если длина текста изменилась более чем на 20 %, рамка предпросмотра предупреждает красным — просите проверить внимательнее.

Все ИИ-действия выполняются в глобальной [ИИ-консоли](./ai.md#ии-консоль): виден процесс размышления, в любой момент можно остановить.

## Автосохранение

В редакторе действует ненавязчивый механизм автосохранения:

- Проверка каждые **10 секунд**; на диск молча сохраняется, только если заголовок или текст изменились
- **При переключении статьи, нажатии «Назад» и уходе со страницы редактирования** тоже сначала выполняется автосохранение
- Единственное, что вас остановит: пустой заголовок (записать невозможно) — тогда появится подсказка сначала заполнить заголовок

Автосохранение покрывает только заголовок и текст; метаданные в панели «Информация о статье» сохраняются кнопкой «Сохранить».
