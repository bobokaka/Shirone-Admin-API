# Статьи

Модуль статей работает напрямую с `content/posts/` контент-репозитория. Все параметры-пути — пути в стиле POSIX относительно этой директории. Список: **закреплённые сверху, далее по дате публикации по убыванию**.

## GET /api/posts

Возвращает список метаданных всех статей (без текста).

**Возвращаемое значение** `PostMeta[]`, ключевые поля каждой записи:

| Поле | Тип | Описание |
|------|------|------|
| `slug` | `string` | Имя каталога (для статьи-каталога) или имя файла без `.md` |
| `path` | `string` | Относительный путь, например `hello/index.md` |
| `layout` | `"directory" \| "file"` | Каталогом / плоско |
| `title` / `published` / `description` / `image` / `category` / `tags` | — | Метаданные; `published` в формате `YYYY-MM-DD` |
| `publishedAt` / `updated` / `updatedAt` | `string?` | Точное время и время обновления |
| `pinned` / `draft` / `comment` / `encrypted` / `hideHomeContent` | `boolean` | Переключатели |
| `hasPassword` | `boolean` | Задан ли пароль (**сам пароль никогда не возвращается**) |
| `passwordHint` | `string` | Подсказка к паролю |
| `alias` / `permalink` | `string?` | Пользовательский путь доступа |

```bash
curl http://127.0.0.1:5175/api/posts
```

## GET /api/posts/detail

Читает полное содержимое одной статьи.

| Query-параметр | Обязателен | Описание |
|------------|------|------|
| `path` | да | Относительный путь статьи |

**Возвращаемое значение** `PostFile`: `{ meta: PostMeta, body: string }`. Если путь не существует — `404`.

```bash
curl "http://127.0.0.1:5175/api/posts/detail?path=hello/index.md"
```

## POST /api/posts

Создаёт статью (в статусе **черновика**). Записывается каталогом как `content/posts/<slug>/index.md`.

| Поле body | Тип | Обязателен | По умолчанию | Описание |
|-----------|------|------|------|------|
| `title` | `string` | да | — | Заголовок; не может быть пустым |
| `slug` | `string` | нет | транслитерация заголовка пиньинем | Пользовательское имя каталога; недопустимые символы вычищаются, совпадения разносятся |

**Возвращаемое значение** `PostFile` (созданная статья). **Побочные эффекты**: создаёт каталог и `index.md` в контент-репозитории; при отсутствующем `slug` подбирает уникальный относительно существующих статей.

```bash
curl -X POST http://127.0.0.1:5175/api/posts \
  -H "Content-Type: application/json" \
  -d '{"title":"我的第一篇文章"}'
```

## PUT /api/posts

Сохраняет статью. Frontmatter **дописывается слиянием**: обновляются только ключи, присутствующие в `meta`; текст заменяется целиком; сериализация гарантирует неизменность формата дат вроде `published`.

| Поле body | Тип | Обязателен | По умолчанию | Описание |
|-----------|------|------|------|------|
| `path` | `string` | да | — | Путь целевой статьи |
| `body` | `string` | нет | `""` | Полный текст (замена целиком) |
| `meta` | `object` | нет | `{}` | Обновляемые ключи-значения frontmatter; пустая строка в `alias`/`permalink` удаляет ключ |
| `password` | `string` | нет | — | Передавать **только при установке/смене пароля**; без параметра прежнее значение сохраняется |
| `clearPassword` | `boolean` | нет | — | При `true` удаляет пароль (например при снятии защиты) |

**Возвращаемое значение** сохранённый `PostFile`.

```bash
curl -X PUT http://127.0.0.1:5175/api/posts \
  -H "Content-Type: application/json" \
  -d '{"path":"hello/index.md","meta":{"draft":false},"body":"# 你好\n\n正文。"}'
```

## DELETE /api/posts

Удаляет статью. Статья-каталог удаляется только на верхнем уровне `slug` (весь каталог вместе с иллюстрациями), плоская — одним файлом.

| Query-параметр | Обязателен | Описание |
|------------|------|------|
| `path` | да | Относительный путь статьи |

**Возвращаемое значение** `{ "ok": true }`.

```bash
curl -X DELETE "http://127.0.0.1:5175/api/posts?path=hello/index.md"
```

## POST /api/slug

Генерирует или вычищает slug (транслитерация заголовка пиньинем, замена недопустимых символов, разводка совпадений с существующими статьями).

| Поле body | Тип | Обязателен | Описание |
|-----------|------|------|------|
| `title` | `string` | нет (по умолчанию `""`) | Заголовок; используется для генерации, только если **`slug` не передан** |
| `slug` | `string` | нет | Если передан — только вычищается, не генерируется |

**Возвращаемое значение** `SlugSuggestion`: `{ slug: string, adjusted: boolean, note?: string }` — `adjusted=true` означает, что была замена или разводка совпадений, причину поясняет `note`.

```bash
curl -X POST http://127.0.0.1:5175/api/slug \
  -H "Content-Type: application/json" \
  -d '{"title":"快速上手指南"}'
```

## POST /api/taxonomy/rename

Массовое переименование категории/тега: переписывает frontmatter **всех затронутых статей**. Если целевое имя уже существует — слияние; пустая строка в `to` = удаление из всех статей.

| Поле body | Тип | Обязателен | Описание |
|-----------|------|------|------|
| `kind` | `"category" \| "tag"` | да | Что переименовывается — категория или тег |
| `from` | `string` | да | Исходное имя (не может быть пустым) |
| `to` | `string` | да | Целевое имя; пустая строка = удалить |

**Возвращаемое значение** `{ changed, kind, from, to }` — `changed` равно числу переписанных статей. **Побочные эффекты**: пофайловая перезапись (в сценарии тегов с автодедупликацией), формат полей дат не меняется.

```bash
curl -X POST http://127.0.0.1:5175/api/taxonomy/rename \
  -H "Content-Type: application/json" \
  -d '{"kind":"tag","from":"JS","to":"JavaScript"}'
```
