# Моменты

Модуль моментов работает с `content/moments/` контент-репозитория: один Markdown-файл на запись, имя файла — это id: `<yyyymmdd-HHmmss>.md`. Список отсортирован по времени по убыванию.

## Структура MomentMeta

Метаданные, общие для списка и деталей:

| Поле | Тип | Описание |
|------|------|------|
| `id` | `string` | Имя файла без `.md`, например `20260906-183000` |
| `path` | `string` | Относительный путь |
| `published` | `string` | `YYYY-MM-DD HH:mm:ss` |
| `pinned` / `draft` | `boolean` | Закреплено / черновик |
| `location` | `string` | Место |
| `mood` | `string` | Значок настроения — имя иконки Iconify (пустая строка — не выбрано) |
| `tags` | `string[]` | Теги |
| `images` | `{ src, alt }[]` | Иллюстрации; `src` — путь на сайте |
| `body` | `string` | Текст (включён уже в список) |

## GET /api/moments

Полный список, без параметров.

```bash
curl http://127.0.0.1:5175/api/moments
```

## GET /api/moments/detail

| Query-параметр | Обязателен | Описание |
|------------|------|------|
| `path` | да | Относительный путь момента |

**Возвращаемое значение** `MomentFile`: `{ meta: MomentMeta, body: string }`.

```bash
curl "http://127.0.0.1:5175/api/moments/detail?path=20260906-183000.md"
```

## POST /api/moments

Создаёт момент. **Побочные эффекты**: пишет `content/moments/<метка-времени-публикации>.md`; файлы, на которые ссылаются `images`, уже должны лежать в репозитории через [загрузку изображений моментов](./media.md#post-api-media-moment-image).

| Поле body | Тип | Обязателен | По умолчанию | Описание |
|-----------|------|------|------|------|
| `published` | `string` | да | — | `YYYY-MM-DD HH:mm:ss`, определяет имя файла |
| `body` | `string` | нет | `""` | Текст |
| `location` | `string` | нет | — | Место |
| `mood` | `string` | нет | — | Имя значка настроения |
| `tags` | `string[]` | нет | — | Теги |
| `images` | `{ src, alt? }[]` | нет | — | Список иллюстраций |
| `draft` / `pinned` | `boolean` | нет | `false` | Черновик / закреплено |

**Возвращаемое значение** созданный `MomentMeta`.

```bash
curl -X POST http://127.0.0.1:5175/api/moments \
  -H "Content-Type: application/json" \
  -d '{"published":"2026-09-10 10:30:00","body":"第一条说说！","mood":"material-symbols:celebration","tags":["开始"]}'
```

## PUT /api/moments

Обновляет момент; поля те же, что выше, плюс:

| Поле body | Тип | Обязателен | Описание |
|-----------|------|------|------|
| `path` | `string` | да | Путь целевого момента |

Непереданные необязательные поля откатываются к значениям по умолчанию (семантика полной перезаписи); самый надёжный шаблон — сначала прочитать detail, изменить и записать (интерфейс управления делает именно так).

```bash
curl -X PUT http://127.0.0.1:5175/api/moments \
  -H "Content-Type: application/json" \
  -d '{"path":"20260906-183000.md","published":"2026-09-06 18:30:00","body":"改过了","pinned":true}'
```

## DELETE /api/moments

Удаляет момент (файл `.md`). **Файлы иллюстраций не удаляются вместе с ним** — при необходимости вручную почистите соответствующий каталог партии в `public/images/moments/`.

| Query-параметр | Обязателен | Описание |
|------------|------|------|
| `path` | да | Относительный путь момента |

**Возвращаемое значение** `{ "ok": true }`.

```bash
curl -X DELETE "http://127.0.0.1:5175/api/moments?path=20260906-183000.md"
```
