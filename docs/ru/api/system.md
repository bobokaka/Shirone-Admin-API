# Система и предпросмотр

Системный модуль отвечает на два вопроса: **нормально ли подключено рабочее пространство** и **запущен ли dev-сервер фронтенда блога**. Метка подключения в верхней панели и панели предпросмотра реального сайта на страницах работают именно на этой группе интерфейсов.

## GET /api/status

Проверяет состояние рабочего пространства. Без параметров, ошибок не выдаёт никогда (поля с внутренним сбоем возвращают `null`/`false`).

**Возвращаемое значение** `SystemStatus`:

| Поле | Тип | Описание |
|------|------|------|
| `contentDir` / `themeDir` | `string` | Разрешённые абсолютные пути контент-репозитория / репозитория темы (источник: `.env` или относительные позиции по умолчанию) |
| `contentConnected` | `boolean` | `true`, если в директории контент-репозитория есть `content/` |
| `themeConnected` | `boolean` | `true`, если в репозитории темы есть `scripts/content/sync.mjs` |
| `themeDepsInstalled` | `boolean` | `node_modules` репозитория темы установлен (определяет возможность локальной проверки) |
| `git` | `GitStatus \| null` | Сводка git контент-репозитория; `null`, если это не git-репозиторий |

`GitStatus`: `branch`, `ahead`, `behind`, `staged[]`, `modified[]`, `untracked[]` (списки относительных путей файлов).

```bash
curl http://127.0.0.1:5175/api/status
```

```json
{
  "contentDir": "D:\\blogs\\Shirone-Content",
  "themeDir": "D:\\blogs\\Shirone",
  "contentConnected": true,
  "themeConnected": true,
  "themeDepsInstalled": true,
  "git": { "branch": "main", "ahead": 0, "behind": 0, "staged": [], "modified": [], "untracked": [] }
}
```

## POST /api/preview/start

Поднимает процесс предпросмотра реального сайта: в репозитории темы запускаются `content:watch` (отслеживающая синхронизация контента) и `astro dev` (:4321). Если уже запущено, сразу возвращается «уже запущено». **Побочные эффекты**: создаются два дерева фоновых процессов; в Windows запуск идёт через `cmd /c`, при выходе службы они снимаются через `taskkill` вместе с деревом.

```bash
curl -X POST http://127.0.0.1:5175/api/preview/start
```

```json
{ "started": true, "message": "真站预览已启动，首次启动需等待依赖编译" }
```

Готовность определяйте опросом `/api/preview/status` (первый запуск требует компиляции, готовность наступает позже старта).

## POST /api/preview/stop

Завершает дерево процессов предпросмотра. **Побочные эффекты**: убивает все дочерние процессы, запущенные start; если dev-сервер запущен из другого источника (например скриптом единого запуска), он не затрагивается.

```bash
curl -X POST http://127.0.0.1:5175/api/preview/stop
```

Возвращает `{ "stopped": true }`.

## GET /api/preview/status

Запрашивает состояние предпросмотра; фронтенд опрашивает раз в 3 секунды.

```bash
curl http://127.0.0.1:5175/api/preview/status
```

```json
{ "running": true, "ready": true, "procs": ["node content-watch.mjs", "astro dev"] }
```

| Поле | Описание |
|------|------|
| `running` | Управляемый этой службой процесс предпросмотра работает |
| `ready` | `http://localhost:4321/` фактически достижим (подходит dev-сервер из любого источника) |
| `procs` | Список описаний процессов |
