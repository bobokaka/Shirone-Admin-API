# 文章管理

「文章管理」页是你与文章打交道的主入口：浏览全部文章、按分类标签筛选、快速预览正文，以及批量整理分类体系。

![文章管理](/assets/guide/posts.png)

页面分为左右两栏：**左侧文章列表**（筛选 + 选中），**右侧内容预览**（阅读或就地编辑）。点击左侧任意文章，右侧立即渲染它的 Markdown 正文。

## 新建文章

点工具栏「**新建文章**」，在弹窗里输入标题（创建后随时可改），确认后：

1. 后端在内容仓 `content/posts/` 下创建一篇**草稿状态**的文章
2. 自动跳转到[文章编辑](./post-editor.md)页开始写作

文章标题会经拼音转写生成 URL 友好的目录名（slug），例如《快速上手指南》→ `kuai-su-shang-shou-zhi-nan/index.md`。重名时自动加序号。

## 浏览与筛选

工具栏提供三个筛选器，可组合使用：

| 筛选器 | 行为 |
|--------|------|
| 搜索框 | 同时匹配**标题、分类、标签**（不区分大小写） |
| 分类下拉 | 只显示该分类的文章，选项后括号内是该分类的文章数 |
| 标签下拉 | 只显示含该标签的文章 |

列表头部实时显示「文章（筛选后 / 全部）」。每行文章显示标题、发布日期、分类，以及状态标签：黄色「草稿」、「置顶」、红色「加密」。

## 预览与就地编辑

选中文章后右侧展示：

- **标题与元信息**：日期、分类、标签、草稿/置顶/加密标签
- **正文渲染**：Markdown 实时渲染，文章目录内的配图（`./images/…` 相对引用）直接显示
- **编辑**按钮：右栏原地切换为完整编辑器（与[文章编辑](./post-editor.md)页同一套界面，只是不带分栏预览）。编辑器右上角的「分栏编辑」图标可跳转到带左右分栏预览的完整编辑页，返回时自动恢复到这篇文章的编辑状态
- **删除**按钮：目录式文章会提示「将删除该文章及其目录下全部配图」；已提交过 git 的内容可从历史恢复

> [!TIP]
> 在就地编辑状态下切换左侧文章时，若有未保存改动会**先静默自动保存**再切换，不会丢稿（详见[文章编辑 · 自动保存](./post-editor.md#自动保存)）。

## 分类 / 标签管理

工具栏右侧「**分类管理**」打开批量整理弹窗，这是全站分类体系唯一需要维护的地方：

- 顶部分类 / 标签两个页签，列表按**使用文章数降序**排列
- **重命名 / 合并**：把某个分类（或标签）改名为新名字；如果新名字已存在，等于把两者**合并**。后端会逐篇改写文章 frontmatter 并保持日期格式不变
- **移除**：从所有文章中删掉这个分类/标签（文章本身不受影响）

例如想把零散的「JS」「JavaScript」统一成「JavaScript」：对「JS」执行重命名，填 `JavaScript`，确认后所有相关文章自动改写。

## 文章在磁盘上的形态

理解存储形式，备份与排查时更从容：

```
content/posts/
├── hello/                  # 目录式（新建文章默认）：配图随文管理
│   ├── index.md
│   └── images/
│       └── cover.webp
└── old-post.md             # 平铺式（历史文章或外部导入）：单文件
```

- 新建文章一律是**目录式**，编辑器里上传的配图自动进该目录的 `images/` 子目录
- 列表按**置顶优先、发布日期倒序**排列
