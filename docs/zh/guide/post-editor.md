# 文章编辑

文章编辑器是后台功能最密集的页面。从[文章管理](./posts.md)新建文章、或点「编辑」后进入，完整编辑页自带**左右分栏实时预览**；文章管理页内的就地编辑则是同一套编辑器的单栏形态。

![文章编辑](/assets/guide/post-editor.png)

## 顶栏操作

从左到右：

| 按钮 | 作用 |
|------|------|
| 返回 | 自动保存后回到上一页面 |
| 标题输入框 | 常驻大号输入框，随时改名 |
| 文章信息 | 打开元信息抽屉（见下文） |
| 删除 | 删除文章及其目录下全部配图，需二次确认 |
| 保存 | 立即落盘内容仓 |
| 保存并去发布 | 保存后直接跳转[提交和发布](./publish.md) |

顶栏还会显示「已自动保存 HH:mm:ss」提示最近一次自动保存的时间。

## 编辑器

编辑器采用 **Markdown 源码模式**（基于 md-editor-v3 + CodeMirror），你直接书写 Markdown 源码，右侧分栏实时渲染预览。工具栏提供常用排版：加粗、斜体、删除线、标题、引用、列表、任务、行内代码、代码块、链接、图片、表格、撤销/重做，以及预览/目录切换。

**配图零负担**：编辑器里粘贴截图或通过图片按钮上传，文件自动存入当前文章目录的 `images/` 子目录，正文自动插入相对引用（`./images/xxx.webp`）。文章因此是自包含的——整个目录拷走就是完整的一篇。

AI 启用后，工具栏末尾会多出一个 **AI 下拉工具**，详见下文 [AI 辅助写作](#ai-辅助写作)。

## 文章信息抽屉

「文章信息」抽屉收纳全部元数据（对应文章 frontmatter）：

### 基础字段

- **发布日期**（`YYYY-MM-DD`）与**精确时间**——同一天发布多篇文章时用它控制排序，时区自动按 `+08:00` 规范化
- **分类**——下拉可选已有分类（附使用计数），直接输入新名字回车即新建
- **标签**——多选，同样支持输入新建
- **摘要**——留空时主题自动截取正文前段；封面支持本地上传或外链
- **开关**——草稿 / 置顶 / 评论 / 加密

### 加密文章

勾选「加密」后展开三个字段：

- **访问密码**——已设置过的文章，输入则修改、留空保持不变；取消勾选「加密」即清除密码
- **密码提示**——访客输入密码前看到的提示语
- **首页卡片隐藏预览**——防止加密内容以摘要形式泄露到首页

### 访问路径

三种模式决定文章的最终 URL，底部有实时地址预览：

| 模式 | 地址形态 | 适用场景 |
|------|----------|----------|
| 默认 | `/posts/<文章名>/` | 常规文章 |
| 自定义别名 | `/posts/<别名>/` | 想要更短、更语义化的 URL |
| 根路径固定链接 | `/<自定义路径>/` | 精心制作的招牌页面，如 `/about-me/` |

## AI 辅助写作

> [!NOTE]
> 以下功能需要先启用 AI 助手（[配置方法](./ai.md#配置服务商)）。未启用时工具栏不出现 AI 入口，写作功能不受影响。

AI 下拉工具内置 5 个动作 + 自定义指令，所有动作都会**原样保留代码与 Shirone 主题私有扩展语法**（三冒号容器、file-tree 等）：

| 动作 | 作用范围 | 结果如何应用 |
|------|----------|--------------|
| AI完善内容 | 全文 | 补全论述缺口、增强逻辑衔接——先预览再应用 |
| AI格式优化 | 全文 | 规范标题层级、统一标点、补全代码围栏语言——先预览再应用 |
| AI润色 | **选中优先** | 有选中文本直接替换；无选中走全文 diff 预览 |
| AI续写 | 文末 | 从结尾自然延续，结果追加到正文末尾 |
| AI生成摘要 | 全文 | 生成 80–160 字摘要回填「文章信息」（已有摘要会先确认） |
| 自定义指令 | 选中或全文 | 输入任意指令（如「改成更口语化的风格」）后执行 |

**diff 预览**是全文改写类动作（完善/格式优化/无选中润色/自定义指令）的安全网：AI 结果以左右对照的差异视图流式刷新，长段未变行自动折叠，可用「上一处/下一处」逐块跳转。核对后「应用替换」才真正改写正文；停止生成的内容不完整，不允许应用。正文长度变化超过 20% 时预览框会红字警示，提醒仔细核对。

所有 AI 动作在全局 [AI 控制台](./ai.md#ai-控制台)里执行：思考过程可见、随时可停止。

## 自动保存

编辑器有一套不打扰的自动保存机制：

- 每 **10 秒**检查一次，标题或正文有改动才静默落盘
- **切换文章、点击返回、离开编辑页**的瞬间也会先自动保存
- 唯一会拦下你的情况：标题为空（无法落盘），此时会提示先填标题

自动保存只覆盖标题与正文；「文章信息」抽屉里的元数据通过「保存」按钮落盘。
