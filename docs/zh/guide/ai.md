# AI 助手

Shirone-Admin 的 AI 能力是**可选增强**：不配置，所有功能照常工作；配置后，写作、导入、发布各环节多出一系列智能辅助。本章先讲配置，再讲使用。

## 配置服务商

点顶栏**齿轮**打开「设置」弹窗，左侧菜单选「AI助手」。

![AI 服务商配置](/assets/guide/app-settings.png)

### 核心概念

- **多服务商**——可保存多套连接配置（最多 20 套），随时切换生效的那套。适合同时持有官方 API 与中转代理、或多模型按需切换的人
- **双协议**——每套配置二选一：
  - `anthropic`——Anthropic 兼容协议（`v1/messages`），适配官方 API 及各家「Anthropic 兼容」中转
  - `openai`——OpenAI 兼容协议（`chat/completions`），适配 OpenAI 及绝大多数国产模型 API
- **总开关**——「启用」关闭时所有 AI 入口隐藏，API 一律拒绝

### 每套配置的字段

| 字段 | 说明 |
|------|------|
| 名称 | 显示名，如 `Anthropic 官方` / `GLM 中转` |
| 协议 | anthropic / openai |
| API 地址 | 根地址即可（`https://api.anthropic.com` 或 `https://api.openai.com/v1`），容忍裸根、带 `/v1`、代理子路径等写法 |
| API Key | 仅保存在本机 `server/data/ai-settings.json`，**绝不写入内容仓**、不会随发布泄漏 |
| 主模型 | 日常任务用，如 `claude-sonnet-5` / `gpt-4o-mini` / `glm-5.3` |
| 轻量模型 | 摘要、标签建议等简单任务用；**留空 = 同主模型**（省一份配置） |
| 联网检索 | 给支持的服务附加 web 检索工具；服务端不支持时自动降级为普通请求 |
| 温度 | 采样温度 0–2，默认 0.7 |
| 超时 | 单次请求超时秒数，5–86400，默认 30 |

### 操作流程

1. 点 + **新增服务商**（默认名「默认配置 N」，直接输入即改名）
2. 填写字段，或用**粘贴导入**：把 Claude Code 的 `settings.json` env 块、shell `export` 语句或 dotenv 内容整段粘进去，自动识别 `ANTHROPIC_*` / `OPENAI_*` 等 10 个键填表
3. **测试连接**——无需保存即可测，返回延迟与模型应答；通过后再**保存**

> [!WARNING]
> `server/data/ai-settings.json` 里是明文 API Key。该文件已被 gitignore，但请避免把它拷贝到任何会被提交或分享的位置。

## AI 控制台

顶栏 **✨ 按钮**打开的全局浮窗，是所有 AI 任务的执行现场：

![AI 控制台](/assets/guide/ai-console.png)

两种形态：

- **任务形态**——从各功能页触发的 AI 动作（润色、续写、起草…）在这里执行：带「任务」角标的指令条目、模型**思考过程**（可折叠）、正文流式上屏、耗时与所用模型标注
- **对话形态**——任务结束后直接在输入框追问（携带上文继续改稿），或纯聊天提问；Enter 发送、Shift+Enter 换行

通用能力：**随时停止**（停止后已有内容按场景保留或恢复）、标题条点击**收起**不占屏、**新对话**清空重来。多轮对话历史超 6 万字符时自动从最旧丢弃；思考流保留最近 8000 字符。

## 各页面的 AI 入口

启用后这些位置会出现 AI 功能（按页面整理）：

| 页面 | 入口 | 能力 |
|------|------|------|
| [文章编辑](./post-editor.md#ai-辅助写作) | 工具栏 AI 下拉 | 完善内容 / 格式优化 / 润色（选中优先）/ 续写 / 生成摘要 / 自定义指令，全文改写带 diff 预览 |
| [说说动态](./moments.md#ai-辅助可选) | 发布器按钮 | 正文润色（流式回填）、标签与心情建议 |
| [数据管理](./data.md#字段级-ai) | 编辑弹窗 ✨ | 项目/技能/番剧等描述字段生成与改写 |
| [数据管理 · 时间线](./data.md#时间线-ai-起草) | AI起草按钮 | git 历史归纳 / 描述起草事件，勾选插入 |
| [数据管理 · 歌单](./data.md#歌单-导入音乐) | 导入音乐 | 联网检索曲目并附版权信息 |
| [站点设置](./settings.md#基础信息) | 输入框 ✨ | 副标题、签名一句话生成 |
| [站点设置 · 横幅](./settings.md#横幅壁纸) | AI生成文案 | 打字机轮播文案整组生成 |
| [平台导入](./import.md#单篇粘贴) | 自动触发 | 粘贴文章的标题/摘要/分类/标签补全 |
| [提交和发布](./publish.md#提交信息) | AI生成按钮 | 双仓提交信息生成（不合规自动回退） |

此外编辑器工具栏的 AI 菜单在生成期间会显示加载动画并禁用重复触发；所有流式任务共用一个控制台，同一时间只跑一个。

## 设计哲学

- **AI 永不阻断主流程**——提交信息生成失败自动回退启发式；导入元信息失败回退正文摘要；润色停止即恢复原文
- **结果先预览再应用**——全文改写类一律走 diff 确认，不直接覆盖你的文字
- **轻量任务用轻量模型**——标签建议、摘要等小任务走 `modelFast` 并关闭思考，省钱省时
