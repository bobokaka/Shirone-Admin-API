# 平台导入

正在其他平台写博？「平台导入」页提供迁移通道，当前支持**简书**，页面顶部按平台分页签，后续平台以此扩展。

导入有两条路径，进入页面先二选一：

| 方式 | 适合 | 输入 |
|------|------|------|
| **导出包导入** | 整站搬迁、几十上百篇 | 简书官方「打包下载全部文章」得到的 rar / zip |
| **单篇粘贴** | 精选单篇、即贴即转 | 网页版文章页全选复制的内容 |

![平台导入](/assets/guide/import.png)

## 导出包导入

五步向导：**选择方式 → 上传导出包 → 选择文章 → 内容转换 → 导入完成**。

### 第 1 步：上传导出包

在简书「设置 → 账号管理 → 打包下载全部文章」申请导出（简书会发邮件给下载链接），得到压缩包后拖入上传区。限制：zip / rar 格式，单包 ≤30MB。

上传后服务端在内存中解包解析，按**文集**分组列出全部文章。

### 第 2 步：选择文章

- 解析成功后**默认全选**未导入过的文章
- 支持按文集整组勾选、全选/清空
- 已导入过的文章标记「已导入」并禁选，防止重复
- 每篇文章可先「预览」——不落盘查看转换后的 Markdown 效果

页面右侧设置导入选项：

| 选项 | 说明 |
|------|------|
| 统一发布日期 | 简书导出包不含日期，所有文章套用同一发布日（之后可逐篇改） |
| 文集作分类 | 勾选后每个文集名直接成为文章分类；不勾则手动指定一个统一分类 |
| 标签 | 为本批文章统一追加标签 |
| 图片本地化 | 把简书 CDN 图片下载进各文章的 `images/` 目录；下载失败的保留远程链接 |
| 导入为草稿 | **建议保持勾选**——先在[文章管理](./posts.md)过目再发布 |

### 第 3 步：内容转换

点击开始后服务端创建**后台任务**逐篇转换，页面每 2 秒轮询进度：总数、已完成、当前正在处理的文章标题。中途可以离开页面，任务继续跑。

### 第 4 步：完成

任务结束展示结果清单：每篇的成败、落仓路径、本地化图片数。失败的会给出原因（单篇失败不影响其他文章）。可「导入下一包」继续，或跳转文章管理检查成果。

## 单篇粘贴

五步向导：**选择方式 → 粘贴内容 → 内容转换 → 文章信息 → 导入完成**。

1. **粘贴**——在简书网页版打开文章，全选复制，直接 `Ctrl+V` 粘贴进编辑器：富文本自动转 Markdown（标题、加粗、链接、图片全保留），左侧源码右侧预览，可继续手动修正
2. **内容转换**——确认后服务端落仓：图片自动下载到文章目录（失败的保留远程链接），生成目录式文章
3. **文章信息**——AI 分析正文**自动补全**：标题（留空时 AI 拟定）、摘要、分类、标签建议，全部可手改；AI 不可用时回退为正文摘要截取，会明确提示 `aiUsed=false`
4. **定稿**——元信息写回文章，完成。可一键跳转[文章编辑](./post-editor.md)继续精修

> [!TIP]
> 标题输入框也支持粘贴兜底：剪贴板里只有富文本（从网页复制常见）时自动提取纯文本压成单行。

## 会话与任务说明

- 导出包上传后形成一个**会话**（解析结果缓存于服务端内存），有效期 24 小时，最多同时保留 3 个，超时/超量自动淘汰最旧的——「换一个包」可立即丢弃当前会话
- 后台导入任务结果保留 1 小时
- 服务重启后内存会话与任务清空，重新上传导出包即可，**已导入的文章不受影响**（它们已经落在内容仓里了）
