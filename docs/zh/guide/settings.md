# 站点设置

「站点设置」页把主题的全部配置项做成表单：左侧分区表单，右侧内嵌[真站预览](./dashboard.md#真站预览)，改完保存、预览刷新，所见即所得。

页面分五个页签：**基础信息**、**导航**、**页脚**、**主题外观**、**横幅壁纸**。

![站点设置 · 基础信息](/assets/guide/settings.png)

## 基础信息

七个分区，各自独立保存：

| 分区 | 配置什么 |
|------|----------|
| 站点信息 | 站名、副标题（副标题带 AI ✨ 一句话生成） |
| 个人资料 | 头像（在线 URL 或本地上传，自动重命名落仓）、昵称、签名（同样带 AI ✨） |
| 社交链接 | GitHub / B 站等外链列表：名称、Iconify 图标、地址 |
| 站点图标 favicon | 浅色 / 深色两个槽位；未自定义时显示主题默认图标的当前生效提示；上传自动定名 `favicon-light/dark.<ext>` 原位替换，也可直接填在线地址 |
| 常规设置 | 站点地址（部署后的最终域名）、子路径（根部署填 `/`）、时区（下拉常用时区，可手输） |
| 访客显示面板 | 控制前台开放给访客的显示开关：配色选择器、配色规范切换、背景模式、列表布局、减弱动效、背景纹理 |
| 国际化 | 是否开放多语言：勾选开放的语言集合，站点主语言必须落在集合内；关闭则全站锁定简体中文 |

## 导航

可视化的导航菜单编辑器：

- **主题预设**——从 15 个内置预设（首页、归档、友链等）中选取，一键接入
- **自定义链接**——名称 + 图标 + 地址，可标记「新窗口打开」
- **下拉分组**——拖出二级菜单收纳同类入口

导航配置整体保存，数组语义为**整体替换**。

## 页脚

- **启用开关**——控制自定义页脚内容是否注入主题版权行上方
- **HTML 编辑器**——CodeMirror 代码编辑器，附带 **Prettier 格式化**按钮；页脚 HTML 原文保存在内容仓 `config/footer.html`
- **页脚图片库**——上传图片或粘贴在线直链（服务端代取下载，webp 自动转 png/jpg）落仓到 `public/images/footer/`，点「复制路径」粘进 HTML
- **实时预览**——iframe 近似还原主题页脚渲染效果，版权行 + 你的自定义内容

## 主题外观

![站点设置 · 主题外观](/assets/guide/settings-appearance.png)

两个分区：

### 主题配色

- **色相滑块**（0–360）——实时显示由该色相生成的 5 级色板预览
- **锁定**——勾选后站点色相不随内容/访客偏好变化
- **配色风格**——Material 3 的 9 种动态取色风格：tonalSpot（经典柔和）、vibrant（鲜活）、content（取自内容色）、expressive、rainbow、fruitSalad、monochrome、neutral、fidelity
- **配色规范**——Material 3 的 2021 / 2025 两代规范

### 壁纸与纹理

- **默认背景模式**——banner / none 二选一，决定未选壁纸时前台默认形态
- **背景纹理**——六种预设：none、starlight（星光）、cyber-dots（赛博点阵）、topography（等高线）、geometric（几何）、sakura（樱花）；透明度 0.05–0.25；允许动效开关

## 横幅壁纸

首页横幅的完整控制：

- **桌面壁纸 / 移动壁纸**两组列表——本地上传、在线直链导入（服务端代取）、**AI 推荐壁纸**按钮（从 safebooru 图源按尺寸筛选抓取一批：桌面 ≥1920 横图、移动 ≥1920 竖图，勾选下载落仓）
- **展示控制**——位置（top/center/bottom）、遮罩（开关 + 透明度）
- **首页文案**——标题、多句副标题、打字机效果（速度/删除速度/停顿时长/循环）；副标题可点 **AI生成** 基于站名与签名一次生成 4–6 句轮播文案
- **轮播**——多张壁纸时启用，切换间隔、渐变时长、六种切换动画（ken-burns 缓慢推拉、zoom-in/out、pan-left/right、none）
- **波浪装饰**——横幅底部波浪动效开关

> [!TIP]
> 保存横幅时，不再被桌面/移动任何一端引用的本地壁纸文件会被**自动清理**，无需手动删文件。

## 配置落在哪里

所有设置写入内容仓 `config/*.yaml`，遵循**最小化覆盖**原则：只写你改过的键，未声明的字段继承主题默认值——主题升级新增配置项时你的站点自动跟进，不会因为一份「全量快照」而卡死在旧版本。字典键递归合并，数组整体替换。
