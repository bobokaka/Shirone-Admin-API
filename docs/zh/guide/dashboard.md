# 仪表盘与预览

打开 `http://localhost:5173/` 后看到的第一个页面就是**仪表盘**。它是整个后台的总览：当前有多少待发布的改动、多少文章与动态，以及一个实时渲染你博客真实外观的预览窗口。

![仪表盘](/assets/guide/dashboard.png)

## 四张统计卡

| 卡片 | 数值含义 | 快捷按钮 |
|------|----------|----------|
| **待发布变更** | 内容仓里已暂存 + 已修改 + 未跟踪的 git 变更文件总数 | 「去发布」→ 跳转[提交和发布](./publish.md) |
| **文章总数** | 内容仓中全部文章（含草稿） | 「管理文章」→ 跳转[文章管理](./posts.md) |
| **动态总数** | 全部说说（含草稿） | 「管理说说」→ 跳转[说说动态](./moments.md) |
| **草稿总数** | 文章与说说中标记为草稿的数量之和 | 「继续创作」→ 跳转文章管理 |

「待发布变更」就是你在后台做过的所有尚未提交改动的汇总——写完文章、发完说说后，看到这个数字不为零，说明还没发布上线。

## 最近内容

统计卡下方两张列表卡分别展示**最近 6 篇文章**与**最近 6 条动态**：

- 文章行显示标题、发布日期，草稿带黄色标签
- 动态行显示时间、置顶/草稿/标签，正文截取前三行，缩略图最多 3 张（点击可放大预览）
- 右上角「更多」跳转对应管理页

## 真站预览

页面底部的「真站预览」卡片内嵌一个 iframe，直接加载 `http://localhost:4321/` ——也就是主题仓 Astro 开发服务器渲染出的**真实站点**。它不是截图或简化模拟，预览效果与将来发布的站点完全一致。

### 状态指示与操作

预览面板顶部工具栏从左到右：

- **状态标签**（3 秒轮询一次）：
  - 站点就绪 `:4321` —— 预览可用
  - 检测到 dev server 已在运行 `:4321` —— 预览可用（进程非本面板启动）
  - 启动中，首次需编译… —— Astro 正在冷启动，稍等片刻
  - 未运行 —— 需要点「启动预览」
- **启动预览 / 停止** —— 在后台拉起或终止主题仓的 `content:watch` + `astro dev` 进程
- **新窗口打开** —— 弹出浏览器标签页直接访问 `:4321`

仪表盘的预览面板不会自动拉起进程（避免打扰），需要手动点「启动预览」。如果你是用 `node workspace/content-watch.mjs` 一键启动的，dev server 已经在跑，面板会直接显示就绪。

### 预览为什么是「真」的

[三仓工作区](./workspace.md)里介绍过数据流：后台保存 → 写入内容仓 → `content:watch` 物化到主题仓 → Astro 重新编译。所以你在后台改一处文案、保存，几秒后预览里的博客就会更新——**所见即即将发布的真实站点**。

## 顶栏与全局入口

每个页面共用的顶栏：

- **页面标题** —— 当前所在功能页名称
- **连接状态标签** —— 内容仓「已连接 / 未连接」（详见[三仓工作区 · 连接状态怎么看](./workspace.md#连接状态怎么看)）
- **✨ 按钮** —— 打开全局 [AI 控制台](./ai.md#ai-控制台)
- **齿轮按钮** —— 打开「设置」弹窗（[AI 服务商配置](./ai.md#配置服务商)与关于页）
