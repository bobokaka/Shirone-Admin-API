# 结构化数据

博客里「我的」页面上的项目、技能、设备清单，侧栏的番剧追番表、友链、背景歌单——这些都是**结构化数据**：每一类是内容仓 `data/*.ts` 里的一个 TypeScript 数组。「数据管理」页把它们全部做成表格 + 表单的可视化编辑，改动**即时落仓**。

![数据管理](/assets/guide/data.png)

## 八类数据

| 页签 | 条目 | 典型字段 |
|------|------|----------|
| 项目 | 项目 | 名称、简介、分类、阶段（已发布/开发中/探索中）、技术栈、精选 |
| 技能 | 技能 | 名称、分类（前端/后端/工具/游戏开发）、水平（入门→专家）、图标 |
| 时间线 | 事件 | 标题、日期、分类（里程碑/项目/经历/生活）、要点、关联链接 |
| 设备 | 设备 | 名称、品牌、分类、状态（在用/备用/退役/想买）、规格 |
| 番剧 | 番剧 | 标题、状态（在看/看完/计划/搁置/弃番）、评分、进度、类型、封面 |
| 罗盘 | 书架 | 名称、图标、导航条目（名称 + 链接 + 备注） |
| 歌单 | 曲目 | 曲名、艺术家、封面、音频地址、时长 |
| 友链 | 友链 | 站点名、头像、描述、地址、标签 |

## 通用操作

- **新增**——打开编辑弹窗逐字段填写；必填项缺失会拦截提示
- **表格内直接切换**——「精选」「启用」等布尔字段在表格里就是开关，拨动即保存
- **排序**——每行右侧 ↑↓ 按钮调整顺序（数组顺序即前台展示顺序），即时落仓
- **编辑 / 删除**——编辑打开弹窗回填全部字段；删除需二次确认

几个省力的细节：

- **标识字段自动生成**——项目 key、设备 id、曲目 id 等标识列不用手填：新增时由标题自动转拼音 slug（重名加序号），友链 id 取最大值 +1
- **图标字段**——输入 Iconify 图标名（如 `simple-icons:typescript`）即时预览；图标全部本地内置，不发起网络请求
- **图片字段**——封面支持本地上传（按数据类型自动落入对应资源目录）或粘贴路径；番剧/歌单有专门的一键导入，见下文
- **罗盘与时间线的条目列表**——「导航条目」「关联链接」这类嵌套数组用可视化卡片编辑，每条子项的名称/图标/地址一排填完，支持必填校验

所有改动通过**串行保存队列**写回 `data/*.ts`——文件里的 interface 定义、注释、导出语句逐字保留，只替换数组字面量部分，手工维护的代码不会被动到。

## 番剧：搜索导入

番剧页签专属的「**搜索导入**」按钮，数据来自 [Bangumi（番组计划）](https://bgm.tv/)公开 API：

![番剧搜索导入](/assets/guide/data-anime.png)

1. **搜索**——输入中文/日文/英文标题，返回候选列表（含年份、集数、评分、封面）
2. **选条目**——自动拉取详情补全：制作公司、放送档期、高频类型标签
3. **确认**——生成一条新番剧草稿：标题/年份/类型/简介/封面/制作都已填好，**状态与评分留给你定**；封面图从 Bangumi 官方图床下载落仓到 `public/assets/anime/`

追番记录从此不用手动填元数据，看完一部搜一部。

## 歌单：导入音乐

歌单页签的「**导入音乐**」提供三种进曲方式：

- **AI 检索**——描述想找的歌（歌名/风格），AI 联网检索并附带**版权信息**（能否免费商用、依据链接），确认后音频与封面自动落仓
- **直链导入**——粘贴音频直链，服务端代取下载（浏览器跨域拿不到的也能下）
- **本地上传**——直接上传音频文件

导入后在表格里点 **▶ 试听**，底部播放条随选随播，听对了再保存。

## 时间线：AI 起草

时间线页签的「**AI 起草**」按钮（AI 启用时出现）用两种模式批量生成事件草稿：

- **git 模式**——扫描三个仓库的提交历史（每仓最多 30 条，含文件增删统计），AI 归纳成时间线事件：适合「这个月我做了什么」的复盘
- **描述模式**——你写一句话描述，AI 起草成规范事件（标题/日期/分类/要点/标签）

生成的草稿列表可**逐条勾选**，已收录的事件自动去重（按标题 + 日期比对）。确认插入时按日期找到正确位置插入列表并落仓，日期格式自动转为站点使用的点分风格（`2025.06.01`）。

## 字段级 AI

简介、描述这类长文本字段（项目简介、技能描述、番剧描述、友链描述、时间线描述、设备描述）在编辑弹窗右上角有 **✨ 按钮**：填了条目标题之后，点一下 AI 按 1–3 句中文生成或改写该字段，结果流式直接在输入框里长出来，可停止、可手改。
