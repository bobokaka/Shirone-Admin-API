# 说说动态

「说说」是比文章轻量的内容形态：一段随想、几张图、一个心情图标。发布器在页面上方，动态流在下方，即写即发。

![说说动态](/assets/guide/moments.png)

## 发布一条说说

发布器卡片从上到下：

1. **正文**——多行文本框，此刻的想法
2. **图片区**——最多 **9 张**，点击 + 选择或直接粘贴上传
3. **元信息行**——心情 / 地点 / 标签 / 发布时间 / 置顶
4. **操作行**——AI润色（AI 启用时）/ 存草稿 / 发布说说

### 心情图标

九个预设心情可选：😊 开心、🤩 兴奋、😐 平静、😔 低落、😢 难过、❤️ 喜欢、🎉 庆祝、☕ 小酌、🌙 晚安。图标以 Iconify 名称存储（全部本地内置，无网络请求），前台渲染为对应图标。

### 图片如何归档

一次发布的所有图片进入**同一个批次目录**：

```
public/images/moments/<yyyymmdd-HHmmss>/   # 批次号与说说文件名一致
├── 1.webp
└── 2.webp
```

多选上传并发进行时也归入同一批（批次号预先生成）。这条目录规则不是随意的——主题的缩略图生成管线**只扫描** `public/images/moments/`，说说图放别处前台无法生成缩略图，所以后端强制约束了落盘位置。

> [!TIP]
> 发布前移除某张图只是从本次发布中去掉，文件仍留在仓库里；删除整条说说时配图文件同样保留，需要清理时手动处理。

### AI 辅助（可选）

AI 启用时发布器多两个入口：

- **AI润色**——流式改写正文，结果直接在输入框里长出来（口语化自然、保留语气与事实），随时可停止、停止即恢复原文
- **AI建议**——从正文提取 2–4 个标签（与已有标签合并去重）并猜测心情（已有选择不覆盖）

## 管理动态流

下方列表支持组合筛选与分页（每页 8 条）：

| 筛选 | 说明 |
|------|------|
| 搜索框 | 匹配正文、地点、标签 |
| 状态下拉 | 全部 / 已发布 / 草稿 |
| 标签多选 | 点卡片上的标签也能快速筛选（再点取消） |
| 只看置顶 | 复选框 |

每条动态卡片提供：

- **编辑**——内容回填到上方发布器（新上传的图进**新批次**，不混入旧目录），改完点「发布说说」保存
- **置顶切换**——一键置顶/取消，列表立即刷新
- **删除**——二次确认后移除 `.md` 文件（配图保留）

## 说说与文章的区别

| | 文章 | 说说 |
|---|------|------|
| 内容形态 | 长文 + 元信息体系 | 短文本 + 图 + 心情 |
| 存储 | `content/posts/<slug>/index.md` | `content/moments/<yyyymmdd-HHmmss>.md` |
| 典型用途 | 教程、笔记、深度思考 | 近况、碎碎念、随手记录 |
