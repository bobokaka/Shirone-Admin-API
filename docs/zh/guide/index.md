# 指南

欢迎使用 **Shirone-Admin**——[Shirone](https://github.com/LyraVoid/Shirone) 博客的可视化内容管理工具。它本地单机运行、前后端分离，直接读写你的内容仓，并提供 AI 辅助写作与一键双仓发布。

本板块面向**第一次接触 Shirone-Admin 的读者**：由浅入深、每一步都可照做复现，不需要任何背景知识。遇到不熟悉的概念，文中会在它首次出现时就地解释，或给出跳转链接。
