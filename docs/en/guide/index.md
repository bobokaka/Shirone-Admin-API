# Guide

Welcome to **Shirone-Admin**, the visual content management tool for the [Shirone](https://github.com/LyraVoid/Shirone) blog. It runs locally as a standalone application with a decoupled frontend and backend, reads and writes your content repository directly, and offers AI-assisted writing and one-click publishing across two repositories.

This section is written for **readers touching Shirone-Admin for the first time**: it progresses from basics to depth, every step can be followed and reproduced, and no prior background is assumed. Whenever an unfamiliar concept appears, it is explained in place on first mention, or a link is provided.
